# v0.1.0-rc.11 发布说明（2026-11-18）

> 单版本、面向玩家的发布说明（新增 / 改进 / 修复）。详细更新见
> [`changelog/v0.1.0-rc.11.md`](../changelog/v0.1.0-rc.11.md)；全量历史见根目录 [`changelog.md`](../../changelog.md)。

一句话：默认端口改 18080 并可用 `config.json` 配置；网页里能直接刷 Boss / 刷怪（按名单放行）；
图标网格三档大小；遮罩不糊了、全屏里看详情不再错位。

> 升级提示：**插件权限节点统一加了 `hf.` 前缀，老节点不再生效**。升级后请重新授权：
> `/group addperm default hf.webui.use`、`/group addperm default hf.webui.request.use`
> （管理组再加 `hf.webui.admin` / `hf.webui.request.review`），或对默认组跑一次 `/web init`。
> 另：默认端口从 8080 改成 **18080**，沿用旧端口的地方（`docker run -p`、反代、防火墙、书签）需要同步改，
> 想保持 8080 就设 `LISTEN=:8080` 或写进 `config.json`。

## 新增

- **`config.json` 配置文件**：第一次运行在启动目录生成（键名与同名环境变量一致），改完重启生效；
  优先级是「环境变量 > config.json > 内置默认值」，键名写错会直接报错而不是静默回退。
- **网页里直接刷 Boss / 刷怪**：`/spawnboss`（`/sb`）、`/spawnmob`（`/sm`）可以以你自己在线角色的身份执行，
  刷怪点就是你站的位置。默认不开，服主要同时配 `TSWUI_ALLOW_INGAME_COMMANDS=true` +
  `TSWUI_INGAME_COMMANDS=spawnboss,spawnmob` 与插件 `"InGameOnlyAllowlist": ["spawnboss","spawnmob"]`；
  其余 22 条「仅游戏内」指令仍然只能在游戏内敲。
- **图标大小三档**（页面设置 →「图标大小」）：
  - 物品 ID：大 64 / 中 48（默认）/ 小 32；
  - 数据 ID：NPC 默认大，图格 / 墙 / Buff 默认中，Boss 分类按档位放大一倍；
  - 鱼店货架：默认中。小尺寸只显示图标。

## 改进

- **默认端口统一 `18080`**：单文件二进制、Docker 镜像、开发脚本、vite 代理一致。
- **物品 ID 结果区左上角直接放制作界面的 11 个分类**：点一下只看该类，再点一次取消；
  手机上整行横向滑动、边缘渐隐提示。
- **侧栏全局搜索执行后可原地重跑**：焦点留在搜索框，`Enter` 再跑一遍、结果累积对比，`Esc` 回列表。
- **遮罩统一半透明黑、不再模糊**；物品 ID 的分组抽屉桌面端只盖内容区，左侧边栏照常能点。
- **图集换成无损 WebP**：首次打开要下载的数据约 2.8MB → 1.7MB，画质逐像素一致。
- **反代来源 IP 取右端段**，新增 `TRUST_PROXY_HOPS`（默认 1，套 CDN 设 2）；只影响 `TRUST_PROXY=true` 的部署。

## 修复

- **全屏里看详情不再错位**：物品 ID / 数据 ID 全屏后打开详情，遮罩盖满整屏；鱼店全屏连顶栏一起盖住，
  页面设置 / 退出全屏挪到右上角的小操作坞。
- **鱼店不再预判「能不能买」**：NPC 刚被杀 / 人已复活时的红字与禁用按钮去掉，真买不了时点一下看插件报错。
- **被拦下的游戏内指令会说明原因**：没装插件 / 没开总闸 / 这条不在名单 / 连不上服务器，四种情况分开提示。
- **安全加固**：响应头补 `frame-ancestors 'none'` 与 `X-Frame-Options: DENY`，防点击劫持。
