# 开发速查（环境路径 / 常用命令 / 数据再生成）

> 这里只放**可执行信息**；规则与铁律见 [`../AGENTS.md`](../AGENTS.md)，文档索引见 [`README.md`](README.md)。

## 环境路径

> 约定：`$HOME/tr` = 本机 Terraria 资源根目录（TShock 配置 / 插件目录等所在处）。

| 用途 | 路径 / 变量 |
| --- | --- |
| 反编译源码（1.4.5.8） | `TR_SRC`，默认 `<仓库>/../tr-code-1458` |
| 已解包图标 | `SPRITE_DIR`，默认 `<仓库>/../tr-sprite-1458/Content/Images` |
| TShock 源码 | `TSHOCK_SRC`，默认 `<仓库>/../TShock` |
| 生成的数据 | `data/`（**禁止手工修改**） |
| 前端 | `web/`（base 目标 `/`） |
| 信使插件（在线授权） | `plugin/WebUI/`（C# / net9.0，引用 TShock 6.2.1 NuGet） |
| 插件配置（运行时） | `<TShock SavePath>/WebUI/config.json`（`Secret` / `TimeoutSeconds`） |
| 后端 | `server/`（Go 1.27，标准库 only） |
| 角色存档解析（`.plr`） | **纯前端**：`web/src/lib/save/aes.ts`（AES-128-CBC 无填充解密）+ `plr.ts`（字段解析 → `PlayerLook`）；文件不上传 |
| 世界存档解析（`.wld`） | **纯前端**：`web/src/lib/save/worldFile.ts`（头部字段）+ `worldThumb.ts`（图格 RLE → 缩略图位图）；颜色表 `worldColors.generated.ts` 由 `tools/gen-world-colors.mjs` 生成 |
| 存档解析测试夹具 | `web/src/lib/save/fixtures/webui-326.plr`（真实 1.4.5.8 角色存档）+ `web/public/demo/Joy.plr`（1.4.0.2 旅途角色，也是「来个 Demo」那份）；世界存档用 `web/src/test/worldFile.ts` 现场合成 |
| 图格图例名来源（查找图格 / 显示名） | `data/tile-names.json`（`TR_SRC=../tr-code-1458 node tools/gen-tile-names.mjs`，提取 `Lang.cs BuildMapAtlas()` 的赋值规则）；名字本身在 `data/loc.*.json` 的 `ItemName` / `MapObject` |
| 物品数量上限（`.plr` 编辑器校验） | `data/item-limits.json`（`GameDump --item-limits`：`Item.maxStack` + `ItemID.Sets.ItemsThatShouldNotBeInInventory`） |
| 存档版本 → 游戏版本表 | `web/src/lib/save/playerVersions.ts`（由 TEdit `src/TEdit.Terraria/Data/versions.json` 的 `gameVersionToSaveVersion` 反查生成，游戏升版时重新生成） |
| TEdit（世界文件参考实现） | `TEDIT_DIR`，默认 `<仓库>/../TEdit`（`MapColors.xml` / `docs/settings.xml` 是颜色表来源） |
| 内嵌前端产物 | `server/internal/webdist/`（构建期由脚本/Dockerfile 注入，`//go:embed`，不入库）；Dockerfile 消费预构建的 `web/dist` |
| 单文件产物 | `dist/`（`scripts/build-binary.sh` 生成，不入库） |
| 本机 TShock 配置 | `$HOME/tr/s/ts/tshock/config.json` |
| 本机 TShock 容器 | `s/ts/docker-compose.yml`，REST `127.0.0.1:7878` |

> `Makefile` 是常用任务的薄封装（`make help`）：`data` / `web` / `lint` / `test` / `plugin` / `image` / `binary` /
> `dev` / `dev-all` / `dev-web` / `dev-container(-frontend|-backend)` / `clean`。

## 常用命令

```bash
# 数据（升级版本后必跑）
node tools/gen-data.mjs
python3 tools/gen-atlas.py
python3 tools/gen-player-atlas.py   # 玩家角色全身图图集（需 Pillow；见 docs/计划-玩家全身图.md）
python3 tools/gen-npc-atlas.py      # NPC 贴图图集（需 Pillow；见 docs/页面-数据ID.md）
python3 tools/gen-buff-atlas.py     # Buff 图标图集（需 Pillow；见 docs/页面-数据ID.md）
python3 tools/gen-brand-assets.py   # favicon.png + login-art.png（猛爪手套，取自物品图集；需 Pillow）
TEDIT_DIR=../TEdit node tools/gen-world-colors.mjs   # 世界缩略图颜色表 → web/src/lib/save/worldColors.generated.ts
bash tools/gen-game-data.sh     # 合成表 + 属性 stats + item-tips + item-groups + shimmer + prefix-mods + prefix-sets
                                # + tiles/walls + item-limits + tile-names（需 dotnet 9）
node -e "const d=require('./data/items.json');console.log(d.items.length, d.items.filter(i=>i.icon==null).length)"   # 6195 0
node -e "const a=require('./data/items-atlas.json');console.log(a.meta.width+'x'+a.meta.height, Object.keys(a.regions).length)"  # 1024x4906 6133
node -e "const a=require('./data/player-atlas.json');console.log(a.meta.width+'x'+a.meta.height, Object.keys(a.regions).length)"  # 1024x968 507
node -e "const a=require('./data/npc-atlas.json');console.log(a.meta.width+'x'+a.meta.height, Object.keys(a.regions).length)"    # 1024x5042 694
node -e "const a=require('./data/buff-atlas.json');console.log(a.meta.width+'x'+a.meta.height, Object.keys(a.regions).length)"   # 1022x428 400
node -e "const t=require('./data/tiles.json');const w=require('./data/walls.json');console.log(t.entries.length, w.entries.length)"  # 754 367
node -e "const r=require('./data/recipes.json');console.log(r.meta.count, r.meta.groupCount)"   # 3603 34
node -e "const s=require('./data/item-stats.json');console.log(s.meta.itemsWithTip)"             # 6049
node -e "const g=require('./data/item-groups.json');console.log(g.tabs.length, Object.keys(g.items).length)"  # 11 6195
node -e "const s=require('./data/shimmer.json');console.log(s.meta.count)"  # 316
node -e "const p=require('./data/prefix-mods.json');console.log(p.meta.count)"  # 78
node -e "const p=require('./data/prefix-sets.json');console.log(p.meta.setCount, p.meta.itemCount)"  # 7 886
node -e "const z=require('./data/loc.zh-Hans.json');console.log(z.ItemName.Zenith, z.NPCName.Turtle)"  # 天顶剑 龟

# 前端（web/）
cd web && npm install
make dev-web         # vite HMR 页面跑在 :5173，/api → 127.0.0.1:18080（容器后端）
                     # 启动前会探一次 API_TARGET/healthz，后端没起会先提示（否则只会看到 http proxy error）
                     # 换端口：make dev-web WEB_PORT=5174 API_TARGET=http://127.0.0.1:8080
npm run dev          # 裸跑 vite：:5173，/api 代理到 VITE_API_TARGET（默认 :8080）；端口用 VITE_PORT 改
npm run build        # 产物 web/dist/，base=/
VITE_TRANSPORT=mock VITE_BASE=/TShockWebUI/ npm run build   # GitHub Pages 演示（子路径 + Mock）
npm run typecheck && npm run lint && npm run test:run

# 信使插件（在线授权；plugin/WebUI）
cd plugin/WebUI && dotnet build -c Debug   # → bin/Debug/net9.0/WebUI.dll
# 部署：DLL 放进 TShock 的 plugins 目录后重启 TShock；ts-sync-plugins 会自动同步（无需登记）

# 后端（server/）
cd server && go vet ./... && go test -race ./...
WEB_DIST_DIR=../web/dist TSHOCK_URL=http://127.0.0.1:7878 go run .   # :8080
# 真实 TShock 联调（默认不跑，需可用 token）
TSHOCK_URL=http://127.0.0.1:7878 TSHOCK_TOKEN=simpleToken go test -tags integration -run Integration -v ./internal/tshock
# 存档解析（前端）：单测覆盖合成世界 + 真实 .plr 夹具

TSWUI_REAL_WORLDS=~/tr/s TSWUI_REAL_PLAYERS=~/tr/Terraria/Players \
  npx vitest run src/lib/save/localSaves.test.ts
# 对已运行后端做端到端冒烟
TSWUI_TOKEN=$TSHOCK_TOKEN server/scripts/smoke.sh

# 容器
# 宿主直跑（绕过 Docker 容器网络/代理；访问公网 TShock 时用）
scripts/dev-native.sh               # 默认 :8080，多服务器切换默认开
BUILD_WEB=1 scripts/dev-native.sh   # 先 npm run build 再启动
# 开发迭代（不 build 镜像）：宿主构建 + 挂载到 distroless 跑，秒级反馈
scripts/dev-container.sh            # 构建前端+后端并（重）启动（= make dev-container）
scripts/dev-container.sh frontend   # 只重建前端：刷新浏览器即可，无需重启（= make dev-container-frontend）
scripts/dev-container.sh backend    # 只重建后端并重启容器（= make dev-container-backend）
LOGS=1 scripts/dev-container.sh      # 前台跟随日志

# 典型的「改 UI」日常（后端常驻 :18080，vite HMR 在 :5173）：
make dev-all                # 一条命令：后端容器（:18080）+ vite 页面（:5173）
                            # 之后只改 web/ 就别重跑它了，自己开第二个终端 make dev-web
make dev-container         # 终端 A：起（或重建）后端，默认 :18080
make dev-web               # 终端 B：vite HMR 页面 :5173，/api → 127.0.0.1:18080
                           # 开 http://localhost:5173 改 UI；http://localhost:18080 仍是旧 dist（要更新用
                           # make dev-container-frontend）
                           # 想让 HMR 也落在 18080：make dev-all WEB_PORT=18080 API_PORT=18081
                           # 另：make image 默认也占 18080，与开发容器不能同时跑
# 交付验证（真镜像）
scripts/run-container.sh                 # 构建前端+镜像并（重）启动容器，默认映射 :18080，TSHOCK_URL=http://host.docker.internal:7878
SKIP_WEB_BUILD=1 scripts/run-container.sh   # 复用现有 web/dist
NO_BUILD=1 PORT=8080 scripts/run-container.sh   # 跳过构建 / 换端口
NETWORK=ts_default TSHOCK_URL=http://tshock:7878 scripts/run-container.sh   # 加入 TShock 所在网络
FOREGROUND=1 scripts/run-container.sh    # 前台运行看日志
docker images tshockwebui:dev --format '{{.Size}}'   # 目标 ≤ 30MB

# 单文件（内嵌前端+data，无需 Docker/Node 即可运行；macOS/Windows/Linux）
scripts/build-binary.sh                  # → dist/tswui（GOOS/GOARCH/OUT/VERSION/SKIP_WEB/SMOKE 可覆盖）
SKIP_WEB=1 SMOKE=1 scripts/build-binary.sh          # 复用 web/dist + 自动冒烟
SMOKE_PORT=18123 SKIP_WEB=1 SMOKE=1 scripts/build-binary.sh   # 默认端口 18099 被占时换一个
                                                    # 冒烟会先确认端口空闲、并核对 /healthz 版本 = 本次构建
GOOS=windows GOARCH=amd64 scripts/build-binary.sh   # 交叉编译 → dist/tswui.exe
./dist/tswui -version                    # 版本号（-X main.version 注入，默认 git describe）
# Windows 用户：scripts/build-binary.ps1（同参数；尚未在 Windows 实机验证）
```

## 数据再生成（升级游戏版本时）

1. 确认新的 `tr-code-*` 反编译源码与 `tr-sprite-*` 已解包，且 TShock/OTAPI 构建产物版本一致。
2. `TR_SRC=... SPRITE_DIR=... node tools/gen-data.mjs`，再 `python3 tools/gen-atlas.py`、
   `python3 tools/gen-player-atlas.py`、`python3 tools/gen-npc-atlas.py` 与 `python3 tools/gen-buff-atlas.py`。
3. `TR_SRC=... bash tools/gen-game-data.sh`（合成表 + 物品属性 + 创意菜单分组 + 微光嬗变 + 词缀修正/可滚词缀 + 图格/墙表）。
4. 检查 `data/meta.json` 的 `gameVersion`，抽查若干已知物品（29 生命水晶、4956 天顶剑）。
5. 同步更新 `data/README.md` 与 `docs/设计原则与约束.md` 的版本号。

## 发版（GitHub Release + Docker）

- **版本**：app（Go + 内嵌 web）`0.1.0`；信使插件独立 `0.1.0`。预发布用 `-rc.1` 后缀（如 `0.1.0-rc.1`）。
- **触发**：`release.yml` 只在**推 tag（`v*`）**或 Actions 手动 Run 时运行；普通分支 push 只跑 `ci.yml` 测试，**不会发版**。

  ```bash
  git tag v0.1.0-rc.1 && git push origin v0.1.0-rc.1   # 预发布（自动标 Pre-release，Docker 不打 :latest）
  git tag v0.1.0       && git push origin v0.1.0        # 正式（Docker 追加 :latest）
  ```

  别用 `git push --tags` / `--follow-tags`（会把本地所有 tag 一起推）。
- **产物**（同一个 GitHub Release）：
  - `tswui-<版本>-{linux-amd64,linux-arm64,windows-amd64.exe,darwin-arm64}`（**不再编译 darwin-amd64**）
  - `WebUI-<版本>.dll`
- **Docker**：多架构（linux/amd64 + linux/arm64）推
  - `ghcr.io/<owner>/tshockwebui`（用 `GITHUB_TOKEN`，需仓库允许 packages 写入）
  - Docker Hub（可选）：仓库 secrets `DOCKERHUB_USERNAME` / `DOCKERHUB_TOKEN`，未配置则只推 GHCR。
- **手动触发**：Actions → Release → Run workflow，填 `version`（tag 由它拼成 `v<version>`）。
- **撤销 / 重发**：`gh release delete <tag>`、`git push origin :refs/tags/<tag>`；在工作流重跑会用 `gh release upload --clobber` 覆盖资产。
