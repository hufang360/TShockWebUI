# 功能 · 查找图格（在世界里定位某个方块 / 物件）

> 「世界存档」页的「查找图格」卡片：按名字找图格（生命水晶、金矿、罐子…），
> 得到**命中数量 + 坐标列表**，并可**在缩略图上标记**。纯本地扫描，不上传、不需要登录。

## 1. 怎么用

1. 输入名字（也支持常量名 `Heart`、ID `12`、代表物品名）→ 候选列表：**图格 / 墙 / 液体**三类都能搜；
2. 点一个候选 → 扫描世界（大世界约 0.15 秒，带进度条）；
3. 看到「命中 N 处」+ 坐标列表（最多列 200 个）；
4. 三个动作：
   - **在缩略图上标记**：命中点画成红点（覆盖层 canvas，不改缩略图位图），左上角显示图例 `生命水晶 ×37`；
   - **点坐标**：打开 1:1 大图并**平滑滚动到那个位置**，画一个黄色高亮圈；
   - **导出坐标 CSV**：下载 `<世界名>-<目标>.csv`，抬头是目标与世界信息，正文是 `x,y` 每行一个。

## 2. 名字从哪来（口径 = 游戏地图图例）

游戏里图例名来自 `Lang.BuildMapAtlas()` 往 `_mapLegendCache` 里填值。我们把那批规则**静态提取**成
`data/tile-names.json`，解析顺序：

1. `objects[tile]` → `loc.MapObject[key]`（树 / 铁 / 罐子 / 门…，79 条，中英都有）；
2. `items[tile]` → `loc.ItemName[代表物品]`（**生命水晶就走这条**：`Lang.cs:584` 把图格 12 指到物品 29）；
3. `data/tiles.json` 的 `item`（能放置出该图格的物品）；
4. 都没有 → 常量名（`Heart` / `Pots`…）。

这条链同时修掉了之前「图格 12 显示成 `Heart`」的问题：地图分析、查找、导出统一用 `dataset.tileNameById`。

**覆盖率实测**（754 个图格 id）：`MapObject` 84 / 图例物品 262 / 代表物品 338 / **只剩常量名 70**。
那 70 个（藤蔓 `Vines`、腐化草 `CorruptPlants`、垃圾桶 `TrashCan`…）在游戏自己的图例里**本来就是空的**
（`_mapLegendCache` 初始化成 `LocalizedText.Empty`，`BuildMapAtlas` 没给它们赋值），
所以我们显示常量名不是漏提取；要搜到它们只能用常量名或 id。

## 3. 扫描实现

- 复用 `worldThumb.ts` 的图格流解码**规则**（字段顺序完全一致），但**单独跑一趟**，只记录命中的 `(x, y)`：
  用户点「查找」时才扫，不拖慢导入。
- RLE 是「同列向下重复」：命中时按重复格数逐个展开坐标（`y .. y+cells-1`）。
- **命中过多**（找「石块」动辄几百万处）时：**计数按真值**，坐标只保留前 5000 个并标记 `truncated`；
  界面显示「命中太多，只保留了前 N 个坐标」。
- 每 128 列 `setTimeout(0)` 让出主线程，进度条能刷新。
- 支持三类目标：**图格**（`tile:id`）、**墙**（`wall:id`）、**液体**（`liquid:1..4`，水/岩浆/蜂蜜/微光），
  一趟解码同时判断；空气不在范围内。

## 4. 数据与生成

| 文件 | 内容 | 生成 |
| --- | --- | --- |
| `data/tile-names.json` | 图格 → 图例名来源（`items` / `objects`） | `TR_SRC=../tr-code-1458 node tools/gen-tile-names.mjs` |
| `data/loc.<culture>.json` 的 `MapObject` | 79 条图例名（树 / 铁 / 罐子…） | `tools/gen-data.mjs`（已把 `MapObject` 加进 `LOC_CATEGORIES`） |

`gen-tile-names.mjs` 的提取方式：定位 `BuildMapAtlas()` 方法体 → 正则匹配
`_mapLegendCache[MapHelper.TileToLookup(tile, style)] = itemNameCache[item] | Language.GetText("MapObject.Key")`
→ 只取 `style 0`（同名变体）→ 额外展开两个循环（`IsATreeTrunk` → `Tree`、罐子 `for k<9`）。
当前提取到 **items 262 / objects 84**。

## 5. 交互细节

- 点坐标跳转时用 `scrollTo({behavior:'smooth'})`，目标居中；同一坐标可以重复点（内部用 `seq` 触发）。
- 标记与跳转互不影响：取消标记只清红点，跳转弹窗独立关闭。
- 导出用 `text/csv;charset=utf-8`，抬头行以 `#` 开头，方便 Excel / 脚本直接读正文。

## 7. 限制

- 图格级查找，不区分样式 / 帧（同 id 的不同外观会一起算）。
- 界面最多列 200 个坐标；更多请用「导出坐标 CSV」（完整列表，最多 5000 条，见 §3）。
- 墙的显示名没有地图图例口径（游戏只给图格做图例）：用「代表物品名 → 常量名」。
