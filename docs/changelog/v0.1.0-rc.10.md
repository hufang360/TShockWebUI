# v0.1.0-rc.10 更新日志（2026-11-14）

> 单版本、按功能模块的详细更新。对外发布说明见 [`release/v0.1.0-rc.10.md`](../release/v0.1.0-rc.10.md)；
> 全量历史见根目录 [`changelog.md`](../../changelog.md)。

本轮重点：侧栏全局搜索升级成「可展开、可执行」的命令面板；新增「常用表格」页（世界种子 / 词缀 / 常用链接）；
全站焦点样式与下划线 tabs 对齐 shadcn；移除「工具 › 精灵图」。

## 全局搜索（侧栏搜索框 / `Ctrl·Cmd+K`）

- **结果可以在弹框里逐级展开，指令直接执行**
  - 被截断的组末行是「更多」+ 命中数：点它（或回车）在弹框内展开该组，最多 20 条；
    超过 20 条时最后一条「更多」（右侧写目标页名，如 `物品 ID`）才跳页，并带上搜索词。
  - 展开后 `Esc` 回一级，再进同一组会回到原来那一行；清空搜索词或关掉弹框就忘掉，重开一律是空面板。
  - 指令回车就是**执行**：`/help`、`/help 2` 都能跑。数据里标了「必填参数」的指令也不再被拦
    （那份标记是从 TShock 源码解析的，`/help` 这类参数其实可省），缺参数时 TShock 的用法错误会直接显示；
    失败时结果下面给「查看用法」，标了必填参数的再给「填入终端」补参数。
  - 执行结果用**富文本**显示：`[c/RRGGBB:文字]` 上色、`[i:ID]` 出物品图标，与「指令」页的结果面板一致。
- **整行输入即可执行**：`/help 4`、`.wm find 生命水晶` 会在列表顶部给出「执行指令：…」一行（默认高亮），
  回车就执行、结果留在弹框里；这种查询没有其它命中时不再报「没有找到」。
- **带前缀也能命中指令**：`/help`、`.help`、`/help 4` 都按 `help` 匹配。
- **仅游戏内指令**（`allowServer=false`）标红、右侧写「仅游戏内」，回车只去「指令」tab 看用法。
- **行里不再有图标按钮**：`⌘/Ctrl+C` 复制、`⏎` 执行 / 查看 / 打开 / 填入终端，动作全写在底栏；
  底栏文案跟着当前高亮行变，键帽用符号与图标（`⏎`、delete 键），不写英文单词。

## 常用表格（`#/ref`）

- **新页面**：指令 + 世界种子 + 词缀 + 常用链接 四张表。
  侧栏名「常用表格」（`BookText` 图标），在「数据 ID」下一行；旧地址 `#/tables`、`#/commands`、`#/spawn` 都落到本页。
- **第一个 tab 改名为「指令」**（原来叫「指令小抄」，内容与入口位置不变；搜索里搜「指令小抄」「小抄」仍能到）。
- **世界种子**：特殊世界种子 9 个 + 秘密世界种子 37 个（按碰撞 / 世界生成 / 生物群系 / 结构 / 被动 / 生成点 / 其他分类）
  合成一张表；种子列逗号分隔多写法，点整行看详情；详情里有 `WorldModify` 开关指令，一键填入浮动终端。
- **词缀**：96 条（含 19 个饰品词缀），列出伤害 / 速度 / 暴击率 / 魔力消耗 / 大小 / 射弹速度 / 盔甲穿透 /
  召唤标记伤害 / 击退 / 饰品效果 / 级别 / 价值；增值绿、减值红；可按配饰 / 武器 / 公共 / 近战 / 远程 / 魔法 / 召唤过滤。
- **常用链接**：wiki 条目（中文界面走中文站、英文走英文站）、TShock 仓库与发布页、存档 / 地图 / 材质包工具链、社区论坛。
- 种子图标全部本地化（`data/seed-icons/`）；吸血鬼症用 NPC 159 的贴图单独裁出，不加载整张 NPC 图集。

## 界面与交互

- **详情弹框统一为 Dialog**：种子 / 词缀行、「指令」tab 的指令详情都从 popover 改成居中弹框，
  遮罩与鱼店抽屉一致（半透明黑、不模糊）。「填入浮动终端」后自动关掉弹框，免得遮罩挡住右下角的终端。
- **焦点样式与 shadcn 对齐**：全站 `focus-visible` 从 ring 改为 `outline: 2px solid var(--color-ring)` +
  `outline-offset: 2px`，键盘导航才看得见，鼠标点击不再出现粗框。
- **下划线 tabs（物资申请 / 数据 ID / 常用表格 / 设置）与 shadcn 对齐**：贴着底边一条 2px 线、去掉灰色轨道线；
  选中项只变字色不加粗；没有权限的 tab 不再显示手型光标和悬停高亮。

## 移除

- **「工具 › 精灵图」**（本地 PNG 切图 / 多图合并 / GIF 拆帧）：侧边栏不再有入口，`#/slice` 老地址回到首页，
  也不再占用本机存储键（浏览器里残留的 `tswui:spriteSheet` 无害）。
  功能迁到单独项目，规格、算法与实现说明存档在 [`记录-精灵图.md`](../记录-精灵图.md)。
