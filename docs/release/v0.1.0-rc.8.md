# v0.1.0-rc.8 发布说明（2026-11-04，预发布）

> 单版本、面向玩家的发布说明（新增 / 改进 / 修复）。详细更新见 [`changelog/v0.1.0-rc.8.md`](../changelog/v0.1.0-rc.8.md)；
> 全量历史见根目录 [`changelog.md`](../../changelog.md)。

一句话：新增语言材质包与 `/web init`；「指令」页把聊天并了进来；卡片、物品详情、数据 ID 与鱼店整体翻新。

> 升级提示：语言材质包只影响显示、数据只存浏览器；鱼店建造图需新版鱼店插件；预发布不打 `latest`。

## 新增

- **语言材质包**：设置里上传创意工坊的语言包 `.zip`，物品名 / 提示 / NPC / Buff / 词缀 / 图格 / 配方组名改用包内文本；
  可叠加多个、列表靠上优先，立即生效；只存本机、不上传、不影响指令执行；内置「1.4.2 汉化修正」（默认关闭）。
- **指令页自带聊天**：一个输入框，`/` 开头执行指令、其它内容发到游戏内聊天（带 `[WebUI] 玩家名:` 前缀）；
  宽屏左右两栏可拖、双击复位，手机上顶部切换；旧「聊天」页移除，`#/chat` 仍可用。
- **`/web init`**：一条指令写好推荐的 TShock REST 配置，并给默认注册组补齐必需权限；幂等、只升不降，管理权限不自动发。
- **鱼店**：「买过 / 收藏」页签（只存本机、按商品内容识别）、建造范围示意图、商品「广告到游戏内」、
  `/fish reload` 重载卡片（成功后自动刷新货架）。
- **物品 / 数据 ID**：物品提示右上角 ⓘ 直接打开详情；NPC 详情与表格显示英文名，召唤 / 地牢等指令合并成「相关指令」；
  Buff / 物品详情的同类指令也统一成这一套。
- **其它**：顶栏浮动终端入口；TShock 服务器弹框显示实测延迟。

## 改进

- **结果与卡片**：长结果超过 20 行改为框内滚动；手动卡片显示「执行于 …」、超过一天提示可能过时，结果刷新后仍在；
  卡片可选小 / 大 / 右栏并拖拽排序，按服务器分别保存；「管理卡片」抽屉改一行一张，行内切尺寸 / 自动执行 / 显示。
- **指令页**：输入框上方新增「发送内容预览」；工具面板收成两个入口 + 底部图标 tab（常用指令、插入 ID / 标签、记住上次位置）；
  浮动终端输入区收成一行。
- **物品详情**：复制 / Wiki 移到底部固定操作区；提示占满整行；「合成 / 作为材料 / 微光嬗变 / 词缀」四个分区统一；
  词缀总是显示、带 ID 与评分、可一键广播到游戏内，从带词缀的标签点进详情会自动对上。
- **表格**：物品 ID 与数据 ID 的表格修正表头吸顶与列宽，列名统一为 `ID`，整行可点；NPC 表格支持两列。
- **鱼店**：图标大小三档 + 「货架板」外观（可关）；页面设置 / 全屏移到顶栏；表格加斑马纹、名称列显示词缀。
- **说明与统一**：页面说明变成正文顶部说明卡、使用说明可收起；全站图标按钮统一三档并带悬停说明。

## 修复

- 输入框「幽灵文字」错位、长文本时横向滚动条盖住输入框。
- 物品提示同时叠出一堆；物品 ID 表格图标不再缺少提示。
- 自定义模块「使用说明」开头的 `NaN`。
- 指令卡片页头图标大小不一致。
- 鱼店右栏卡片被压扁、货架最后一行板线被容器切掉。
- 表格表头吸顶位置偏移。
