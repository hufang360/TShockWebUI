# v0.1.0-rc.13 发布说明（2026-11-21）

> 单版本、面向玩家的发布说明（新增 / 改进 / 修复）。详细更新见
> [`changelog/v0.1.0-rc.13.md`](../changelog/v0.1.0-rc.13.md)；全量历史见根目录 [`changelog.md`](../../changelog.md)。

一句话：鱼店货架改成手动刷新 + 本机缓存（再进页面不再打服务器）；首页世界信息 / 我的背包默认改手动执行。

> 升级提示：本版没有配置或权限变更。鱼店货架**不再自动刷新**——服主改完 `fish.json` 后 执行 `/fish reload`，
> 或让玩家点工具条的「刷新货架」（缓存超过 24 小时会变成警告色提醒）。

## 新增

- **鱼店「刷新货架」按钮**：工具条上手动重拉一次，按钮旁显示「更新于 20:08」；
  超过 24 小时没更新会变警告色并带上日期，提醒该刷了。

## 改进

- **鱼店货架不再定时重拉**：只在货架为空时请求一次，拿到就存本机（按服务器分开）。之后刷新页面、
  切走再回来都直接读缓存，**不再请求服务器**。右侧卡片的「刷新全部」也不再顺带刷货架。
- **商品详情不再显示「我的进度 / 还能买 N 次 / 冷却」**：拉货架时不再逐条算个人限购，
  能不能买以购买那一刻的服务器判定为准（买不成会原样提示原因）。
- **鱼店「分组」取消分组更顺手**：下拉第一项固定是「全部」，点它或再点一次已选中的分组就回到整张货架，
  工具条少了旁边那颗 ×。
- **首页「世界信息」「我的背包」默认手动执行**：不再跟着进页面自动打指令，按钮是 ▶「执行」、
  左下角显示「执行于 …」。想自动刷新就在「管理卡片」里打开。

## 修复

- 修掉鱼店货架与右侧卡片「刷新全部」互相牵连的问题（现在各刷各的）。
