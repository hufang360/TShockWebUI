# v0.1.0-rc.14 更新日志（2026-11-26）

> 单版本、按功能模块的详细更新。对外发布说明见 [`release/v0.1.0-rc.14.md`](../release/v0.1.0-rc.14.md)；
> 全量历史见根目录 [`changelog.md`](../../changelog.md)。

本轮重点：存档跨游戏版本转换（世界 1.4.0.1–1.4.6.1 升级 / 1.4.4 起降级、角色 1.4.0.1 ↔ 1.4.6.1 双向）+
全面支持 1.4.6.1；数据 ID 新增油漆 / 射弹两个页签；首页内置指令卡改为默认手动执行。

## 存档（角色 / 世界）

- **支持 1.4.6.0 / 1.4.6.1（release 329）**
  - 角色存档：1.4.6.1 的 `.plr` 直接查看 / 编辑（329 的字段布局与 1.4.5.8 一致，不做特殊处理）。
  - 世界存档：1.4.6.1 的世界可以打开、分析、编辑；新增「无蜘蛛世界」特殊种子徽章。
- **世界存档可改游戏版本**（「世界存档 → 编辑」的**版本**下拉）
  - 同布局段只改版本号；跨段按目标版本真正转换格式：头部字段、箱子段、NPC 段、图格实体段。
  - 升级：1.4.0.1（225）起都支持，一直到 1.4.6.1（329）；补默认值（天顶 / 8 个 NPC 解锁位按世界自身状态推导）。
  - 降级：只到 1.4.4（269）—— 再往下缺少可靠的实体类型表，明确拒绝而不是赌。降级删字段
    （最后游玩时间 / 永久节日 / 种子位 / 团队出生点 / manifest / NPC 流浪消失位等），界面说明**无法恢复**。
  - 降级前扫描世界内容：目标版本没有的图格 / 墙 / 物品 / NPC / 图格实体类型直接**拒绝**并报出具体 ID。
  - 299–312 的预览版存档只读不转。
- **玩家存档可转游戏版本**（「查看存档 → 编辑」的**版本**下拉，1.4.0.1 ↔ 1.4.6.1 双向）
  - 按目标布局段分组列出，不再是几十项平铺。
  - 升：只插入新版本多出来的字段（生态火把位、BUFF 容量、矿车包、死亡次数、虚空袋收藏位、三套配装、
    研究进度前导位、队伍、声音、音调、退款队列、一次性对话、收藏位、预留位），其它字节不动。
  - 降：只删除目标版本没有的字段；**删掉的内容无法恢复**，界面先说明，原文件不覆盖、下载的是新文件。
  - 明确拒绝而不是硬写：存档尾部读不出来（被第三方改过）、退款队列里还有东西（条目长度无法确认）。
    1.4.0.1 之前的版本（1.4.0 及更早、1.3.x、1.2.x）不支持转换。
- **超出原版上限的数值不再锁死编辑器**
  - 只校验**改过**的那一项（与「只校验改过的物品格子」同一口径）：原样不动就能改背包、改物品；
    真要把生命改成超范围才报错。SSC / 插件服导出的生命 600 / 1000 / 30000 这类档不再一个字都改不了。
- **修**「版本号」下拉的布局段判断漏了一个门槛（1.4.5 的研究进度前导字节），281 ↔ 282 曾被当成同一布局。

## 数据 ID

- **新增「油漆 / 射弹」页签**（页签现在是 NPC / Buff / 图格 / 墙 / 油漆 / 射弹）
  - 油漆：30 个油漆（`PaintID`）+ 2 个涂料（`PaintCoatingID`：夜明 / 回声），分组栏「全部 / 油漆 / 涂料」；
    详情列出「对应物品」，表格列 `ID / 图标 / 名称 / 对应物品 / 内部名`。
  - 射弹：1136 条，名称取游戏本地化名 `ProjectileName`（不落盘，换界面语言跟着变）；
    图标是图集首帧（1117 个，等比缩进 48px 框），表格列 `ID / 图标 / 名称 / 内部名`。
  - 与其它页签同一套：图标网格 / 表格视图、页面设置、右侧详情、**各自独立**的最近搜索。
  - 数据来源与再生成见 [`data/README.md`](../../data/README.md)（`paints.json` / `projectiles.json` / `projectile-atlas`）。
- **图格 / 墙中文名补齐 70 + 74 条**：名称解析链新增第 4 步「补齐表」（`data/tile-name-overrides.json`）。
  游戏里没有图例名 / 代表物品的那些（藤蔓、草丛、苔藓砖、未安全墙…）以前只能显示英文常量名，现在显示中文名；
  搜中文也能命中。

## 首页

- **内置指令卡全部改为默认手动执行**
  - 在线玩家 / Boss 进度 / 世界信息 / 我的背包 / 死亡次数 / Boss 战伤害进页面不再自动执行，
    按钮是 ▶「执行」；自己添加的卡片同样默认手动。
  - 「刷新全部」的语义收敛为「现在把可见的卡全跑一遍」：**包含设为手动的卡**（缺插件的卡也会重探一次）；
    模块页与鱼店的「刷新全部」只跑自动的。
  - 想让某张卡跟着页面自动跑：「管理卡片」→ 行尾「更多设置」→ 打开自动执行。
- **去掉「游戏时间」内置卡**：`/time` 与「世界信息」里的游戏时间重复。
  老布局升级时自动丢弃这张卡，不影响其余顺序与自定义卡片。

## 鱼店

- **搜索能按「商品实际发的东西」找**：命中字段增加编号（`serial`）、插件别名（`map`）、
  商品实际发放的物品名（中英文与内部名；`id > 0` 才参与，服务类商品借来的图标不参与，避免误伤）。

## 全局搜索

- **收录油漆 / 射弹两组**：射弹按本地化名检索，选中后跳「数据 ID · 射弹 / 油漆」并预填。

## 登录

- **未登录时不再自动弹登录框**：启动、会话过期、切换服务器后，即使本机记住过账密也**不主动弹框**，
  页面显示「请先登录！」占位卡，玩家点「登录」才弹（账密仍回填）。
  - 只读工具页（物品 ID / 数据 ID / 常用表格 / 存档 / 世界分析）**不进这条重登流程**：玩家可能只是来查物品或看存档。
  - 自动弹只保留给「执行指令时 token 失效」的被动重登；重登成功后原指令自动重试一次。
