# v0.1.0-rc.9 发布说明（2026-11-07，预发布）

> 单版本、面向玩家的发布说明（新增 / 改进 / 修复）。详细更新见 [changelog/v0.1.0-rc.9.md](https://github.com/hufang360/TShockWebUI/blob/master/docs/changelog/v0.1.0-rc.9.md)；
> 全量历史见 [changelog.md](https://github.com/hufang360/TShockWebUI/blob/master/changelog.md)。

一句话：侧栏多了一个全局搜索框（`Ctrl/Cmd+K`，一个框搜物品 / NPC / 指令 / 页面等），
指令小抄改成「单击一行就地展开详情 + 同前缀指令折叠」，详情抽屉只压暗内容区（左侧导航照常能点、切回来还在），
物品详情在别的页面直接弹框，货架顶上多了遮阳伞。

> 升级提示：无需改配置；「切页面回来详情还在」与搜索的「最近搜索」都只记在本机浏览器（清站点数据即回到默认）。

## 新增

- **侧栏全局搜索**：侧栏页头（「首页」上面）多了一个搜索框，`Ctrl/Cmd+K` 随时聚焦（侧栏收起会自动展开），
  手机在顶栏的搜索图标里。一个框搜物品 / NPC / Buff / 图格 / 墙 / 鱼店商品 / 指令 / 页面 / 物品集合，
  结果按分组列出来，每组前 3 条，想要更多点组标题右侧的「全部」去对应页面接着筛。
  **物品点一下就地弹详情**（不跳页，当前筛选和填了一半的指令都不会丢）；其余结果跳页时自动带上搜索词。
  键盘 `↑` / `↓` + `Enter` 选，`Esc` 清空收起；空词显示最近搜索；纯本地匹配，不发任何请求。
  「鱼店商品」没登录或插件没装时整组不出现；玩家名不参与搜索（由「玩家管理」页自己查）。
- **物品详情弹框**：在指令 / 数据 ID / 鱼店等页面点物品提示右上角的 ⓘ「物品详情」，不再跳到物品 ID 页，
  而是**就地弹框**显示（tips、词缀与标签广播、`/give`、合成 / 分解 / 掉落、Wiki 与复制）；弹框里再点材料会叠一层「返回」。
  物品 ID 页面内的可堆叠抽屉不变。

## 改进

- **指令小抄改版**：主表只剩指令 / 说明 / 权限三列（说明和备注合成一列），**整表按指令 a~z 排序**；
  **单击一行就地展开「详情行」**（指令语法、使用提示、别名、相关指令、数据 ID → NPC），再点收起，页面里不再有弹框；
  **同一前缀的指令默认折叠**（`/worldevent …`、`/group …`、`/give` 收起 `/item`、`/buff` 收起 `/gbuff`、
  `/tp` 收起 `tphere` `tppos` `pos` `tpallow`、`/death …` 等，点一下展开，搜索时自动展开）；
  行内悬停可**复制指令 / 执行指令 / 复制权限**（`allowServer=false` 与带占位符的参考行没有「执行」）；
  **只能在游戏内执行的指令标红**并在说明里写「仅游戏内」；搜索也匹配权限名。
- 指令小抄的分组合并：「账号（玩家自己）」+「用户账号」→「玩家账号」，「封禁」+「禁言 / 踢出」→「封禁」，
  「入侵」并进「世界事件」，`/itemban` `/projban` `/tileban` 挪到「封禁」。
- **详情抽屉不再挡住左侧导航**（鱼店 / 物品 ID / 数据 ID，桌面端）：遮罩只压暗内容区，
  左侧导航照常能点，所以抽屉开着也能直接切页面；点遮罩 / × / `Esc` 关闭。
  **切到别的页面再回来，详情还开着**（关掉后才不再弹）；手机 / 窄屏仍是原来的模态抽屉。
- 侧栏收起时，「展开侧栏」按钮浮在遮罩之上，不会被压暗或点不到。
- **鱼店**：货架顶上加了一圈蓝白遮阳伞，按透视散开、拉宽窗口也不变形；表格视图不画，
  「页面设置」里可以关掉（跟服务器分开记）。

## 修复

- **无 HTTPS（`http://IP:8080`）时所有复制按钮都没反应**：复制 ID / 名称 / 指令 / 执行结果 / 配方 / 权限命令全部静默失效，
  「指令小抄」里点复制还会报错。原因是 `navigator.clipboard` 只在 `https:` / `localhost` 存在；
  现在统一改成「优先 Clipboard API，不可用时退回 `execCommand('copy')`」，两条都失败才不显示「已复制」。
