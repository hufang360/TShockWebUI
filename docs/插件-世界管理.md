# 插件接入：世界管理（WorldModify）

> 模块 id `world`；侧边栏「世界管理」；入口在「设置 → 激活模块 → 世界管理」。
> 依赖 TShock 第三方插件 **WorldModify**（提供 `/wi`、`/bi`、`/relive`、`/cleartomb`）。

## 0. 插件依赖

| 项 | 值 |
| --- | --- |
| 插件 | WorldModify（简易世界修改器） |
| 插件版本 | **v1.6.7**（随 TShock 6.2.1 服务端验证） |
| 项目地址 | <https://github.com/hufang360/TShockWorldModify> |
| REST API | 无（只注册游戏内指令，WebUI 走 `/api/command` 的 rawcmd） |
| 探测 | 无 REST 端点（`/webui/meta` 也没有）→ 用**固定卡片的执行结果**判定：`/wi` 返回 `command_not_found` 即视为未安装（见 §3） |

## 1. 固定指令卡片

插件注册的指令（源码）：

```
Commands.ChatCommands.Add(new Command("worldinfo", WorldInfo, "worldinfo", "wi")   { HelpText = "世界信息" });
Commands.ChatCommands.Add(new Command("bossinfo",  BossInfo,  "bossinfo",  "bi")   { HelpText = "boss进度信息" });
Commands.ChatCommands.Add(new Command("relive",    Relive,    "relive")            { HelpText = "复活NPC" });
Commands.ChatCommands.Add(new Command("cleartomb", ClearTomb, "cleartomb", "ct")   { HelpText = "清理墓碑" });
```

| 卡片 | 指令 | 权限（TShock 节点） |
| --- | --- | --- |
| 世界信息 | `/wi` | `worldinfo` |
| Boss 进度 | `/bi` | `bossinfo` |
| 复活 NPC | `/relive` | `relive` |
| 清理墓碑 | `/cleartomb` | `cleartomb` |

卡片通过 **rawcmd** 以 token 用户所在组的身份执行，**权限仍由 TShock 判定、不提权**。

插件还注册了更多指令，可在「管理卡片」里自行添加为卡片：

| 指令 | 权限节点 | 说明 |
| --- | --- | --- |
| `/wm`（`/worldmodify`） | `worldmodify` | 主命令：简易世界修改器 |
| `/moon`（`/moonphase`） | `moonphase` | 月相管理 |
| `/ms`（`/moonstyle`） | `moonstyle` | 月亮样式管理 |
| `/boss`（`/bossmanage`） | `bossmanage` | Boss 管理 |
| `/npc`（`/npcmanage`） | `npcmanage` | NPC 管理 |
| `/igen` | `igen` | 建造世界 |

## 2. 权限不足怎么处理（重点）

`/relive`、`/cleartomb` 常被服主只授权给管理员组。普通玩家点这两张卡片时：

- 后端 `client.go` 把 TShock 的 `you do not have access to this command` 归类为 **`no_permission`**
  （`StatusNoPermission`），并给出**本地化 message**「权限不足，无法执行该指令」（原始英文文案也保留）。
- 前端 `CommandCard` 对 `status === 'no_permission'`：
  - **卡片保留**（不隐藏、不当成「插件未安装」）；
  - 在结果上方显示本地化提示 **`home.permissionDenied`**（「没有执行该指令的权限（请让服主授予）」）；
  - 屏蔽后端那条中文 message，避免与本地化提示重复；
  - 刷新按钮仍可用，玩家获得授权后点一下即可。
- 与「未安装插件」区分：插件缺失时 TShock 返回 **`command_not_found`**（`输入的命令无效…` / `Invalid command entered…`），
  不是 `no_permission`；首页内置卡片据此自动隐藏（见 §3）。

> 需要服主授权时，让对应用户组拿到对应节点即可：`/group addperm <组名> relive cleartomb`。

## 3. 插件探测（模块级提示）

WorldModify **没有 REST 端点**，无法像 PlayerManager / FishShop 那样「缺参数探一次」判定装没装，
所以探测走**固定卡片的执行结果**：

- 后端把 TShock 的「指令不存在」文案（`Invalid command entered…` / `输入的命令无效…`）归类为
  **`command_not_found`**（`server/internal/tshock/client.go` 的 `classifyOutput`），与参数写错的
  `command_error` 分开。
- 世界管理用**第一张固定卡片的只读指令 `/wi`** 做探测（`ModuleCardsPanel` 的 `pluginName` 参数，
  插件名来自 `MODULE_DEFS.world.pluginName`）：
  - `/wi` 结果 `command_not_found` → 判定插件未安装 → 页面顶部显示 **`Notice`「服务器未安装 WorldModify 插件」**
    （带「重新检测」按钮），与玩家管理 / 鱼店缺插件时的提示一致；
  - 4 张固定卡片统一改显示「插件未安装」，不再展示 TShock 原文（`输入的命令无效…`）与后端提示，
    避免「指令不存在」看起来像玩家输错；自定义卡片不受影响；
  - 「管理卡片」里固定卡片置灰并标「缺少插件」。
- **与权限无关**：`no_permission` 不算缺插件。TShock `Commands.HandleCommand` 先查指令是否存在、
  再查 `CanRun` 权限（源码已核实），所以「有指令但没权限」返回权限不足，只有插件没装才「指令不存在」。
  普通玩家把 4 张卡片都点一遍也不会被误报成未安装。
- 缺插件期间**自动刷新不再重跑**固定卡片（避免每次白跑必失败的指令）；点提示里的「重新检测」
  或顶栏「刷新全部」（强制刷新）会重跑 `/wi`。装上插件后提示消失、卡片恢复；成功后还会清掉其它固定卡片
  上一次的「指令不存在」结果，避免残留旧失败。
- 探测只在**登录后**、且有执行结果时生效：`/wi` 默认自动执行，进页面就会探一次；
  若把 `/wi` 切成「手动执行」，则要等第一次手动执行后才会给出提示。

「设置 → 激活模块 → 已适配」里世界管理也显示真实状态：复用最近一次 `/wi` 结果（没有就探一次，
与模块页共用同一个结果 key `world:fixed:/wi`），点面板右上角「重新检测」会强制重跑 `/wi`。
注意：连 `tshock.rest.command` 都没有的账号只会看到「无权限」，无法判断插件装没装（没有更可靠的上游接口）。
`docs/UI组件.md` 里的 `MODULE_DEFS.world.cards` 与这里保持同步。

## 4. 自动执行 / 手动执行（v1.4）

- `/relive`、`/cleartomb` **默认手动执行**：进入模块不自动跑，「刷新全部」也不跑，只能点卡片自己的按钮。
- 右上角图标随语义变化：自动卡片是刷新图标（`RefreshCw`），手动卡片是**播放图标（`Play`，aria-label「执行」）**。
- 偏好存本机 `tswui:autoExec`（`lib/autoExec.ts`，key 如 `world:fixed:/relive`，默认值由模块定义给出）。
- 「管理卡片」弹框（`ModuleCardManagerDialog`，与首页 `HomeCardManager` 同款交互/样式）里可逐张切「自动执行」。
- **页头收进顶栏**：页内不再有标题 / 描述行；「上次刷新 / 管理卡片 / 刷新全部」在内容区顶栏右侧（`TopBarActions` + `IconAction`），
  页面说明收进顶栏的 ⓘ 图标（`InfoPopover`）。

## 5. 追加指令卡片

世界管理允许在固定 4 张卡片之后**自行添加指令卡片**：点「管理卡片」在弹框底部填名称 + 指令即可（可删除）。
数据存 `tswui:moduleCards` 的 `byServer[serverId].world`（见 `lib/moduleCards.ts`）；自定义模块的卡片也存这里。
首页卡片同样有「自动执行」开关（`HomeCardManager`）；鱼店右侧卡片仍为全自动（只读指令）。
