# v0.1.0-rc.9 更新日志（2026-11-07）

> 单版本、按功能模块的详细更新。对外发布说明见 [`release/v0.1.0-rc.9.md`](../release/v0.1.0-rc.9.md)；全量历史见根目录 [`changelog.md`](../../changelog.md)。

本次重点：**「指令小抄」改版**（单击看详情、同前缀指令折叠）、**详情抽屉不再挡住左侧导航**
（鱼店 / 物品 ID / 数据 ID，且切回来还在）、**图鉴以外的物品详情改成弹框**、**货架顶上多了一圈遮阳伞**。

---

## 指令小抄：单击看详情、同前缀指令折叠

- 主表只剩**指令 / 说明 / 备注**三列：不再显示「规范写法」那一行、不再有操作列，也没有单独的分组标题行
  （分组标题改成折叠行的「说明」，例如 `/worldevent` → 世界事件）。
- **单击任意一行**弹出居中的「指令详情」弹框（`max-w-xl`，打开时焦点在弹框本身、不落在复制键上）：
  指令（等宽加粗、悬停出现复制）、说明、使用提示、指令语法、权限（悬停复制）、别名；
  底部一个「填入指令浮窗」（参考行没有底部栏）。详情里不再显示「执行位置」与「分组」，文字也不再是灰色。
- **同一前缀的指令默认折叠**：`/worldevent invasion …`、`/worldmode …`、`/time …`、`/spawnboss …`、`/warp …`、
  `/region …`、`/itemban …`、`/projban …`、`/tileban …`、`/group …`、`/tp …`、`/death …` 等收成一行，点一下展开；
  展开后子行显示完整指令并缩进一级；搜索时自动展开。
- **只能在游戏内执行的指令**（`allowServer=false`）指令文字标红，备注写「仅游戏内」；多子项的只在折叠行标（子行不重复）。
- 分组合并：「账号（玩家自己）」+「用户账号」→ **玩家账号**；「封禁」+「禁言 / 踢出」→ **封禁**；
  去掉「在数据 ID → NPC 里查更多」入口。
- 「权限配置」只剩两行折叠组：TShock 权限两条并进 `/group`，四条插件权限并进 `hf 常用`。
- 表格斑马纹（与物品 / 数据 ID 表格同一套），三列都单行、超出省略；指令列超过 22 字符时悬停显示完整指令。
- 使用提示与指令语法都按句换行显示（`whitespace-pre-line`）。

## 详情抽屉：只遮内容区、不再挡住左侧导航

- 适用范围：鱼店商品详情、物品 ID 详情（可堆叠抽屉）、数据 ID 详情、指令小抄的分组抽屉。
  （指令小抄的指令详情本次已改成居中弹框，不再走这套遮罩。）
- 以前的详情是**模态抽屉**：弹出就把整页压暗（包括左侧导航），想切到别的页面得先关掉；
  关掉再回来还得重新翻货架找那件商品。
- 现在（桌面端）遮罩**只盖内容区**（半透黑 50%，**不模糊**），**左侧边栏不被遮住**：抽屉开着也能直接点导航切到指令 / 首页。
  外观仍是原来的右侧整高抽屉；侧栏收起时，「展开侧栏」按钮浮在遮罩之上。
- **切到别的页面再回来，刚才打开的详情还在**：鱼店商品（数量 / 参数回默认）、数据 ID（`{ kind, id }` 记在页面模块内存里）、
  物品 ID 都接着开；关掉之后就不会再自动弹开。
- 关闭：点遮罩、右上角 × 或 `Esc`（点导航不算关闭）；「建筑预览」的放大图叠在它上面时，`Esc` 只关放大那一层。
- 手机 / 窄屏保持原样：模态抽屉，点抽屉外 / 下滑关闭。
- 详情里的内容本身都没变（鱼店的价格 / 解锁 / 别名 / 限购 / 购买时机 / 检查 / 备注、参数与数量、购买结果、建筑预览）。
- 货架还没拉回来时，恢复出来的详情**不允许购买**（此时商品编号可能已经指向别的商品，插件是按配置下标发货的）。

## 物品详情：图鉴以外的页面改成弹框

- 以前在指令 / 数据 ID / 鱼店等页面点物品提示右上角的 ⓘ「物品详情」，会**跳到「物品 ID」页**再打开抽屉，
  当前筛选与填了一半的指令都丢了。
- 现在**就地弹出物品详情弹框**，内容与图鉴里那份完全一样（tips、词缀与标签广播、`/give`、合成 / 分解 / 掉落、
  前往 Wiki / 复制名称 / 复制 ID）；弹框里再点配方材料 / 掉落物的 ⓘ 会**叠一层**（左上角「返回」）。
- 切到别的页面会自动关掉这个弹框；「物品 ID」页面内的行为不变（仍是可堆叠的右侧抽屉）。

## 鱼店：货架区顶上多了一圈遮阳伞

- **蓝白相间**的布条排成一整片，每条下端收成半圆；最左 / 最右那一条是灰色（篷布绕到背面的那一截）。
- 布条会**按透视散开**：中间几条竖直、越靠两端越往外斜，像站在摊子正前方看那圈裙边；
  每块布两侧略暗、下端再压一截，看着是一片厚布。两端留一点空白，不会切出半条碎布。
- 布条尺寸固定（蓝 33px / 白 24px），窗口拉多宽都不会变胖。
- 表格视图里不画（数据表上面顶块篷布没意义）；「页面设置」里可以关掉（`遮阳伞`），跟服务器分开记。
