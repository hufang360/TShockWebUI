# 功能：搜索记录（统一规则）

文档版本：1.2
相关代码：`web/src/lib/searchHistory.ts`（规则与纯函数）、`web/src/hooks/useSearchHistory.ts`（localStorage 绑定）、
`web/src/components/SearchInput.tsx`（搜索框内嵌的「最近搜索」下拉框）
使用页面：物品图鉴（`ItemsPage`）、数据图鉴（`CodexPage`）、玩家管理（`PlayerManagerPage`）

> 所有页面的「最近搜索 / 最近查询」都遵守本规则，**不要再各自写一套**。新增带搜索的页面请复用上面三个文件。

---

## 规则

| 规则 | 值 | 说明 |
| --- | --- | --- |
| 最多保留 | **10 条** | `SEARCH_HISTORY_MAX`；超出丢最旧的 |
| 窄区域最多显示 | **5 条** | `SEARCH_HISTORY_NARROW_MAX`；按展示容器宽度判定（< 420px 视为窄） |
| 顺序 | 最新在前 | 再次搜索已有词会把它提到最前，不重复 |
| 去重 | 忽略大小写 | `Zenith` 与 `zenith` 视为同一条 |
| 存储 | localStorage | 仅本机；不参与服务端、不上传 |
| 过滤空值 | 是 | 空白字符串不进记录 |

纯函数（可单测）：

- `addSearchHistory(list, query)`：加入一条，返回新数组。
- `sanitizeSearchHistory(value)`：从持久化数据恢复（丢非法项、去重、截断到 10）。

## 展示方式：统一的搜索框下拉框

四个页面（物品图鉴 / 数据图鉴 · NPC / 数据图鉴 · 图格墙 / 玩家管理）都用 `SearchInput` 的 `history` 属性，
在输入框下方弹出「最近搜索」下拉框。

**打开时机**（`v1.35` 起）：

- **聚焦本身不弹**——页面进入会自动聚焦搜索框，如果聚焦就弹，一进页面就有一层菜单盖住结果；
- **打字时**才弹，可边输边筛（像代码补全），点一下填入；
- 想不输入就看历史：点输入框右侧的**历史图标按钮**（`History`）展开 / 收起（`historyToggle`，默认开）；
- 点输入框外面 / Esc / 选中一条 / 点清空（✕）都会收起。
- 宽区域最多列 10 条，**窄区域（容器 < 420px）只列前 5 条**（`SearchInput` 自己量宽度）。

需要的旧行为（聚焦即弹）显式传 `historyOnFocus`；没有 `history` 的输入框不受影响。

`history` 里除了搜索记录，也可以混入其它候选（如玩家管理把**在线玩家**拼在最近查询后面），
用 `historyHeader` 改下拉框顶部小标题（默认「最近搜索」）。

## 各页面

| 页面 | 存哪 | 记什么 |
| --- | --- | --- |
| 物品图鉴 | `tswui:dex:searchHistory` | 搜过的词（防抖后） |
| 数据图鉴 · NPC | `tswui:npcs:searchHistory` | 搜过的词（防抖后） |
| 数据图鉴 · 图格 / 墙 | `tswui:tiles:searchHistory` | 搜过的词（防抖后） |
| 玩家管理 | `tswui:moduleState` 里 `players` 模块的 `recent`（按服务器分开） | 查询过的玩家名（下拉框里在线玩家拼在后面） |

> 数据图鉴按数据源分开记（`CodexPage` 的 NPC / 图格 / 墙），切换数据源时下拉框里的建议也随之切换。

> 物品图鉴原先还有一排「预制 tag（匣 / 宝藏袋）」，已去掉，只保留最近搜索。
