# v0.1.0-rc.10 发布说明（2026-11-14）

> 单版本、面向玩家的发布说明（新增 / 改进 / 修复）。详细更新见
> [`changelog/v0.1.0-rc.10.md`](../changelog/v0.1.0-rc.10.md)；全量历史见根目录 [`changelog.md`](../../changelog.md)。

一句话：侧栏搜索变成一个真正能用的命令面板——结果可以展开、指令可以直接执行，
再加上「常用表格」页（世界种子 / 词缀 / 常用链接）。

> 升级提示：插件与网页版本号都是 `0.1.0-rc.10`，插件 DLL 同时更新（本轮插件代码没有变化，仅版本号跟随）。
> 老地址 `#/slice`（精灵图）已移除，会回到首页。

## 新增

- **「常用表格」页（`#/ref`）**：指令 + 世界种子 + 词缀 + 常用链接 四张表，侧边栏在「数据 ID」下一行。
  - 世界种子：特殊 9 个 + 秘密 37 个合成一张表，支持逗号分隔的多种写法，点整行看详情，详情里能一键把 `WorldModify` 开关填进浮动终端。
  - 词缀：96 条（含 19 个饰品词缀），伤害 / 速度 / 暴击 / 魔力 / 大小 等列全，增值绿、减值红，可按武器 / 配饰 / 职业过滤。
  - 常用链接：wiki（中文界面走中文站）、TShock 仓库与发布页、存档 / 地图 / 材质包工具链、社区论坛。
  - 旧地址 `#/tables`、`#/commands`、`#/spawn` 都落到本页。
- **全局搜索里直接执行指令**：搜索框输入一整行指令（`/help 4`、`.wm find 生命水晶`）会给出
  「执行指令：…」一行，回车就执行，结果留在弹框里；`/`、`.` 前缀都能用，`/help`、`.help` 也能直接搜到该指令。

## 改进

- **搜索结果可以「更多」展开**：每组末尾的「更多」带命中数，点进去在弹框内看前 20 条；超过 20 条才跳页并带上搜索词。
  `Esc` 回一级、再进同一组回到原来那一行；清空搜索词或关掉弹框即忘，重开是空面板。
- **指令回车即执行，不再被「必填参数」拦住**：`/help`、`/help 2` 都能跑；缺参数时 TShock 的用法提示直接显示，
  并给「查看用法」/「填入终端」两个退路。结果用富文本渲染（彩色文字、物品图标与「指令」页一致）。
- **键盘操作全部写在底栏**：行内不再有复制 / 执行图标按钮。`⏎` 打开 / 查看 / 执行 / 填入终端、`⌘/Ctrl+C` 复制 ID 或指令，
  键帽用符号与图标，中文界面里不再夹英文单词。
- **仅游戏内指令一眼可辨**：搜索里标红 + 右侧「仅游戏内」，回车只带你去看用法，不会假装能执行。
- **详情弹框统一**：种子 / 词缀 / 指令详情都走居中弹框，「填入浮动终端」后自动关闭，不再挡住终端。
- **焦点样式与下划线 tabs 对齐 shadcn**：键盘导航才出现描边，鼠标点击不再有粗框；tab 下划线更细、切换不跳字。

## 修复

- **弹框横向溢出**：搜索面板底部提示条用负外边距做通栏，会把整个弹框撑宽、冒出横向滚动条；现在通栏分割线不再撑宽布局。
- **二级状态不再「复活」**：清空搜索词或关掉弹框后再打开，不会再自动跳回上次展开的那一组。
- **「指令小抄」tab 改名「指令」**，与侧边栏「常用表格」的导航名一致，不再出现同一个页面三个叫法。
