# 页面 - 查看世界（`#/wld`）

> 代码：`web/src/pages/WorldPage.tsx`（导入 / 导出外壳）+
> `web/src/components/world/WorldPanel.tsx`（世界概览 + canvas 缩略图）+
> `web/src/lib/save/`（解析与渲染：`worldFile.ts` / `worldThumb.ts` / `worldColors.generated.ts`）+
> `web/src/lib/worldPage.ts`（缓存 / 错误文案 / 字段映射）。
> 格式事实见 [`技术事实.md`](技术事实.md)「世界文件（.wld）」。

## 定位

**公开工具 + 纯本地**：本地 `.wld` 世界存档查看器。

- 侧边栏「世界 › **查看世界**」，排在「世界管理」（WorldModify 插件模块）**之前**。
- **文件不上传服务器**：头部解析、图格解码、缩略图渲染全部在浏览器里完成（无接口、无登录、无插件依赖）。
- 只读：不改动任何文件，也不写入任何存储（导出是浏览器本地生成）。

## 支持的文件

| 文件 | 说明 |
| --- | --- |
| `.wld` | Terraria PC 世界存档 |
| `.wld.bak` | 游戏 / TShock 保存时的上一份备份（**同格式**） |
| `.wld.bak2` | 更早一份备份（**同格式**） |

文件选择框 `accept=".wld,.wld.bak,.wld.bak2,application/octet-stream"`；也可以把文件**拖进整页**。
不做客户端扩展名拦截：改名后的文件照样能解析，真正判定看文件头。

范围：release **140 … 326**（1.2.4 ~ 1.4.5.8）。更旧的是 V1 格式（没有 `relogic` 文件头），
提示「世界文件版本过旧（…）：请在游戏里打开并重新保存一次」；更新的提示「高于本工具支持的版本」。
另外有个 64 MB 的保险丝：明显不是世界存档的大文件直接拒绝（不做解析、不卡界面）。

## 界面结构

1. **顶栏右侧**：`导出图片`（`IconAction` + `Camera`，与「查看存档」同款；渲染完成后才出现）。
2. **工具卡**（一行）：`导入 .wld`（主按钮，解析中显示 Spinner）+ **`来个 Demo`**（outline，`Sparkles`）+ `导出 .wld`
   （导入过才有）+ 右侧说明（格式；解析中变成「正在渲染缩略图… N%」）。文件选择框隐藏（`data-testid="world-wld-input"`）。
   - **来个 Demo**：拉取自带的一张**空白世界**（`web/public/demo/world.wld`，4200×1200，只有天空 / 地表 / 石头 / 地狱，
     81 KB、release 228），走**完全相同的本地解析**流程，导出 `.wld` 也能把这份 demo 存下来。
     资源缺失时给一句「Demo 世界加载失败」，不影响手动导入。
3. **本地说明**（`Alert variant="info"` + `ShieldCheck`）：**明确写清「全部在你的浏览器里完成、不会上传服务器」**。
4. **空态**：`Empty` + 「还没有选择世界存档」；整页是拖放区（`data-testid="world-drop"`）。
5. **错误**：`Alert variant="destructive"`，文案直接用解析器给的具体原因（如「不是有效的 Terraria 世界存档: 文件头不匹配」）。
6. **世界概览**（`WorldPanel`）：
   - **缩略图**：`<canvas>`。位图按「像素预算」尽量做到 **1 图格 = 1 像素**（小 / 中世界原尺寸，
     大世界 2 图格/像素 = 4200×1200）；屏幕上按容器宽度平滑缩放，**点击可打开 1:1 大图**（可滚动看清方块）。
   - **标题行**：世界名 + 徽章（难度 / 大小 / 邪恶 / 困难模式 / 已收藏 / 本地导入）。
     - 难度：旅途 / 普通 / 专家 / 大师；大小按图格宽（≤4200 小 / ≤6400 中 / 其余大）；邪恶：腐化 / 猩红。
   - **特殊种子**（有才显示）：醉汉世界 / 值得一玩的世界 / 十周年纪念 / 饥荒联动 / 蜜蜂世界 /
     颠倒世界 / 无陷阱世界 / 天顶世界 / 空岛世界。
   - **字段网格**（2 / 3 / 4 列自适应，值空则不显示该行）：尺寸 `宽 × 高`、种子、创建时间、最后游玩、
     出生点、地牢、存档版本（release）、保存次数（revision）。
   - **Boss 进度**：已击败的 Boss / 入侵徽章；一个都没有时显示「还没有击败任何 Boss」。

## 导出

- **导出 .wld**：把导入时的原始文件原样下载（浏览器 object URL）。
- **导出图片**：把渲染好的缩略图用 `canvas.toBlob('image/png')` 编码，下载 `<世界名>.png`
  （小 / 中世界是原尺寸 1 图格 = 1 像素；大世界 4200×1200）。
  与「查看存档」的导出图片同一套思路：位图已经算好，只做编码 + 下载，**不经过任何服务端**。

## 时间显示（重要）

存档里的创建 / 最后游玩时间是 `.NET DateTime.ToBinary()` 记录的**本地时间**（保存时所在时区），
解析器按 UTC 解释、前端按 UTC 原样截取 `YYYY-MM-DD HH:mm`，即**游戏里看到的墙上时间**。
刻意不做时区换算——否则玩家会比游戏里看到的时间早 / 晚几个小时。
（ticks 是 100ns 单位、约 6.2e17，超过 double 精度，解析时用 BigInt。）

## 缩略图怎么画（浏览器里）

- 采样：先按**像素预算**（默认 8M 像素 ≈ 4200×1200）算缩放比
  `res = max(1, ceil(sqrt(宽×高/预算)), ceil(宽/8192), ceil(高/8192))`，
  即「能不缩小就不缩小」；每块取**优先级最高**的颜色：图格 > 液体（≥64/255）> 墙 > 深度背景。
- 深度背景（与 TEdit 小地图一致）：`y < 80` 太空 / 最下 192 行地狱 / 岩石层以下 / 地表以下 / 天空。
- 只读图格段一次（`for x { for y }`，RLE 同列向下重复），**按列分块**（默认每 128 列
  `await` 让出主线程一次 + 回调进度），大世界也不卡界面；内存只有缩略图位图（1280px 宽 ≈ 1.8 MB）。
- 颜色表：`web/src/lib/save/worldColors.generated.ts`（`node tools/gen-world-colors.mjs` 生成，别手改）。
- 性能实测：15.4 MiB / 8400×2400 的真实世界，解析 <1ms、渲染 **4200×1200** 位图 ≈**130ms**（V8）；
  输出大小与之前 1200px 版本几乎相同（耗时在图格扫描，不在输出像素数）。
- 为什么不再用 `image-rendering: pixelated`：屏幕上永远是「原图缩小」，平滑降采样比最近邻更接近游戏地图的观感；
  需要逐格看清时点开 1:1 大图。
