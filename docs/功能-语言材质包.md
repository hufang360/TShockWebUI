# 功能-语言材质包（Terraria 语言 Resource Pack）

> 当前行为说明。设计取舍与调查过程见 [`计划-语言材质包.md`](计划-语言材质包.md)。
> 入口：**设置 → 语言材质包**（登录 / 未登录都可用，纯本机显示偏好）。

---

## 1. 是什么

把 Terraria 的**语言材质包**（创意工坊 `Resource Pack`，`Content/Localization/**` 里的文本）
套到 WebUI 的显示文本上：物品名、物品提示、NPC / Buff / 词缀 / 图格名、配方组名。
**只影响显示**，不改服务器、不改指令执行、不改物品 ID，也不处理材质包里的贴图 / 音效。

内置作者自制的「1.4.2 汉化修正」包（`data/langpacks/2447707451.zip`，默认**不启用**）；
其它包由用户自己上传（如 Potralia 的个人汉化）。

## 2. 支持的包格式（实测）

- 创意工坊下载的 zip（可带 `<SteamId>/depots/105600/<ManifestId>/` 包装层），
  也兼容「包根直接是 zip 根」的情况：找**层级最浅**的 `pack.json` 当包根。
- 本地化文件读 `Content/Localization/<culture>/*.json` 或 `*.csv`：
  - **JSON（1.4.4+）**：`{"ItemName":{"Ruby":"红玉"},"ItemTooltip":{...}}`；
  - **CSV（1.4.2）**：`key,translation` 扁平行（`ItemName.Ruby,红玉`，带 BOM）。
- 只收白名单分类：`ItemName` / `Prefix` / `NPCName` / `BuffName` / `MapObject` / `Misc` /
  `LegacyMisc` / `ItemTooltip` / `CommonItemTooltip` / `LegacyTooltip` / `GameUI` /
  `LegacyInterface` / `PaintingArtist` / `BuffDescription`。
- 其余文件（图标、`.DepotDownloader/`、`Content/Itеms.json` 这类仿冒文件）**一律忽略**。

## 3. 应用规则

- **按界面语言取**：只合并当前界面语言（`zh-Hans` / `en-US`）对应的词条；
  包里没有当前语言时，该包显示「当前语言无文本」且不参与合并（不混语言）。
- **列表顺序 = 优先级**：同一个 `(分类, key)` **靠上的包胜出**；不同 key 叠加。
- 名字类（物品 / NPC / Buff / 词缀 / 图格 / 配方组）在 `loadDataset()` 里一次性解析；
  搜索、指令补全、图鉴、数据 ID 页、`[i:...]` 图标提示都自动跟着变。
- **物品提示**：有材质包时按合并后的本地化表**运行期重算**（`web/src/lib/itemTips.ts`，
  规则与 `tools/gen-item-stats.mjs` 一致）；没有材质包时仍用构建期算好的
  `item-tips.<culture>.json`（行为与以前完全相同）。
- 提示里的 `[c/RRGGBB:文本]`、`[i:ID]` 按游戏富文本渲染（颜色 + 物品图标）；
  `{$分类.key}` 与 `{InputTrigger_X}` 已展开，不会露出占位符。

## 4. 存储

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 已导入包的词条 | **IndexedDB** `tswui` / `languagePacks`（主键 = zip 的 SHA-256） | 只存当前浏览器；同一内容重复上传 = 覆盖更新 |
| 启用状态与顺序 | **localStorage** `tswui:languagePacks` = `{ order, enabled }` | 纯界面偏好 |
| 内置包 | 随前端产物下发，启用时才 fetch + 解析 | 不写 IndexedDB，不可删除 |

IndexedDB 不可用（隐私模式 / 被禁用）时：页面提示「本浏览器无法保存材质包」，
本次会话仍可临时应用，关闭后丢失；不会静默失败。

## 5. 设置页交互

- 「上传 .zip」：解析成功 → 追加到列表**末尾**并启用（已有包的优先级不变）；失败按原因提示
  （不是 ZIP / 缺少 `pack.json` / `pack.json` 损坏 / 没有 `Content/Localization` / 文件过大 / 不支持的压缩）。
- 每行：拖拽或 ↑↓ 调顺序、开关启用、删除（内置包不可删；删除需二次确认）。
- 标签：`内置`、`1.4.2 旧格式`（CSV）、`当前语言无文本`；行下方显示作者 · 包版本 · 词条数
  （物品名 / 提示 / NPC）。
- 顶栏提示：「列表靠上的优先；相同条目以靠上的为准。只影响本机显示文本。」
- 勾选 / 排序 / 删除后**立即重新加载数据集**（不刷新页面）。

## 6. 限额与错误

| 限制 | 值 |
| --- | --- |
| zip 大小 | ≤ 20MB |
| 条目数 | ≤ 2000 |
| 单个文件解压后 | ≤ 8MB |
| 解压总量 | ≤ 32MB |
| zip64 / 加密 zip / 非常见压缩方式 | 不支持，给明确错误 |

## 7. 不做

- 不处理材质包的贴图 / 音乐 / 图集（图标来自项目自建图集）。
- 不上传服务器、不写服务器磁盘、不新增 `/api/*`。
- 不改 TShock / 权限 / 指令执行。
- 不按服务器区分（语言包是本机显示偏好，切换服务器不影响）。

## 8. 验证

- `web/src/lib/itemTips.realdata.test.ts`：6195 件物品 × 中英两种语言，运行期重算与构建期 `item-tips` **逐行完全一致**。
- `web/src/lib/languagePack/languagePack.test.ts`：zip（store / deflate）、CSV（BOM / 引号 / 逗号）、
  JSON、白名单与仿冒文件忽略、错误码、多包优先级与文化过滤。
- `web/src/lib/languagePack.integration.test.ts`：真实内置包与 JSON 包 → `loadDataset`，
  验证 NPC / 物品名 / 提示（含 `{$}`、`{InputTrigger}` 展开与颜色标签保留）。
- `web/src/components/settings/LanguagePackSection.test.tsx`：上传入口、开关、排序、删除、语言提示、存储不可用提示。
- 实测：Potralia 包解析 ~11ms、应用后重算 6049 件提示 ~40ms，无残留 `{$` / `{InputTrigger_`。
- 人工：已在 **18081 挂载式开发容器**里目视通过（上传 / 勾选 / 排序、物品名与提示变化、颜色与图标正常）。
