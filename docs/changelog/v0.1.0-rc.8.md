# v0.1.0-rc.8 更新日志（2026-11-04）

> 单版本、按功能模块的详细更新。对外发布说明见 [`release/v0.1.0-rc.8.md`](../release/v0.1.0-rc.8.md)；全量历史见根目录 [`changelog.md`](../../changelog.md)。

本次重点：**语言材质包**、**「指令」页并入聊天**、**卡片自由排布并按服务器记忆**、
**物品 / 数据 ID / 鱼店详情与表格翻新**，以及新服一键配置的 `/web init`。

---

## 语言材质包（新）

- 设置里新增「语言材质包」：上传创意工坊的语言包 `.zip` 后，**物品名、物品提示、NPC / Buff / 词缀 / 图格名、配方组名**
  都会改用包里的文本；提示里的颜色和物品图标也按游戏样式显示。
- 可以同时启用多个包，**列表靠上的优先**（同一条目以靠上的为准）；拖拽或 ↑↓ 调顺序，勾选 / 排序 / 删除后立即生效。
- 支持新版 JSON 包和 1.4.2 的旧 CSV 包（旧包会标出来，缺的条目自动回退官方文本）。
- 数据**只存在当前浏览器**，不上传服务器；只影响显示，不影响指令执行与权限。
- 内置作者自制的「1.4.2 汉化修正」包，设置里可直接勾选（**默认关闭**）。
- 顺带修正：钩爪类物品的提示从「按键发射抓钩」改成「按抓钩键发射抓钩」。

## 指令页：指令与聊天合一

- 一个输入框：`/` 开头是执行指令，其它内容直接发到游戏内聊天（带 `[WebUI] 玩家名:` 前缀）。
- 宽屏左右两栏（左边结果、右边服务器动态），**中间分隔条可拖**，双击恢复 65% / 35%，比例会记住；
  手机上是顶部「指令结果 / 聊天」切换，切走再回来聊天记录还在。
- 侧栏的「聊天」页已移除；老地址 `#/chat` 仍可用，会落到指令页并打开聊天。
  首页「最新动态」右上角的箭头现在也跳到指令页（手机上顺带切到聊天），发言需要已登录（走信使插件）。
- 输入框上方新增「发送内容预览」：物品标签会画成图标，聊天会显示实际带上的前缀。
- 结果栏底部统一放「展开全部 / 折叠全部 / 清空结果」；往上回看时浮出「↓ 最新」，点一下回到底部。
- 页头显示「上次刷新 · 游戏内时间」，聊天栏底部显示世界名 / 难度 / 天气。
- 工具面板收成「指令库 / 物品」两个入口 + 底部图标 tab；新增常用指令、`插入ID` / `插入标签` 开关，
  收藏 / 历史 / 物品条目改成整行；会记住上次停留的 tab、搜索词与滚动位置。
- 右下角浮动终端：输入框与发送键并成一行，去掉分割线与「清空」按钮。
- 修复输入框「幽灵文字」错位、以及长文本时底部横向滚动条盖住输入框的问题。

## 卡片与首页

- 长结果超过 20 行改为框内滚动（细滚动条，鼠标移入才显形），不再把卡片撑到一屏高。
- 手动执行的卡片左下角显示「执行于 …」，**超过一天变警告色**（悬停说明可能已过时）；结果会存在本机，
  刷新或重开标签页后仍在；鱼店的手动卡片统一成 ▶「执行」。
- 首页「最新动态」更紧凑：去掉世界名和日期分隔线，只显示最近 6 条 + 世界状态 / 刷新时间。
- 每张卡片都能选**小 / 大 / 右栏**三档尺寸、可拖拽排序，**按服务器分开保存**；
  首页默认顺序有调整（没手动排过的会换成新默认，排过的保持原样）。
- 「管理卡片」抽屉改成一行一张：行内依次是 **尺寸 → 自动执行 → 是否显示**，整行都能拖，
  行尾菜单可上移 / 下移 / 复制指令 / 删除；页脚有「添加卡片」和「恢复默认」。
- 页面说明改成内容区顶部的一张说明卡（点标题旁 ⓘ 开关，关过就不再自动弹）；
  抽屉里的「使用说明」可收起；世界管理 / 自定义模块的卡片现在也能隐藏。
- 顶栏新增浮动终端入口；快捷入口换成「路标」图标。

## 物品与物品详情

- 物品提示右上角新增 ⓘ「物品详情」，在图鉴里就地打开抽屉、在别处跳到图鉴再打开；
  全站同时只显示一个物品提示，快速滑过不会叠成一堆。
- 物品详情的「复制 ID / 复制名称 / 前往 Wiki」统一到底部操作区；提示（tips）占满整行。
- 合成分区统一改名为 **「合成」**（这件物品怎么来的）和 **「作为材料」**（它能拿去做什么）；
  微光分解挪到「微光嬗变」末尾；合成记录外观与指令条目统一。
- 「词缀」分区改为总是显示，标题随物品能否有词缀切换「词缀 / 物品标签」；
  下拉条目带词缀 ID 与评分，最佳词缀高亮；标签框可一键复制或**广播到游戏内**；
  从带词缀 / 数量的物品标签点进详情会自动对上（不再在名称后写 `x10`）。
- 物品 ID 与数据 ID 的表格：表头吸顶修正、列名统一为 `ID`、整行可点打开详情；
  物品 ID 表格里的图标也能悬停出提示。

## 数据 ID

- NPC 详情顶部改成一行的 `#4 克苏鲁之眼`，并显示 `/sb`、`/tpnpc` 认的英文名。
- NPC 的「召唤指令」合并成「相关指令」：可直接填进终端、收藏或复制；按 NPC 类型给出
  `/spawnboss`、`/sb all`、`/give <召唤物>`、`/sm`、`/tpnpc`、`/renameNPC`、`/npc`，
  以及地牢 NPC 的 `/setdungeon`、`/wm dungeon`。
- 数据 ID 不再探测权限：未登录也能看到全部 NPC 指令。
- Buff 详情的「增益指令」、物品详情的「物品给予指令」也统一改叫「相关指令」，样式与操作一致。
- 数据 ID 的 NPC 表格最后一列改为英文名（英文界面显示内部名），并支持大屏两列表格；
  数据源 Tab 跟着页面滚动，只把搜索行和筛选吸在顶栏下面。

## 鱼店

- 新增「全部 / 买过 / 收藏」三个页签：「买过」「收藏」只存本机，按商品内容识别（服主改名也能认出来），
  整件下架会显示「已下架」；旧版的「最近购买」记录会自动接过来。
- 新增「图标大小」三档（小 32 / 中 48 / 大 64，默认大）：中 / 大尺寸下商品站在「货架板」上，
  编号像价格标签；页面设置里可关掉层板，只剩纯网格。
- 建造类商品（小房间 / 鱼池 / 钓棚 / 刷怪场）详情多一张**建造范围示意图**，可放大查看。
  这张图需要**新版鱼店插件**，旧版不显示，其它功能不受影响。
- 商品详情新增「广告到游戏内」：把 `#编号 [物品] = [价格]` 发到聊天，价格用插件配置里的原文。
- 右侧新增「重载配置」卡片（`/fish reload`，需服主权限）：默认隐藏、不自动执行，在「管理卡片」里打开；执行成功会自动刷新货架。
- 页面设置 / 全屏挪到顶栏右侧；工具条排版跟「物品 ID」一致；表格加斑马纹、名称列显示词缀、表头吸住。

## 界面统一与小修

- 全站「只有图标的按钮」统一成三档尺寸，颜色、形状一致，并都带悬停说明。
- 服务器弹框改名「TShock服务器」；已连通时在信号图标旁显示实测延迟（如 `42 ms`）。
- 修正：自定义模块「使用说明」开头出现 `NaN`、指令卡片页头图标大小不一致、鱼店右栏卡片被压扁、
  货架最后一行板线被容器切掉等。

## 信使插件 / 新服配置

- 新增 `/web init`：一条指令写好推荐的 REST 配置（含更合理的建令牌限流），并给默认注册组补上
  `tshock.rest.useapi`、`tshock.rest.command`、`webui.use`、`webui.request.use`。
  幂等、只升不降，管理类权限不会自动发给默认组；`RestApiEnabled` 改动需重启 TShock。
- 启动日志不再被世界加载冲掉；缺权限或 REST 没开时会直接提示去执行 `/web init`。
- 即使打开 `LogRest`，`/webui/*` 也不会把参数（secret、聊天内容、申请物品）写进日志。
- 设置页的「信使插件诊断」会提示新服执行 `/web init`；新增「WebUI 插件权限」文档。

### 升级提示

- 这是**预发布**版本：Docker 只提供 `0.1.0-rc.8` 标签，不会更新 `latest`。
- 鱼店的建造范围示意图需要同时升级鱼店插件；语言材质包只影响显示，数据只存在浏览器。
- 从 rc.7 升级后，如果从没手动调整过首页卡片顺序，第一次打开会换成新的默认排布。
- 真实客户端相关的待验证项（`.plr` / `.wld` 编辑结果、物资申请「在线发放」）见仓库的 `docs/验收清单.md`。
