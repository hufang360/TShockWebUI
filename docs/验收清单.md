# 验收清单（需要真实游戏 / Windows 的部分）

> 这里列的每一项**都还没被验证**，因为需要的环境（真实游戏客户端、Windows、改版服务端）不在开发机上。
> 每条都给了「怎么做、看什么、算通过」——照做就能把对应 TODO 项从「待验证」变成「已验证」。
> 代码侧的等价证据见 [`记录-实现与验收.md`](记录-实现与验收.md)（真实存档 195 项断言、写回逐字节不变等）。

## A. 「玩家存档」编辑结果（`.plr`）

代码侧已证明：写回只改目标字节、文件长度不变、106 份真实存档「写回现有值」逐字节相同、重新解析逐项一致。
**没证明的是「游戏认不认」**。这是唯一还缺的一环。

1. 打开「玩家存档」→ 导入一份要试的角色 `.plr`（**建议先复制一份备份**）。
2. 点「编辑」，做 4 类改动：
   - 生命 500 / 上限 500；
   - 背包第 1 格换成「天顶剑」并加词缀；
   - 装备区第 1 格（头部）换一件装备；
   - 猪猪存钱罐第 1 格放 7 个生命水晶。
3. 保存并下载 → 用它**替换**游戏角色目录里的原文件（`Documents/My Games/Terraria/Players/<名字>.plr`，
   或服务器的 SSC 目录）。
4. 进游戏后检查：

| 检查点 | 通过标准 |
| --- | --- |
| 角色能进游戏 | 出现在角色列表、能选中、能进入世界（不报「加载失败」） |
| 生命 / 魔力 | 与编辑值一致（500/500） |
| 背包第 1 格 | 天顶剑 + 你选的词缀 |
| 装备区第 1 格 | 你换的那件 |
| 猪猪存钱罐第 1 格 | 7 个生命水晶 |
| 未改的格子 | 与原来完全一样（尤其看装备/仓储/配装是否串位） |

> 若某项没生效或串位，请把「存档 + 你的操作步骤」发我：说明偏移表在**你的游戏版本**上有差异。

## B. 「世界存档」编辑结果（`.wld`）

代码侧已证明：定长字段就地补丁不改结构、改名/种子会重排段指针并同步 footer、75 个真实世界全套字段写回后重新解析一致。
**没证明的是「游戏能打开改名后的世界」**。

1. 「世界存档」→ 导入一个世界 `.wld`（**先备份**，并注意：**服务器正在用这个世界时要先关服**）。
2. 点「编辑」：改世界名（长度变化）+ 种子 + 难度 + 出生点 + 当日时间 + 勾一个 Boss。
3. 保存并下载 → 替换游戏的世界文件（`Documents/My Games/Terraria/Worlds/<名字>.wld`）。
4. 在游戏里检查：

| 检查点 | 通过标准 |
| --- | --- |
| 世界能打开 | 世界列表里出现、能加载（**不报 `BadFooter` / 段指针错误**） |
| 名字 | 列表与进入后都显示新名字 |
| 难度 / 时间 / Boss | 与编辑值一致 |
| 地形与箱子 | 与原来完全一样（图格段没被动过） |
| 保存一次再进 | 能正常保存并再次进入（证明字段自洽） |

> 关键失败信号：`BadFooter`（footer 名字/worldId 不一致）或「世界文件损坏」——出现请立刻把文件发我。

## C. 物资申请「在线发放」

离线路径（批准 / 补发 / 审核 / 限额 / item ban）已在 TShock 6.2.1 实测过；**在线 `GiveItemCheck`** 需要有人在线。

1. 让一个真实玩家账号进服（SSC 或普通均可）。
2. 网页上提交一条物资申请 → 服主在网页「批准（在线发放）」。
3. 通过标准：该玩家**在游戏里立刻收到物品**，网页状态变「已发放」；若玩家不在线，应提示改为「下次上线补发」。

## F. 「替换图格」的验收（W3，新增）

代码侧已证明：只改图格 id 字节、**文件长度/段指针/footer 全不变**、被换格数与原计数一致、
墙/液体/空气统计不变（75 个真实世界逐个做过）。

进游戏确认（**先备份世界**）：

1. 「世界存档」→ 导入世界 → 点「编辑」→ 在「替换图格」里填 `1`（石块）→ `0`（土块）→ 点「替换」→ 确认。
2. 用下载的新文件替换原文件，进游戏。

| 检查点 | 通过标准 |
| --- | --- |
| 世界能打开 | 正常加载，无「世界文件损坏」 |
| 石头变成土 | 原来大片石块的地形变成土（形状与原来完全一致） |
| 箱子 / 房子 | 箱子、家具、门这些**没有**被换（只换你指定的 id） |
| 家具换家具 | 再试一次「箱子(21) → 木箱(467)」：箱子仍在原位、还能打开（frame 保留，形状相同时显示正常） |

> 家具之间形状不同（如 2×2 ↔ 3×2）换完可能显示错位——这是已登记的已知限制，不是 bug。

## G. 「箱子与招牌」编辑的验收（W4，新增）

代码侧已证明：**原样重建这两段 == 逐字节相同**（75 个真实世界，唯一差异是 `Revision+1`）、
改文本/名字后重新解析读到新值、**图格段逐字节不变**、箱子/招牌数量不变。

进游戏确认（**先备份世界**）：

1. 「世界存档」→ 导入世界 → 「编辑」→ 在「箱子与招牌」里点一个箱子：改名字（≤20 字符）、
   把第 1 格换成别的物品、把第 2 格清空 → 再点一块招牌，把文字改长一点。
2. 点「保存并下载」→ 用新文件替换原文件 → 进游戏。

| 检查点 | 通过标准 |
| --- | --- |
| 世界能打开 | 正常加载（不报段指针 / footer 错误——改了长度会重排指针，这是本项主要风险） |
| 箱子名 | 显示新名字（名字在游戏里也会被截到 20 字符） |
| 箱子内容 | 第 1 格是新物品、第 2 格是空的、其它格原样 |
| 招牌 | 显示新文字（含换行） |
| 其它 | 其它箱子 / 招牌 / 地形 / NPC 都没变 |
