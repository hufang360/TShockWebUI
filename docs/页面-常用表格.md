文档版本：1.0
对应页面：`web/src/pages/TablesPage.tsx`（tab 容器）、`web/src/pages/CommandTipsPage.tsx`（指令小抄 tab）、
`web/src/components/tables/ModifierTable.tsx`、`web/src/components/tables/LinkTable.tsx`
相关数据：`web/src/lib/commonTables.ts`（世界种子）、`web/src/lib/modifiers.ts`（词缀）、`web/src/lib/links.ts`（常用链接）、
`data/prefixes.json` + `data/prefix-mods.json` + `data/loc.<culture>.json`、`data/seed-icons/`
相关代码：`web/src/lib/tableRowStyles.ts`（与指令小抄共用的行样式）、`web/src/lib/tablesView.ts`（跨页打开指定 tab）
相关测试：`web/src/pages/TablesPage.test.tsx`、`web/src/lib/commonTables.test.ts`、`web/src/lib/links.test.ts`

> 定位：**知识性速查**集合页。四个 tab：`指令` / `世界种子` / `词缀` / `常用链接`。
> 侧边栏名「常用表格」（`BookText` 图标），地址仍是 `#/ref`，「工具」分组里紧跟「数据 ID」下一行。
> 整页只读：不执行指令、不发 TShock 请求（唯一的写动作是「把指令填进浮动终端」）。

## 1. 结构与路由

```text
常用表格（#/ref）
├─ tab: 指令            ← CommandTipsPage（原独立页，见 页面-指令小抄.md）
├─ tab: 世界种子
├─ tab: 词缀
└─ tab: 常用链接
```

- 老地址继续可用：`#/tables`、`#/commands`、`#/spawn` 都解析到本页；前两个会顺带打开「指令小抄」那张表
  （`lib/tablesView.ts` 的模块级意图，冷启动也不丢）。
- 全局搜索里命中的**指令**跳到本页并预填搜索词（`searchIntent`，tab 为 `tables`）。
- 侧栏名与图标只在 `App.tsx` 的 `nav` 里定义一次（文案键 `nav.tables` = 常用表格 / Tables）。

## 2. 世界种子（`kind: 'seeds'`）

| 项 | 说明 |
| --- | --- |
| 数据 | `lib/commonTables.ts` 的 `WORLD_SEEDS`：**特殊世界种子 9 行**在前，**秘密世界种子 37 行**按 wiki 的 7 个分类排（世界刷漆 / 世界生成 / 生物群系生成 / 结构生成 / 被动效果 / 生成点 / 其他效果） |
| 列 | 名称（含图标）/ 内部名称 / 种子 / 描述 |

| 吸血鬼症 | 用 NPC 159 的贴图**单独裁出** `data/seed-icons/Vampirism.png`（40×56，750 字节），不加载整张 NPC 图集 |

| 行详情 | 单击整行（或 Enter / 空格）弹 **Dialog**：图标 + 名称、内部名称、全部种子代码（各带底色、可复制）、描述 |

| 表头 | `bg-muted/50` 底色带 + `divide-x` + 加粗；行斑马纹跨分类连续（分类分隔行不占行号） |

有 5 个词缀式种子的「级别」在 wiki 上就是 `-`，表里显示 `–`（不臆造数值）。

## 3. 词缀（`kind: 'modifiers'`）

- 数据：`lib/modifiers.ts` 的 `MODIFIER_ROWS`，共 **96 条**（77 个武器 / 工具词缀 + 19 个饰品词缀），id 升序。
  显示名不在数据里：按 id 取 `dataset.prefixesById`（`loc.Prefix`），语言材质包也会生效。
- 列（15）：`ID / 名称 / 伤害 / 速度 / 暴击率 / 魔力消耗 / 大小 / 射弹速度 / 盔甲穿透 / 召唤标记伤害 / 击退 / 饰品效果 / 级别 / 价值 / 备注`。
- **正负颜色**：`+` 用 `text-success`，`−` 用 `text-destructive`，`–`（不适用）浅灰。
- **饰品词缀**：武器列上没有对应项，效果写在「饰品效果」列（`防御 +4`、`最大魔力 +20`、`移动速度 +1%`…），
  数值取 `data/prefix-mods.json` 的 `benefit`（游戏精确值）。
- **分组**（`MODIFIER_GROUPS`）：配饰 19 / 武器 14 / 公共 10 / 近战 16 / 远程 12 / 魔法 12 / 召唤 12，
  来自 wiki 各小节；`Legendary2` 不在任何小节里，只在「全部词缀」下可见（没有替它猜分组）。
- **备注**：同一显示名对应多个 id 时提示「有多个具有相同名称的修饰语」（中英各 5 组：急速 / 致命 / 迅捷 / 虚弱 / 传奇）。
- 工具栏：搜索（名称 + 内部名）+ 「分组」按钮（secondary）+「前往 Wiki」（secondary）。

## 4. 常用链接

- 数据：`lib/links.ts` 的 `LINK_GROUPS`（4 组：泰拉瑞亚 Wiki / TShock 相关 / 工具链 / 社区）。
- 每条链接是 `{ zh, en }` 两份地址：中文界面走 `/zh/wiki/…`，英文界面走 `/wiki/…`；非 wiki 链接两种语言相同。
- wiki 组只列**本项目真的会跳转**的页面（数据 ID、NPC ID、图格 ID、墙 ID、增益 ID、射弹 ID、秘密世界种子、特殊世界种子、修饰语）。
- 表格与「世界种子」同一套样式：名称列是**纯文字**，地址列是超链接（中英可读文本，不是 `%XX`），
  右侧外链图标按钮在新标签页打开。

## 5. 样式约定（与指令小抄共用）

- 行样式常量在 `lib/tableRowStyles.ts`（`DATA_ROW_CLASS` / `dataRowStripe`），两个页面 import 同一份，不各写一套。
- 表格外壳：`rounded-container border border-border/60` + `overflow-clip`（不是 `overflow-hidden`：那会造出滚动容器、破坏 `sticky` 表头）。
- 表头吸顶：种子表吸在搜索条下面（`useStickyHeaderOffset` 实测），词缀 / 链接表吸在顶栏下（`top-12`）。
- 焦点样式全站与 shadcn 一致：`focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-ring`。
