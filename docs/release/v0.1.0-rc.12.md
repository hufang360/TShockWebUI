# v0.1.0-rc.12 发布说明（2026-11-20）

> 单版本、面向玩家的发布说明（新增 / 改进 / 修复）。详细更新见
> [`changelog/v0.1.0-rc.12.md`](../changelog/v0.1.0-rc.12.md)；全量历史见根目录 [`changelog.md`](../../changelog.md)。

一句话：三个图标页默认换成「横条」并新增它；指令卡片能带参数；搜索框里就地看物品详情；数据 ID 接上怪物图鉴与 Buff 来源。

> 升级提示：本版没有配置或权限变更，直接替换二进制 / 镜像即可。
> 图标大小默认值变了（物品 ID / 数据 ID / 鱼店都默认「横条」），想回到方块格子在「页面设置 → 图标大小」里选小 / 中 / 大，选择会记住。

## 新增

- **自定义指令卡片可以带参数**：添加卡片时从指令库选一条指令，按它的参数表生成字段，每个参数可选
  **每次填写 / 固定值 / 不传**。例如「给物品」卡：物品固定 `29`、玩家每次填、数量固定 `10`，
  点执行就发出 `/give 29 张三 10`。有「每次填写」的卡片不会跟着自动刷新跑（不会拿上次的值替你发指令）。
- **图标「横条」档**（物品 ID / 数据 ID / 鱼店，默认就用它）：一格一条，图标在左、编号与名称在右，
  平分整行宽度；想回方块格子就选小 / 中 / 大。
- **鱼店货架可按商品用途分组**：钓鱼 / buff / npc / 指令 / 建造 / 召唤 / 团队 / 趣味 / 重铸 / 地牢 / 世界事件，
  与搜索叠加使用。
- **数据 ID 的 Buff 补上「游戏内描述」与「哪些东西会给你这个 buff」**；NPC 接上怪物图鉴的分组与排序，
  并补齐 `-1`~`-65` 号 NPC。

## 改进

- **搜索框里就地看物品详情**：物品行回车直接在搜索面板里开一层详情，配方材料 / 子物品可以往里叠，
  `Esc` 逐级退回还停在原来那一行；复制 ID / 名称、前往 Wiki、收藏都在底栏。
- **添加 / 编辑卡片回到抽屉里的两行面板**：名称 + 指令一行（指令带候选也能手写），参数入口就是指令框里的小按钮；
  下一行直接设尺寸 / 自动执行 / 显示。「管理卡片」清单还能按名称 / 指令过滤。
- **卡片上的参数更好填**：输入框占位就是 `参数1` / `参数2`，没填时变黄框、执行按钮灰着，
  输入框下面直接显示最终会执行的指令；状态文字和执行按钮都在卡片右上角。
- **物品 ID 的页签与分类**：左上角改成和数据 ID 一样的下划线页签，分类按钮改回带文字，分组入口并到同一行。
- **三个页面的搜索框统一到页签行右侧**；全屏后右上角只留「退出全屏」；长列表向下滚动会出现「回到顶部」。
- **鱼店**：右侧默认多一张「鱼罐」卡片；商品详情顶部只留一条标题栏；选中全局搜索里的商品直接打开它的详情。
- **页面说明默认收起**，点顶栏 ⓘ 才展开。

## 修复

- 修掉搜索框提示被弹框盖住一半。
- 修掉鱼店全屏时工具条上沿露出商品的一条缝。
- 修掉「填入指令」在多处行为不一致：现在统一为打开搜索框并预填（旧的浮动指令窗已移除，残留设置会自动清理）。
- 横条的悬停提示现在与方块格完全一致（物品 ID、鱼店不再各弹一份不同的内容）。
