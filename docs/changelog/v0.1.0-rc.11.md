# v0.1.0-rc.11 更新日志（2026-11-18）

> 单版本、按功能模块的详细更新。对外发布说明见 [`release/v0.1.0-rc.11.md`](../release/v0.1.0-rc.11.md)；
> 全量历史见根目录 [`changelog.md`](../../changelog.md)。

本轮重点：默认端口改 18080 并新增 `config.json`；网页里可以直接刷 Boss / 刷怪（放行名单制）；
图标网格三档大小（物品 ID / 数据 ID / 鱼店）；全站遮罩不再模糊、全屏里看详情不再错位。

> **升级提示**：插件自定义权限节点统一加了 `hf.` 前缀，**老节点不再生效**。
> 升级后请重新授权：`/group addperm default hf.webui.use`、`/group addperm default hf.webui.request.use`
> （管理组再加 `hf.webui.admin` / `hf.webui.request.review`），或对默认组跑一次 `/web init`。
> 另外默认端口从 8080 改成 18080：沿用旧端口的地方要同步改，或设 `LISTEN=:8080`。

## 部署与配置

- **默认端口 `18080`**：单文件二进制、Docker 镜像、`scripts/dev-native.sh`、vite 开发代理统一。
  下载 exe 双击就是 `http://127.0.0.1:18080`；镜像 `docker run -p 18080:18080`。
- **新增 `config.json`**（第一次运行在启动目录生成，键名与同名环境变量一致）：
  - 程序照常启动、不会退出；退出后改文件（如 `"LISTEN": ":9000"`、`"TSHOCK_URL": "http://192.168.1.10:7878"`），
    再启动就生效。路径可用 `-config D:\tswui\config.json` 或 `TSWUI_CONFIG=...`，`TSWUI_CONFIG=none` 关掉。
  - 优先级：**环境变量 > config.json > 内置默认值**（Docker / compose / `make dev` 的老用法不受影响）。
  - 键名写错（如 `LITSEN`）直接报错并点名，不静默回退；生成失败只警告，不阻塞启动。
  - 已加入 `.gitignore`（可能含 `TSWUI_AUTH_SECRET`）；镜像内默认 `TSWUI_CONFIG=none`，要用就挂卷并指定路径。

## 指令执行（Tier B 放行名单）

- **网页里可以直接刷 Boss / 刷怪**：`/spawnboss`（`/sb`）、`/spawnmob`（`/sm`）现在能在「指令」页、
  浮动终端、全局搜索里跑，以**你自己在线角色的身份**执行，刷怪点就是你当前站的位置。
  - 默认仍然不开，要同时配两处，而且只放行这两条：
    - 容器环境变量：`TSWUI_ALLOW_INGAME_COMMANDS=true`、`TSWUI_INGAME_COMMANDS=spawnboss,spawnmob`
    - 插件 `tshock/WebUI/config.json`：`"InGameOnlyAllowlist": ["spawnboss", "spawnmob"]`（`AllowInGameOnlyCommands` 保持 `false`）
  - `/item`、`/tp`、`/buff` 等其余 22 条「仅游戏内」指令**仍然只能在游戏内敲**：名单里写了哪些才放行哪些，空名单才不限定。
  - 玩家不在线时明确提示「该玩家不在线」；刷怪列表里的提示会广播到全服，网页结果会补一句说明。
  - 被拦住时不再只说含糊话，而是指出缺哪一环：没装信使插件 / 没开 `TSWUI_ALLOW_INGAME_COMMANDS` /
    这条不在 `TSWUI_INGAME_COMMANDS` 名单里 / 暂时连不上服务器；未登录先提示「请先登录」。
- **权限节点统一加 `hf.` 前缀**：`webui.use` → `hf.webui.use`、`webui.admin` → `hf.webui.admin`、
  `webui.request.use` → `hf.webui.request.use`、`webui.request.review` → `hf.webui.request.review`
  （TShock 自带的 `tshock.rest.*` 不变）。游戏内帮助、网页报错文案与文档同步换名；`/web init` 会补前两个。

## 侧栏全局搜索

- **执行指令后焦点留在搜索框，再按回车就是再跑一遍**：结果页不再有「返回」按钮，`Esc` 才回列表。
- **多次执行的结果累积**（不覆盖）：每条自带指令行，多条时标时间，超出高度就在框里滚、新结果贴底。
- 补参数不用退出结果页：`/help` 跑完直接改成 `/help 1` 回车，两条结果上下并排；改成普通搜索词才自动回列表。
- 结果页底栏提示 `⏎ 重新执行` / `Esc 返回`。

## 物品 ID

- **制作界面的 11 个分类直接摆在结果区左上角**：非收藏模式下点一下只看该类物品，再点一次取消；
  窄屏一行横向滚动（两侧边界渐隐），分组抽屉里的「制作界面」分区保留，两处同一份状态。
- **格子能调大小**：「页面设置 → 图标大小」大（图标 64 / 格 72）/ 中（48 / 56，默认）/ 小（32 / 40，只显示图标）。
  切完列数、行高、滚动立刻重算，下次打开还是你选的那档；「恢复默认」回到「中」。

## 数据 ID

- **NPC / 图格 / 墙 / Buff 图标网格同样支持三档大小**，默认按数据源给：**NPC 大，图格 / 墙 / Buff 中**；
  Boss 分类照样按档位放大一倍。小尺寸只有图标（「隐藏 ID 和名称」开关这时不显示）。

## 鱼店

- **不再预判「能不能买」**：货架只回商品信息 + 个人进度（还能买几次 / 冷却剩几秒），去掉了红框与禁用的购买按钮；
  真买不了时点一下，插件的报错原样显示在详情里（需要新版 FishShop 插件，旧版只是字段不再用）。
- **货架格子能调大小**（大 / 中 / 小，**默认中**），小尺寸只留图标。
- **全屏改成盖住整个视口**（连顶栏和侧栏一起），页面设置 / 退出全屏挪到右上角的小操作坞，4 秒无操作收成竖条。

## 界面一致性

- **全站遮罩不再模糊**（统一半透明黑 50%）；顶栏、吸顶表头、全屏操作坞也不再叠模糊。
- 「物品 ID」的分组抽屉（制作页签 / 集合选择那个）桌面端改成非模态：遮罩只盖内容区，**左侧边栏照常能点**。
- **全屏里看详情不再错位**：物品 ID / 数据 ID 全屏后打开详情，遮罩盖满整屏；鱼店全屏里的商品详情同样整屏压暗。

## 性能与安全

- **图集换成无损 WebP**：物品 / NPC / 玩家 / Buff 四张图集体积小约 60%（物品图集 1.9MB → 800KB），
  首次打开要下载的数据约 2.8MB → 1.7MB；图像逐像素与原来一致（旧内核 Chrome 32 / Safari 14 之前不支持 WebP，会显示占位图）。
- **防点击劫持**：响应头补 `Content-Security-Policy: frame-ancestors 'none'` 与 `X-Frame-Options: DENY`。
- **反代后的来源 IP 取对了**（只影响 `TRUST_PROXY=true` 的部署）：不再取 `X-Forwarded-For` 最左段（可伪造，能绕过登录限流），
  改为从右端跳过自己可控的代理层；新增 `TRUST_PROXY_HOPS`（默认 1，套了 CDN 就设 2）。
