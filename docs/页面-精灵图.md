## 定位

**公开本地工具**，页内三个 tab：

- **分割**：把一张 PNG 精灵表按行 × 列切开，或用鼠标**直接框选**任意区域当切片；每张切片可命名 / 微调，
  导出单张、打包 ZIP，或把多张切片串成帧**导出 GIF 动画**；工具条里有「来个 Demo」载入自带 `data/buff-atlas.png`。
- **合并**：多张 PNG 拼成一张精灵图（横向 / 纵向 / 网格 + 间距），导出 PNG。
- **GIF**：上传一张 GIF，按帧拆成 PNG（单帧 / 全部打包 ZIP）。

- 侧边栏「**工具**」分组，排在「世界存档」之后，地址 `#/slice`（图标 `ScissorsLineDashed`）。
- 不读 TShock、不需要登录与任何权限，**文件不上传**：解码、裁切、PNG 编码、ZIP 打包都在浏览器里做。
- 入口**恒在**，不跟随任何模块开关。
- 不写任何图片数据到 localStorage（只记切分参数）。

```
右栏 300px（与预览卡并排；容器 <1100px 时堆到下面；控件一律小号）

┌ 切片列表卡 ──────────────────────────────────────────────────────────┐
│ 切片列表                      共 N 张 · 已微调 M 张 · 手动 K 张      │

```

- **工具条与画布在同一张卡**：没有独立的「导入」卡，页面纵向只有「预览卡 / 列表卡」两层；
  宽屏（容器 ≥820px）时提示小字与工具条同行，窄屏隐藏（提示在顶栏 ⓘ 里也有一份）。
- **「适应」同时受宽度与可用高度约束**（视口约 62%，夹在 280–760px），竖长的精灵表不会把页面撑到好几屏。
- 切片列表的统计放在标题右侧，不再单独占一行；页面纵向间距 12px。

- **切分方式**（`ToggleGroup`，小号）：
  - `网格`：按行列切分，点击选中，微调网格切片；
  - `框选`：按住鼠标（触屏为手指）拖出一块 → 松开即新增一张**手动切片**并自动选中；点一下（没拖开）仍是选中。
    手动切片与网格参数无关，**改行列不会被清掉**。

- 空态用 `Empty`（`ImageUp` 图标 + 拖放提示）；整页可拖放（`data-testid="slice-drop"`）。
- 错误用 `Alert variant="destructive"`，成功提示（导入 / 导出 / 清空微调 / 猜测结果）用 `Alert variant="info"`。
- 预览缩放：适应宽度 / 50% / 100% / 200% / 400% / 800%（`ImageSmoothingEnabled = false`，像素保持锐利）。
- 切片列表只渲染可视区附近的格子（手算窗口），几百上千张也不会同时挂载等量 canvas。

## 计算规则（`lib/spriteSheet/slice.ts`）

默认矩形按「可用区域均分后 `round` 到边界」，行优先编号 `index = row * cols + col`：

```
usable = total - 2*margin - gap*(count-1)
cell   = usable / count
edge(i) = round(margin + i*(cell + gap))     i = 0..count
edge(count) 强制取 total - margin（不吃掉最后 1px）
第 i 格：start = edge(i)，end = i === count-1 ? edge(count) : edge(i+1) - gap
```

- 因此奇数尺寸（如 101 / 3）三格是 34 / 34 / 33：不重叠、不漏像素、末格贴边。
- 单格最小 1×1；行列上限 256（防止误输入把页面拖死）。
- 「自动猜测行列」= 假设正方形单元格且整除整图（`side = gcd(W, H)`），推断 `cols = W / side`、`rows = H / side`；
  猜不出（边长 < 4px、总数 > 4096）时回退 1×1 并提示手填。

### 切片列表模型（`lib/spriteSheet/model.ts`）

```
grid 切片（r1c1…）  ← 默认矩形 + 覆盖表 Map<index, rect>
manual 切片（slice-<id>） ← 鼠标框选的矩形，独立数组
```

- 每张切片的身份是 `key`：网格 `g:<下标>`、手动 `m:<自增 id>`。**不用数组下标**——改行列 / 删手动切片时下标会挪，
  key 不会，选中项与命名都跟着 key 走。
- `buildEntries()` 拼出展示 / 导出顺序：网格在前（行列顺序），手动按创建顺序追加；`index + 1` 就是序号徽标。
- 命名存 `key → 名字`；名字为空时回退默认名（网格 `r1c1`、手动 `slice-<id>`）。

### 微调与命名

- 网格切片微调存覆盖表；手动切片直接改自己的矩形。矩形一律夹进图片范围（`clampRect`，至少 1×1）。
- 改 X / Y / 宽 / 高、点微移四键、在预览上按方向键（Shift = 8px）都会写入；「恢复此切片」= 网格切片的覆盖项删除。
- **改行 / 列 / 边距 / 间距会清空网格切片的微调与名称**（输入框逐字输入时无法弹确认框）：
  提示「切分参数变了，已清掉 N 处微调 / 名称（手动框选的切片保留）」。
- 手动切片可「删除」（同时删掉它的名字）；网格切片不能删（由行列决定）。
- 预览的视觉分层：
  - **网格**：按去重后的边界画 1px 中灰细线（逐格 `strokeRect` 会让相邻边叠成 2px、粗细不均）。
  - **微调过的切片**：琥珀色虚线框（静止、不抢视线，但能数出改过几张）。
  - **选中切片**：其余区域压暗（聚光灯）+ 选中区域原样重画 + 白色光晕外圈 + 主色 2px 边框，任何底色的贴图都看得清。
  - **序号**：左上角小徽标（半透明黑底 / 选中时主色底），不再压在贴图正中；格子太小（<26×18）不画。

## 导出

| 动作 | 产物 | 说明 |
| --- | --- | --- |
| 导出此切片（按钮 / 双击缩略图） | `{名字}.png` | 当前矩形（含微调）原样裁切，不缩放 |
| 导出全部（顶栏） | `{原文件名}-slices.zip` | 每张一个 PNG 条目，名字规则同下；勾选「跳过全透明」时先按 alpha 过滤 |

文件名规则（`sliceFileNames`）：

- 命名优先，否则用默认名（网格 `r1c1` / 手动 `slice-3`）；
- 去掉 `\ / : * ? " < > |` 与控制字符、压空白、去掉开头 `.`、限长 64；
- **重名自动加 `-2` / `-3`**（忽略大小写），保证 ZIP 里不会互相覆盖；单张导出与 ZIP 用同一套名字。

- ZIP 是**手写的 store-only 格式**（`zip.ts`，含 CRC-32 / DOS 时间 / UTF-8 文件名标记），不引第三方依赖：
  PNG 已压缩，再 deflate 只是浪费 CPU。
- 全透明判定：把切片画到离屏 canvas 后读 `getImageData` 的 alpha；拿不到像素数据（无 canvas / 被禁用）时按不透明处理。
  统计里的「全透明 K 张」只在勾选后计算（`setTimeout(0)` 推迟一帧，避免拖慢输入）。

## GIF 动画

把切片按加入顺序串成帧 → 预览 → 导出 `.gif`。编码器是自写的 GIF89a（`lib/spriteSheet/gif.ts`，零依赖、纯本地）。

- 右侧「GIF 动画」卡：帧序列 chips（`#序号 名字`，每个都能 × 移除）、**加入当前切片**（已在序列里的切片按钮禁用）、**清空**、
  96px 预览（按帧间隔自动循环播放）、**帧间隔 (ms)**、**循环播放**、**导出 GIF**。
- 帧顺序 = 加入顺序；**至少 2 帧**才能导出（不足时按钮禁用并提示）。
- **尺寸不一致时按最大宽 / 高居中合成**（四周透明），预览与导出共用同一份合成结果。
- 文件名：`<原文件名>-animation.gif`。
- 编码事实：
  - 标准 GIF89a：逻辑屏幕描述符 + 每帧局部色表 + LZW（变长码，字典满 4096 重发 clear）；
  - 每帧独立量化：≤255 色**原样保色**，超出走中位切分降到 255 色（GIF 上限 256，含透明索引）；
  - 透明：`alpha < 128` 视为透明，预留一个透明索引，且 `disposal = 2`（还原背景），避免上一帧透出来；
  - 延迟精度 1/100 秒（按 10ms 取整），关闭「循环播放」时不写 NETSCAPE 扩展（只播一次）。
- 存储：`tswui:spriteSheet` 只多存 `gifDelayMs` / `gifLoop`；**帧序列只在内存**，刷新即清空。

## 合并

```
[导入 PNG（可多选）]  N 张图片  输出 W×H      排列 [横向|纵向|网格]  每行列数 [4]  间距 [0]  [导出精灵图]
┌ 合并预览（棋盘格底，自然尺寸 + CSS 缩放，像素锐利）──────────────────────────┐
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
列表： 1  a.png  20×10  ↑ ↓ ×      2  b.png  8×6  ↑ ↓ ×
```

- 排版在 `lib/spriteSheet/merge.ts`（纯函数，单测覆盖）：**不缩放**，尺寸不同时在自己的格子里居中；
  横向 = 行高取最大高度、纵向 = 列宽取最大宽度、网格 = 单元格取最大宽 × 最大高。
- 列表可上移 / 下移 / 移除（顺序即拼接顺序）；导出 `<第一张文件名>-merged.png`。
- 支持整块拖放多张图片；读不出来的文件会整体提示，不静默丢弃。

## GIF 分拆

```
[导入 GIF]  512×512 · 12 帧  无限循环                      [导出全部帧]
┌ 选中帧预览 128px ┐  第 3 帧  100 ms  [导出此帧]
└──────────────────┘
帧列表： [1][2][3]…（点选，双击导出该帧）
```

- 解码用自写的 `lib/spriteSheet/gifDecode.ts`：支持全局 / 局部色表、透明索引、interlace、
  disposal 0–3（**还原背景 / 还原上一帧**，所以分拆出来的帧是「合成后看到的画面」）。
- 帧文件命名 `<原文件名>-frame-001.png`；全部帧打包 `<原文件名>-frames.zip`。
- 导出的 PNG 是**逻辑屏幕尺寸**（不自动裁透明边），保证与动图看到的画面一致。

## 存储

- `tswui:spriteSheet` = `{ rows, cols, margin, gap, skipEmpty }`（本机、跨刷新；见 `设计原则与约束.md` §4.6）。
- 图片**不持久化**（`ImageBitmap` 无法序列化）；仅会话内缓存，切页面回来还在，刷新即清空。
- 重新导入时会 `dispose()` 释放上一张 `ImageBitmap`。

## 已知限制

- 网格切分仍是**统一网格**（每行等列数）；不规则精灵表用「框选」逐个圈，或对网格切片微调位置。
- 框选出来的切片只记录矩形与名字（不记录图层 / 锚点）；没有动画预览、九宫格编辑、精灵表再合成。
- 框选不与网格去重：框在已有切片上会**多**出一张，导出会同时包含两者。
- GIF 只支持 1-bit 透明与每帧 ≤256 色（超出会量化，颜色可能略有偏移）；预览只自动循环播放，没有暂停 / 逐帧。
- 帧顺序只按加入顺序，暂不支持拖动排序（要换顺序就移除后重加）。
- 合并**不缩放**图片（尺寸不同按单元格居中），也不支持九宫格 / padding 之外的排版参数。
- GIF 分拆导出的是整幅画面（不裁透明边）；GIF 的 1-bit 透明会被如实还原成 alpha 0。
- 不解析 `.xnb`、不读游戏目录、不推断贴图语义。
