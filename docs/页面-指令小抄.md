# 页面：指令小抄（侧边栏独立页）

文档版本：6.3
相关代码：`pages/CommandTipsPage.tsx`（页面）、`lib/commandTips.ts`（**分组定义**）、`lib/worldCommandTips.ts`、
`lib/userCommandTips.ts`、`lib/spawnTips.ts`、`lib/commandFormat.ts`
相关测试：`pages/CommandTipsPage.test.tsx`、`lib/spawnTips.test.ts`、`App.test.tsx`
数据：`data/commands.json`（内置指令 + `paramSets` 语法）、`data/npcs.json`（`sb` / `en`）

> 定位：世界 / NPC / 物品 / 增益 / 传送 / 建筑 / 用户管理 / 权限配置 / 服务器 / 聊天 的**指令速查 + 生成器**。
> 侧边栏**「工具」分组，紧跟「数据 ID」下一行**（侧边栏名「指令小抄」，图标 `ScrollText`，地址 `#/commands`）——查完 NPC / 图格顺手看对应指令。
> 布局：**左边搜索框 + 表格，右边分组列表**（窄屏分组收进抽屉）。没有顶部 tab。
> **单击一行 = 打开「指令详情」弹框**：复制指令 / 填入浮窗都在弹框里（不自动执行）；
> 带占位符的**参考行只能复制**（填进浮窗也跑不通）。
> 同一前缀的行（`/worldevent invasion …`、`/region …`、`/time …`）默认**折叠成一行**，点一下展开。
> 未登录也能看（指令小抄不取服务器数据）。旧地址 `#/spawn` 也回落到本页。

---

## 1. 为什么是「生成指令」而不是「直接执行」

- 页面只负责拼指令：避免误触发动世界（刷 Boss、切困难模式、改时间都是不可轻率执行的操作）。
- 权限与结果都由 TShock 判定，页面不承诺任何权限。
- `allowServer=false` 的指令（`/sb`、`/sm`、`/tpnpc`、`/login`、`/register` …）**网页端根本不能执行**（C6）：
  页面上照常显示（展示不是权限边界），参考行还会标「仅游戏内」。
- 其余 `allowServer=true` 的（`/worldevent`、`/time`、`/godmode`、`/ban list` …）在浮窗里回车即可执行。

- **没有顶部 tab**：分组是右侧列表（`aside`，`lg` 起常驻；窄屏用搜索框右边的「分组」按钮开 `Drawer`）。
- 分组定义在 `lib/commandTips.ts` 的 `TIPS_GROUPS`（顺序 = 侧栏顺序）；标题 / 说明 / 语法在 `lib/i18n.tsx` 的 `commands.group.*`。
- 点分组只显示那一组（再点「全部指令」回到全部）；**搜索会清掉分组筛选**（避免「选了组又搜不到」的死路）。

### 2.1 整页滚动：工具条吸顶、表头吸在工具条下面

- 页面**不固定高度**（不再用 `usePageHeight` 撑满一屏）：内容多就把页面撑高，滚动条是浏览器右侧那条
  （AppShell 的 `<main>`）。规则见 `docs/UI组件.md` 的「整页滚动」。
- 搜索框 + 分组按钮那一行 `sticky top-12`（顶栏 `h-12`）吸在顶栏下面；表头再吸在它下面：
  `top-[var(--page-sticky-top,0px)]`，变量由 `useStickyHeaderOffset()` 实测「顶栏 + 工具条高度」写在页面根元素上。
- 桌面端右侧分组列表 `lg:sticky lg:top-12`，自己内部最多一屏高、超出自己滚（不跟着表格滚走）。
- 表格不画边框 / 背景，直接铺在页面上（同数据 ID 页：不是卡片），容器也不再溢出滚动。

### 2.2 三种行：折叠行 / 具体指令行 / 参考行

| 行 | 长什么样 | 点一下 |
| --- | --- | --- |
| **折叠行**（`▸`） | 一组同前缀指令的公共前缀（`/worldevent invasion`、`/region`、`/death`）；说明列是**分区标题**（`/worldevent` → 世界事件），条目可用 `foldLabel` 覆盖（`/worldevent rain` → 雨） | **展开 / 收起**（不打开详情） |
| **具体指令行** | 点了就能跑的完整指令（`/worldevent bloodmoon`、`/ban list`） | 打开「指令详情」弹框 |
| **参考行** | 内置指令的语法（`/give <item type/id> <player> …`），说明列优先用子命令标签（`/region define` → 定义区域），没有子命令时用 TShock 的中文帮助 | 打开弹框，但**只有复制**（没有「执行」） |

- 表格列：**指令 → 说明 → 权限**（`md` 以下隐藏权限）。说明列 = 原来的「说明 + 备注」合并（`主说明 · 备注`，如「切换困难模式 · 仅游戏内」）；
  **没有操作列**，也没有单独的分类行 / 语法行 / 说明行。
- **每个分区内的行按指令列 a~z 排序**（折叠行用它的前缀参与排序，`sortKey()` 去掉开头的 `/` 与引号、忽略大小写）。
  权限取自 `data/commands.json` 的 `permission`，**没有权限写 `-`**；折叠行只有**整组权限一致**才显示那一个（不一致就留空）。
- **只能在游戏内执行**（`allowServer=false`）的指令：指令文字用 `text-destructive`（红），说明里跟一句「仅游戏内」；
  折叠行只有**整组都只能在游戏内**时才标红 + 跟上这句（子行不重复）。
- 三列都**单行、超出省略**（`truncate`）；指令列最大宽度手机 `11rem`、`sm` `16rem`、`xl` `22rem`；
  **只有可能被截断的（> 22 字符）才挂 Tooltip**（一页近 200 行，逐个挂 Radix Tooltip 太重）。
- 斑马纹 `odd:bg-muted/25` + `hover:bg-accent/25`（与物品 / 数据 ID 表格同一套）。
- **折叠规则**（`toRowGroups()`）：
  - 参考行按**指令名**折：`/region define` / `/region protect` / … → `/region`；
  - 具体行去掉最后一个参数，最多折到「指令 + 一个子命令」（`/worldevent invasion goblins` → `/worldevent invasion`；
    再往下的已经是参数，折了看不出是哪一条）；
  - `commandTips.ts` 的 `TipsGroup.folds` 可以显式把几条指令折成一组（首条作为折叠行）：
    `/death` 收起 `/pvpdeath` `/alldeath` `/allpvpdeath`；`/give` 收起 `/item`；`/buff` 收起 `/gbuff`；
    `/tp` 收起 `/tphere` `/tppos` `/pos` `/tpallow`；
  - `CommandTip.fold` 让单条指令归到指定折叠行（权限配置里那两条 `/group addperm default …` 归到 `/group`，
    四条插件权限归到 `hf 常用`）。
- 搜索实时过滤（大小写不敏感，中文名 / TShock 中文帮助也能搜）：
  - 命中**分区标题 / 语法 / 提示** → 整段留下；
  - 否则逐行匹配**指令 + 说明（含原备注）+ 使用提示**；
  - **搜索时折叠组自动展开**（否则命中的行藏在折叠里）；某个分区没有命中行时整段隐藏；
  - 全都不命中显示空态「没有匹配的指令」（没有表格）。

### 2.3 指令详情弹框

单击任意一行 → 居中 `Dialog`（`data-testid="command-detail"`，`max-w-lg`，窄屏左右各留 1rem）。
用弹框而不是右侧抽屉：指令语法 / 权限 / 提示文字都很长，抽屉那点宽度只能频繁折行。
打开时**焦点落在弹框本身**（不是指令旁的复制键），`Esc` / 右上角 × / 点遮罩关闭。

| 位置 | 内容 | 例子 |
| --- | --- | --- |
| 顶部 | **指令本身**：等宽加粗、比正文大一号、无底色；悬停时右边出现复制键（触屏常显）。**只能在游戏内执行的用红字并挂「仅游戏内」徽标** | `/register <password>` |
| 其下 | **说明**（表格说明列那一行，不截断） | 海盗入侵 |
| 其下 | **使用提示**：这一组的坑（`commands.group.<id>.hint`），多行；个别指令只讲自己、不套分组提示（见下） | 「只能传送到当前世界里已经存在的 NPC…」 |
| 分隔线以下 | **指令语法**：这一行的写法（行自己的 > 这条指令自己的 > 分区语法行），与这一行相同则不重复；**没有语法的指令不显示** | `/worldevent invasion <goblins\|snowmen\|…>` |
| 同上 | **权限**：`data/commands.json` 的 `permission`，一行小字，悬停出现复制键；无权限写「无（任何人可用）」 | `tshock.world.events` |
| 同上 | **别名**：标签一行、别名一行（没有就不占位） | `/unmute` |
| 分隔线以下 | **相关指令**：手工维护的关联（`RELATED_COMMANDS`），点一下把弹框切到那一条 | `/maxspawns` ↔ `/spawnrate` |
| 底部 | **执行**（`primary`，通栏浅底）——**实际只是把指令填进浮窗，不自动发出**；参考行没有底部栏 | — |

- **个别指令不套分组的语法与提示**（`TipsGroup.selfOnly`）：`/kick` `/mute` 不显示 `/ban` 的语法与提示，
  `/tempgroup` 不显示 `/group` 的提示；「玩家账号」整组只讲自己那一条。
- **没有指令语法**的：`/forcehalloween`、`/forcexmas`、`/hardmode`、`/evil`、`/worldinfo`；
  `/maxspawns` 只显示 `/maxspawns [数量|default]`，`/spawnrate` 只显示自己的（不再把两条写在一段里）。
- 详情里**不再显示**「执行位置」与「分组」：仅游戏内在表格里已经用红字 + 「仅游戏内」标明。
- 详情里的文字**不用灰色**：层级只靠字号（`text-2xs` / `text-xs` / `text-sm`）。
- 详情底部还有**「相关指令」**（`RELATED_COMMANDS` 手写映射，点一下把弹框切到那一条）与
  **「在数据 ID → NPC 里查更多」**（`/spawnboss` `/spawnmob` `/tpnpc` `/butcher` `/renamenpc` 才有，需要页面传 `onNavigate`）。
- 找不到对应内置指令的行（如插件相关占位）只显示指令 + 说明 + 使用提示，不编权限。

## 3. 指令与来源（全部按 TShock 6.2.1 源码核实）

### 3.1 事件（`/worldevent`）

| 行 | 指令 | 说明 |
| --- | --- | --- |
| 陨石 / 满月 / 血月 / 日食 | `/worldevent meteor` / `fullmoon` / `bloodmoon` / `eclipse` | 一次性事件 |
| 沙尘暴 / 下雨 / 史莱姆雨 / 金币雨 | `/worldevent sandstorm` / `rain` / `rain slime` / `rain coin` | **切换**，再执行一次停止 |
| 灯笼夜 / 流星雨 | `/worldevent lanternsnight` / `meteorshower` | 一次性事件 |
| 入侵（二级） | `/worldevent invasion goblins\|snowmen\|pirates\|pumpkinmoon\|frostmoon\|martians` | `Invade()` 读 `args.Parameters[1]`；可选第 3 个参数是波数 |

- 事件全集 = `_validEvents`，入侵类型 = `_validInvasions`（`TShockAPI/Commands.cs`）。
- `rain` 的第二个参数取自 `Rain()`：`slime` / `coin`，不传 = 普通雨。

### 3.8 用户管理（按 TShock 6.2.1 源码 + 本服实测）

来源：`TShockAPI/Commands.cs`（`ManageUsers()` 1114、`PasswordUser()` 1005、`RegisterUser()` 1043、
`Logout()` 983、`ViewAccountInfo()`、`GrabUserUserInfo()`、`Kick()` 1353、`Ban()` 1388、`Mute()` 5571、
`Group()` 3471、`TempGroup()` 1972），并用本服 `POST /v3/server/rawcmd` 实测过
`/user help`、`/ban help`、`/ban list`（返回预期帮助 / 列表）。

| 指令 | 参数 | 说明 |
| --- | --- | --- |
| `/register <密码>` | 注册本人账号 | `AllowRegisterAnyUsername` 时可 `/register <用户名> <密码>`；`allowServer=false` |
| `/login [用户名] <密码>` | 登录 | 开了 UUID 登录时直接 `/login`；`AllowLoginAnyUsername` 时才需要用户名；`allowServer=false` |
| `/password <旧密码> <新密码>` | 改自己密码 | `allowServer=false` |
| `/logout` | 登出 | 无参数，`allowServer=false` |
| `/user add <用户名> <密码> <组>` | 建账号 | `tshock.superadmin.user` |
| `/user del <用户名>` | 删账号 | 同上 |
| `/user password <用户名> <新密码>` | 改别人密码 | 同上 |
| `/user group <用户名> <组>` | 改所属组 | 同上 |
| `/user help` | 列出子命令 | 可点（实测输出与源码一致） |
| `/accountinfo <用户名>`（别名 `/ai`） | 查账号 | `tshock.accountinfo.check`；`tshock.accountinfo.detail` 才看得到 IP / 注册时间 |
| `/userinfo <玩家>`（别名 `/ui`） | 查在线玩家 IP / 账号 / 组 | `tshock.admin.userinfo` |
| `/ban add <目标> [原因] [时长] [标志]` | 封禁 | 时长 `0d0h0m0s`（可只写一部分），不写＝永久；标志 `-a` 账号 / `-u` UUID / `-n` 角色名 / `-ip` 地址 / `-e` 按标识符；默认 `-a -u -ip` |
| `/ban del <编号>`、`/ban list [页]`、`/ban details <编号>`、`/ban help` | 解封 / 列表 / 详情 / 帮助 | `list` 与 `help` 可点（实测） |
| `/kick <玩家> [原因]` | 踢出 | 原因默认「Misbehaviour.」 |
| `/mute <玩家> [原因]` | 禁言 | **再执行一次＝解除**；对方有 `tshock.admin.mute` 时无效 |
| `/group add <组名> [权限]`、`/group addperm`、`/group delperm`、`/group listperm`、`/group parent`、`/group rename`、`/group prefix`/`suffix`/`color`、`/group del` | 组管理 | `tshock.admin.group` |
| `/tempgroup <玩家> <组> [时长]` | 临时换组 | 只对在线玩家生效，到时间自动恢复 |

### 3.9 权限配置（开服时逐个放权）

「权限配置」分区的 6 条是**本服实测过**的原文（见仓库 `notes.md`），表格里折成两行
（`/group` 收 TShock 权限两条、`hf 常用` 收插件权限四条），在详情里点「执行」才会填，执行者仍需 `tshock.admin.group`：

| 指令 | 作用 |
| --- | --- |
| `/group addperm default tshock.rest.useapi tshock.rest.command` | WebUI 前置：允许建 token（登录）与执行指令；`default` 组默认没有 |
| `/group add GM * !tshock.ignore.ssc` | 新建 GM 组：`*` = 全部权限，`!` 表示取反，`tshock.ignore.ssc` 被去掉（保留服务端角色检查） |
| `/group addperm default tshock.tp.home` | 放开 `/home`（`tshock.tp.home`） |
| `/group addperm default hf.recipe hf.search` | 查一查插件：`/r` 合成表、`/s` 物品 ID |
| `/group addperm default worldinfo bossinfo` | 世界管理（WorldModify）插件：`/wi` 世界信息、`/bi` Boss 进度 |
| `/group addperm default lookbag` | 玩家管理（PlayerManager）插件：`/lb` 查背包 |

- `!权限` 与 `*` 不是本页发明的写法：`TShockAPI/Group.cs` 的 `AddPermission()`（认 `!` 前缀 → `NegatePermission`）
  与 `HasPermission()`（逐段替换成 `*` 做通配匹配）就是这么实现的；`TShockAPI/Commands.cs` 的 `Group()`
  负责解析 `add` / `addperm`（权限可一次给多个，空格或逗号分隔）。
- **插件权限名**（`hf.recipe` / `hf.search` / `worldinfo` / `bossinfo` / `lookbag`）来自本服插件配置与实测，
  **不在** `data/permissions.json`（那份只收 TShock 内置节点）。
- 换人 / 换组：写法在「指令语法」里（`/user group <玩家> <组>`，需要 `tshock.superadmin.user`）；
  带占位符的语法只展示、详情里也只给复制（填进去也跑不通）。

## 4. 与浮动终端、数据 ID 的关系

- 单击具体指令行 / 示例 → 打开「指令详情」弹框；弹框底部「执行」→ `useTerminal().open(cmd)`：
  打开浮窗并**覆盖**草稿，不累加。
- 参考行不填浮窗，详情里只用 `navigator.clipboard` 复制（复制后图标变 ✓）。
- 指令库（全部指令列表 + 参数补全）在**指令页的工具弹框**里（输入框左下角最左边的「指令库」按钮；弹框内已无 tab 栏），点一条填进页面输入框。
- **数据 ID → NPC / Buff 详情**里显示同一批指令（`/spawnboss` 仅 Boss、`/gbuff` 用于 buff），同样可复制；
  两边都**不按玩家权限隐藏**（页首提示「各指令权限不同」，判定在 TShock）。

## 5. 边界

- 不做「一键全部 Boss」「一键切换困难模式」这类批量/危险操作按钮：点开只是填一条指令，执行前玩家自己确认。
- 不列全部怪物 / 城镇 NPC（只给示例），避免两处维护同一份清单。
- 不校验权限后才显示行（除数据 ID 详情外）：权限判定在 TShock，页首只做统一提示。
- **不收录插件指令**（语法要读插件源码才能核实）；`allowServer=false` 的照常显示，但标「仅游戏内」。
- 「权限配置」里的插件**权限名**（`hf.recipe` / `worldinfo` / `lookbag` …）不是插件指令：写法统一是
  `/group addperm <组> <权限...>`，由 TShock 解析，页面只把实测过的名称列出来。
