# 功能：全局搜索（侧栏）

文档版本：1.0
对应组件：`web/src/components/GlobalSearch.tsx`（`GlobalSearch` 桌面内联 / `GlobalSearchDialog` 移动弹框）
相关代码：`web/src/lib/globalSearch.ts`（匹配与截断）、`web/src/lib/searchIntent.ts`（跨页预填）、
`web/src/components/AppShell.tsx`（页头插槽）、`web/src/App.tsx`（数据源与导航）
相关文档：[`计划-全局搜索.md`](计划-全局搜索.md)（取舍与分期）、[`功能-搜索记录.md`](功能-搜索记录.md)（最近搜索规则）

## 1. 定位

侧栏里一个常驻搜索框：任意页面输关键词，就能在**物品 / NPC / Buff / 图格 / 墙 / 指令 / 页面 / 鱼店商品**里找到目标，
并把它带到能继续操作的地方。搜索**不发网络请求**；唯一的服务器数据是懒加载的鱼店货架（打开弹框时拉一次，见 §6）。

## 2. 入口与形态

**只有一套界面**：一个居中弹框，桌面与移动端共用（侧栏里那个只是入口，不是输入框）。

| 入口 | 位置 | 说明 |
| --- | --- | --- |
| 桌面 | 侧栏页头**第二行**（`WebUI` 标题行下方、「首页」上面） | 长得像搜索框的**按钮**（放大镜 +「搜索…」+ 快捷键芯片），点一下打开弹框；滚导航不会把它推走 |
| 桌面快捷键 | `Ctrl+K` / `Cmd+K` | 打开同一个弹框；**侧栏收起时也能用**（不需要先展开侧栏）；抽屉 / Popover 开着时**照样能开**（商品详情边看边搜），只让位给已有模态弹框（登录 / 确认 / 物品详情 / 搜索本身） |
| 移动端 | 内容区顶栏的搜索图标（`md` 以下显示） | 侧栏是抽屉，抽屉里的入口会叠两层遮罩，所以入口放顶栏 |

弹框由 `App` 用 `key={open ? 'open' : 'closed'}` 重挂载，因此**一般**每次打开都是空词（不会留着上次的词挡住「最近搜索」）；
例外是二级记忆：60s 内从某一组的二级列表里关掉，再打开会直接回到那一组和那个词（见 §3）。
弹框**没有关闭按钮**：`Dialog` 自带的右上角 × 会压在满宽输入框上，所以关掉（`DialogContent` 的 `hideClose`），
靠 `Esc` 或点遮罩关闭 —— 键盘操作写在**底部提示条**里（`↑` `↓` 选择 / `Enter` 打开 / `Esc` 取消）。

`/` **不占用**：各页面自己的搜索框已经在用它（见 `SearchInput` 的 `shortcut`）。

输入框：占位符只有「搜索…」（要搜什么在空结果的提示里列了，不在框里堆长文案）。
桌面入口按钮上的快捷键芯片按平台显示（macOS `⌘K`，其余 `Ctrl K`），移动端没有物理键盘就不显示。

## 3. 弹框内容

- 结果列表用 `ui/Command`（cmdk）渲染：分组、`↑` / `↓`、`Home` / `End`、`Enter`、`role="listbox"/"option"`、
  `aria-activedescendant` 都由它负责。**匹配与排序仍在 `lib/globalSearch.ts`**，所以传 `shouldFilter={false}`
  （否则 cmdk 会拿已排好的结果再按 `value` 过滤一遍）。
- 焦点环走 `InputGroup` 的 `focus-within:ring-2 ring-ring`（DESIGN.md 的规定）。所以 `ui/Command` 根节点
  **不能**带 `overflow-hidden`：环画在盒子外侧，会被裁成只剩一半。
- 弹框：`Dialog` 居中偏上（`top-[12%]`），最大宽度 `max-w-xl`；**圆角走 16px 档**（`radius="container"`，
  比通用弹框的 24px 紧一档）；输入框与其他搜索框同高（`h-8` / `text-xs`）；结果区最高 `60vh`，超出在框内滚动。
  弹框**自身不设内边距**（`p-0`），内边距写在 `Command` 与底栏上：底栏要用 `border-t` 做通栏分割线，
  靠负外边距（`-mx-3`）抵消 padding 会把那份额外宽度算进 grid 轨道，整个弹框被撑宽、冒出横向滚动条。
- 底部一条常驻提示条（细边框、`text-2xs`），**只在有内容时才提示能做什么**：
  - 刚打开、还没词也没历史（没东西可操作）：左侧 `↑ ↓ 选择`、`Esc 取消`，右侧空；
  - 有内容（结果 / 最近搜索 / 二级 / 执行结果）：左侧不再显示通用键，**右侧按高亮行给出它的动作**——
    `⏎ 打开` / `⏎ 查看` / `⏎ 执行` / `⏎ 填入终端`，配 `⌘ C` 两个键帽 + `复制 ID` / `复制指令`；
    最近搜索是 `⏎ 搜索` + delete 图标 `删除`；二级与执行结果多一个 `Esc 返回`。
    键帽用**符号 / 图标**而不是英文单词（`⏎` 代替 `Enter`、delete 图标代替 `Delete`），组合键拆成两个键帽。
  移动端也显示（没有物理键盘时是「说明」而不是「提示」，不占额外空间）。
- 分组标题 + 每行：图标 24px / 名称（超长截断）/ 右侧弱化的次要信息（`#ID`、价格、指令帮助摘要）。
  右侧信息**真正贴右**（名字 `flex-1` 吃掉剩余空间）；行内**没有按钮**（动作都在底栏，见上）。
  物品集合行**不带条数**（裸数字看不懂，数量在物品 ID 页的集合里有）。
  行高：桌面 30px、触屏（`md` 以下）40px，保证手指点得中。
- 每组最多 **3** 条、总计最多 **12** 条；被截掉的组，组内最后多一条「更多」（右侧是该组真实命中数）。
- **三层结构**（都在弹框里，不跳页）：
  1. **一级**：分组结果 + 每组末尾的「更多」；
  2. **二级**：点「更多」展开该组，最多 **20** 条，左上「返回」、右上「组名 · N 条」；
     命中超过 20 条时，列表最后才是「更多」（右侧写目标页名，如 `物品 ID`）→ 跳到该域页面并带上搜索词；
     二级里可以继续改输入词，就在这一组内过滤；词清空则自动回一级（不留一个空组）；
  3. **执行结果**：指令在弹框里跑完的结果（见下面的「指令结果可以就地执行」）→ 二级之上的临时层，`Esc` 回原列表。
- 层级返回：`Esc` 从执行结果回列表、从二级回一级（高亮停回刚才那行「更多」），一级才关弹框。
- **二级位置记忆 60s**（`lib/searchDrill.ts`，模块级，不进 localStorage）：记住「哪一组 + 哪个词 + 哪一行」，
  `Esc` 回一级再进去、或者关掉弹框再打开，都直接回到那个位置；跳页 / 填终端（离开弹框）后清掉。
- 空查询：显示「最近搜索」（≤5 条，键 `tswui:global:searchHistory`，规则见 `功能-搜索记录.md`）；
  点一条即填进输入框、接着显示结果。没有历史时显示一行提示（可搜哪些域）。
  - 和结果一样是 cmdk 的 `option`：`↑` / `↓` 能选中、`Enter` 填入。
  - **删除**：空查询时按 `Delete` / `Backspace` 删掉高亮那条（有搜索词时这两个键留给输入框删字符，弹框不拦）；
    行尾 ✕ 是**鼠标**辅助（`role="option"` 里不能再放按钮，所以它是 `aria-hidden` 的点击区，
    键盘用户走 Delete）。删空后自动回到「可搜哪些域」提示。
  - 底部提示条在有最近搜索时多一项 delete 图标`删除`。
- 无匹配：一行「没有找到「xxx」」。
- **指令结果可以就地执行**：已登录且 `allowServer !== false` 时，`Enter` 直接在弹框里跑，
  切到执行结果层显示输出（执行中转圈 → 输出 / 错误），`Esc` / 左上「返回」回到列表；
  输出用**富文本**渲染（和「指令」页的结果面板同一个 `CommandOutput`：`[c/..]` 上色、`[i:..]` 出物品图标、
  失败原因走 Alert）；失败时结果下面多一条「查看用法」→ 跳到「指令小抄」，成功时不给这个入口。
- **数据里的必填参数（`required`）不拦执行**：它是从 TShock 源码解析出来的，`/help`、`/userinfo` 这类
  「可带可不带」的指令也会被标成必填。所以一律执行——缺参数就让 TShock 回一句用法错误（结果显示在弹框里），
  失败时结果下面给两个退路：「查看用法」跳「指令小抄」，标了必填参数的再给一个「填入终端」补参数重跑。
  只有 `allowServer=false` / 未登录时 `Enter` 才是跳到「指令小抄」查用法。
- **输入整行指令直接执行**（`/` 或 `.` 开头）：查询写成 `/help 4`、`.wm find 生命水晶` 时，列表**顶部多一行**
  「执行指令：/wm find 生命水晶」且默认高亮，`Enter` 直接跑这一行，结果显示在二级（同「指令结果可以就地执行」）。
  - 这个查询**没有其它命中**时就只有这一行（不再说「没有找到」）；有命中时它在最上面，按下就跑。
  - 未收录的插件指令（如 `/wm`）也放行（Tier A：交给 TShock 校验），右侧带该指令的帮助摘要（能查到的话）；
    必填参数没给也照样给这行（`/give`、`/help` 都能跑，缺参数由 TShock 判）。
- **仅游戏内指令（`allowServer === false`）**：和「指令小抄」一样用语义红（`text-destructive`）标出来，
  右侧写「仅游戏内」，`Enter` **不执行**（也不填终端），只去「指令小抄」看用法；整行输入（`/item 29`）同样标红不可执行。
- **带前缀的写法也能命中指令组**：`/help`、`.help`、`/help 4` 都按 `help` 匹配（只对指令组生效，
  物品 / NPC 名称里没有 `/` 前缀这回事）。
- 键盘：`↑` / `↓` 跨组循环（cmdk 的 `loop`）、`Home` / `End` 跳首尾、`Enter` 执行高亮项（默认高亮第一条）、
  `⌘/Ctrl+C` 复制高亮行的 ID / 指令（输入框里有选中文本时不接管）、`Esc` 清空并收起、`Tab` 收起。
- 底栏右侧的复制提示**跟着高亮行走**：指令 → `⌘ C 复制指令`；物品 / NPC / Buff / 图格 / 墙 → `⌘ C 复制 ID`；
  高亮到没有复制功能的行（页面 / 物品集合）→ 不显示。
- 输入法组合期（`isComposing`）不响应方向键与回车（cmdk 自己先判断）；搜索防抖 120ms。
- 无障碍：输入框 `role="combobox"` + `aria-expanded` / `aria-controls` / `aria-activedescendant`，
  结果 `role="listbox"`，分组 `role="group"`，行 `role="option"`（均由 cmdk 输出）。

## 4. 可搜的域与主操作

| 分组 | 图标 | 数据源 | 命中字段 | 右侧 | 主操作 | 行内操作 |
| --- | --- | --- | --- | --- | --- | --- |
| 页面 | nav 的 lucide 图标 | `App` 的 `nav`（含已激活模块、自定义模块） | 名称 / tab id / 别名表（`PAGE_ALIASES`） | — | 直接跳转 | — |
| 物品 | 物品图集 | `dataset.items`（复用 `searchItems`） | ID 精确 > 名称 / 内部名前缀 > 包含 > 标签 | `#id` | **就地打开物品详情弹框**，不跳页 | `Enter` 打开，`⌘C` 复制 ID |
| 指令 | 终端 `>_` | `dataset.commands`（含登录后合并的运行时插件指令） | 名称 / 别名 / 中英帮助 | 帮助摘要 | 能裸跑 → **就地执行**；要补参数 → **填入浮动终端**；其余 → 跳「指令小抄」并预填 | `Enter` 执行 / 填入终端 / 打开，`⌘C` 复制指令 |
| NPC | NPC 头像 | `dataset.npcs` | 名称 / 内部名 / 英文名 / `/sb` 参数与别名 | `#id` | 跳「数据 ID · NPC」并预填 | `Enter` 查看，`⌘C` 复制 ID |
| Buff | Buff 图标 | `dataset.buffs` | 名称 / 内部名 | `#id` | 跳「数据 ID · Buff」并预填 | `Enter` 查看，`⌘C` 复制 ID |
| 图格 | 代表物品图标 | `dataset.tiles` | 显示名 / 常量名 / ID | `#id` | 跳「数据 ID · 图格」并预填 | `Enter` 查看，`⌘C` 复制 ID |
| 墙 | 代表物品图标 | `dataset.walls` | 显示名（代表物品名）/ 常量名 / ID | `#id` | 跳「数据 ID · 墙」并预填 | `Enter` 查看，`⌘C` 复制 ID |
| 鱼店商品 | 配置的物品图标 / 购物车 | `lib/fishGoodsCache`（按服务器缓存，打开弹框时懒加载） | 名称 / 说明 / 分类标签 | 价格 | 跳「鱼店」并预填搜索框 | — |
| 物品集合 | 方块堆 | `lib/collections.ts` 的 `ITEM_COLLECTIONS` | 集合名 / 集合 id | — | 跳「物品 ID」并应用该集合 | — |

- 组顺序固定：页面 → 物品 → 指令 → NPC → Buff → 图格 → 墙 → 鱼店商品 → 物品集合。
- **不搜玩家名**（按需求移除：玩家名由「玩家管理」页自己查，避免搜索变成「查号」入口）。
- **行里没有操作按钮**（只有图标 + 名称 + 右侧弱化信息）：`role="option"` 的子元素只能是「呈现型」的，
  放按钮屏幕阅读器也读不到；更重要的是行里的小图标认不出是「复制」还是「执行」。
  所以两个动作都走键盘，并且**在底栏写明**：`Enter` 打开 / 查看 / 执行 / 填入终端，`⌘/Ctrl+C` 复制 ID 或指令
  （一级、二级都生效）。复制成功弹 toast（「已复制」），失败弹「复制失败」，不假装成功。
- 指令行的 `Enter`：登录且 `allowServer !== false` → **执行**（含必填参数的情况，缺参数会显示 TShock 的用法错误）；
  `allowServer=false` / 未登录 → 跳「指令小抄」看用法。底栏的 `Enter` 文案就是当前高亮行的实际动作，不靠猜。
- 匹配只做**字面匹配**（大小写不敏感、`trim`），不做拼音 / 模糊 / 语义。数字会参与各域的 ID 字段匹配，
  因此输 `29` 时「物品 #29」「图格 #29」都会命中，组内精确命中的排最前。
- **液体不收录**：数据 ID 页没有液体入口，搜到也没地方去（液体只出现在「世界存档 → 查找图格」）。
- **鱼店货架**已收录（`lib/fishGoodsCache` 按服务器缓存，打开弹框时懒加载）；物资申请条目仍不收录（没有搜索场景）。

物品的主操作直接走 `App` 层那个全局「物品详情」弹框（`ItemDetailProvider`）：搜索在 `AppShell` 里，
在「物品 ID」页也一样用这个弹框，而不是页内那个可堆叠抽屉（两者内容同一个 `ItemDetailPanel`）。

## 5. 跨页预填：`searchIntent`

点击需要跳页的结果 / 组标题的「全部」时，`App` 的导航带一个一次性意图：

```ts
navigate(tab, { query?: string; kind?: 'npc' | 'tile' | 'wall' | 'buff'; collectionId?: string })
```

`lib/searchIntent.ts` 用模块级待办保存它（沿用 `lib/editorView.ts` 的模式），各页面 `useSearchIntent(tab, apply)` 消费：

| 页面 | 消费方式 |
| --- | --- |
| 数据 ID | 切到 `kind` 对应的数据源，写入搜索词（`queryKind` 同步） |
| 指令小抄 | 写入搜索词（搜索时同前缀折叠行自动展开） |
| 物品 ID | `collectionId` → 应用集合；`query` → 切到「全部物品」并搜索 |
| 鱼店 | `query` → 写进货架的搜索框（不自动打开详情） |

普通导航（点侧栏 / 切页）会 `clearSearchIntent()` 作废待办，避免下次进入该页突然带上旧搜索词。
数据 ID 目前只做「按词过滤」，不滚动定位到具体条目（见 `计划-全局搜索.md` 的 P2）。

## 6. 降级与数据

- 未登录：鱼店货架为空 → **「鱼店商品」整组不出现**（不显示灰掉的组，避免点了没反应）。
- 插件未装 / 模块未激活：不影响静态域；货架拿不到时同样不出现该组（静默，不报错）。
- 图标：物品用物品图集（首屏已预加载）；NPC / Buff 图集按需懒加载（与「数据 ID」页共用同一个 Promise 缓存），
  未就绪时先留空位，不阻塞结果；加载失败也不抛错。
- Mock 模式：不新增任何 Mock 数据，组内容随现有 transport 行为；顶部已有 Mock 标识，弹框里不重复标注。
- 搜索本身不发请求：唯一的请求是**打开弹框时**按需拉一次鱼店货架（`transport.fishList`），
  失败静默（就没有这一组）；唯一的本地存储是新键 `tswui:global:searchHistory`。

## 8. 已知限制

- 弹框是模态的：搜索时看不到身后的页面（这是「一个独立弹框」的代价，换来唯一的搜索界面）。
- 鱼店货架由 `lib/fishGoodsCache` 按服务器缓存，第一次打开弹框时拉取；插件配置变了要等下次打开弹框才刷新。
- 鱼店货架、物资申请条目、词缀、本地文件（`.plr` / `.wld`）均不在搜索范围内。
