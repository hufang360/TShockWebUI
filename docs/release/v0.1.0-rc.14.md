# v0.1.0-rc.14 发布说明（2026-11-26）

> 单版本、面向玩家的发布说明（新增 / 改进 / 修复）。详细更新见
> [`changelog/v0.1.0-rc.14.md`](../changelog/v0.1.0-rc.14.md)；全量历史见根目录 [`changelog.md`](../../changelog.md)。

一句话：存档能跨游戏版本转换了（世界 1.4.0.1–1.4.6.1、角色双向），全面支持 1.4.6.1；数据 ID 多了油漆 / 射弹速查。

> 升级提示：本版没有配置或权限变更。存档降级会**删掉目标版本没有的字段且不可恢复**，转换前请留一份原档；
> 首页内置指令卡改为默认手动执行（想自动刷新去「管理卡片」里打开）。

## 新增

- **存档支持泰拉瑞亚 1.4.6.0 / 1.4.6.1（release 329）**
  - 角色存档：1.4.6.1 的 `.plr` 可以直接查看 / 编辑。
  - 世界存档：1.4.6.1 的世界可以直接打开、分析、编辑；新增「无蜘蛛世界」特殊种子徽章。
- **世界存档可以改游戏版本**：「世界存档 → 编辑」多了版本下拉。
  - **升级**从 1.4.0.1 起都支持（老地图能升到 1.4.6.1）；**降级**只到 1.4.4（再往下缺少可靠的实体类型表）。
  - 同布局段只改版本号，跨段会真正转换格式（头部字段、箱子段、NPC 段、图格实体段），
    升级补默认值、降级删字段并在界面上说明**无法恢复**。
  - 降级前会扫描世界内容：目标版本没有的图格 / 墙 / 物品 / NPC / 图格实体直接**拒绝**并报出具体 ID，不生成坏档。
  - 299–312 的预览版存档只读不转。
- **玩家存档可以转成别的游戏版本**：「查看存档 → 编辑」的版本下拉不再只给同布局段。
  - 1.4.0.1 ↔ 1.4.6.1 双向：往上升只插入新版本多出来的字段，往下只删除目标版本没有的字段，其它字节不动。
  - 原文件不会被覆盖，下载的是新文件。
  - 读不出存档尾部（被第三方改过）、退款队列里还有东西时明确拒绝，不硬写。1.4.0.1 之前暂不支持转换。
- **数据 ID 新增「油漆 / 射弹」速查**
  - 油漆：30 个油漆 + 2 个涂料（夜明 / 回声），可按「全部 / 油漆 / 涂料」筛，详情给出对应物品。
  - 射弹：1136 条，带首帧图标（1117 个），名称随界面语言；详情有内部名与 Wiki 链接。
- **全局搜索（`Ctrl/Cmd+K`）收录油漆 / 射弹**：输名字直接进对应页签并定位到那一条。

## 改进

- **未登录时不再自动弹登录框**：启动、会话过期、切换服务器后只显示「请先登录！」占位卡，
  点「登录」才弹（账密仍会回填）。物品查询、数据 ID、存档、世界分析这类**只读工具页不会一进来就被拦**。
  自动弹只保留给「执行指令时 token 失效」的被动重登，重登成功后原指令自动重试一次。
- **首页内置指令卡改为默认手动执行**：在线玩家 / Boss 进度 / 世界信息 / 我的背包 / 死亡次数 / Boss 战伤害
  进页面不再自动打一屏指令，点卡片自己的 ▶「执行」才跑；「刷新全部」仍是把这些卡现在全跑一遍。
  想让某张卡跟着页面自动跑：「管理卡片」→ 行尾「更多设置」→ 打开自动执行。
- **首页去掉「游戏时间」卡**（与「世界信息」里的游戏时间重复）。
- **鱼店搜索能按「商品实际发的东西」找**：编号、插件别名、商品实际发放的物品名（中英文与内部名）都算命中 ——
  服主把商品叫「回城」，搜「魔镜」也能找到。
- **图格 / 墙补了 70 + 74 条中文名**：藤蔓、草丛、苔藓砖、未安全墙这类原本只能显示英文常量名的，现在显示中文名，也能按中文搜到。
- **存档里超出原版上限的数值不再锁死编辑器**：只校验你**改过**的那一项（与「只校验改过的物品格子」同一口径），
  原样不动就能改背包、改物品；SSC 服导出的生命 600 / 30000 这类角色存档终于能编辑了。

## 修复

- 修掉「版本号」下拉的布局段判断漏了一个门槛（1.4.5 的研究进度前导字节），281 ↔ 282 曾被当成同一布局、
  按错布局做转换。
