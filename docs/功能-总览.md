## 会话与部署

- **会话**：后端内存 + TTL；TShock 重启后刷新页面回登录；`token_invalid` 会清会话并提示重登。
- **多服务器**：可选，默认关（`TSHOCK_ALLOW_CUSTOM_TARGETS`）；开启后可在界面维护多个 TShock 上游并切换。
- **界面**：shadcn/ui（new-york / slate），light / dark / 自动，中英双语，可折叠侧栏与移动端抽屉导航。
- **交付**：单个 Docker 镜像（前端 + Go 后端，distroless，约 20MB）；也可构建单文件二进制。
