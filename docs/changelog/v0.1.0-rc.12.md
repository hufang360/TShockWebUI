# v0.1.0-rc.12 更新日志（2026-11-20）

> 单版本、按功能模块的详细更新。对外发布说明见 [`release/v0.1.0-rc.12.md`](../release/v0.1.0-rc.12.md)；
> 全量历史见根目录 [`changelog.md`](../../changelog.md)。

本轮重点：三个图标页新增「横条」并设为默认；全局搜索就地看物品详情；自定义指令卡片可以带参数；
数据 ID 的 NPC 接上怪物图鉴分组、Buff 补描述与来源物品。

## 指令卡片（新增参数 / 新的添加面板）

- **自定义卡片可以带参数**：绑定指令库里的一个用法形态，按参数表生成字段；每个参数可选**每次填写 / 固定值 / 不传**。
  例如「给物品」卡：物品固定 `29`、玩家每次填、数量固定 `10` → 点执行发出 `/give 29 张三 10`。
  - 参数名 / 必填 / 可选取值取自 TShock 源码与插件参数表，不猜、也不用自己写 `{物品}` 模板。
  - 枚举是下拉（带中文名「白天 · day」）；玩家 / 物品 / NPC / Buff / 词缀 / 区域 / 传送点 / 用户组 / 权限给候选，
    同时允许手输（离线玩家、自定义组都合法，最终由 TShock 判定）。
  - 卡片上的输入框旁边没有标签，占位就是 `参数1` / `参数2`（英文参数名与类型提示缩到悬停里），宽度按内容。
    必填没填时输入框变黄框、执行按钮灰着；输入框下面一行显示**最终会执行的指令**。
  - 状态文案（`等待执行…`）与执行按钮都在卡片右上角；有「每次填写」参数的卡片不参与自动刷新 /「刷新全部」/「统一执行」。
  - 指令库更新导致对不上（指令没了 / 用法串变了）时，卡片提示重新配置，不会发半截指令。
  - 只能在游戏内执行的指令（`allowServer=false` 且服务器没放行）在选指令时就标「仅游戏内」，不能建卡。
- **添加 / 编辑卡片改回抽屉里的两行面板**（不再弹对话框）：名称 + 指令一行（指令带候选，也可手写），
  参数入口是指令输入框内右侧的小按钮（图标 + 参数个数）；下一行左边是这张卡片的尺寸 / 自动执行 / 显示，
  右边是取消 / 添加。参数卡片行尾 ✎ 打开同一个面板，普通卡片仍是行内改名称与指令。
- **「管理卡片」清单可过滤**：卡片超过 6 张时顶部出现过滤框（按名称 / 指令），过滤期间禁用拖拽排序；
  参数卡片显示拼好的指令 + 「参数」徽标。

## 全局搜索

- **物品详情就地打开**：物品行回车不再弹第二个弹框，详情在搜索面板里开一层（与图鉴抽屉同一份内容）；
  点配方材料 / 子物品往里叠，`Esc` 逐级退回列表并停在原来那行。这一层没有底部按钮，`⌘C` 复制 ID、
  `⌘⇧C` 复制名称、`⌘⏎` 前往 Wiki 都收进底栏；「操作」里还能收藏 / 取消收藏（与图鉴同一份记录）。
- **底栏统一成一个主操作 + 一个「操作」菜单**（`⌘K` 也能开）；菜单不放「返回」，回上一层用输入框左侧的返回键或 `Esc`；
  组合键合成一个键帽（`⌘C`）。二级列表去掉顶部标题行，条目数移到左下角，`⌘⏎` 直接去目标页。
- 输入框聚焦不再画描边、去掉「清空」✕；鱼店商品价格写成物品标签时显示成图标；选中鱼店商品直接打开它的详情。
- 修掉提示被弹框盖住一半（层级抬到弹框之上）。

## 物品 ID / 数据 ID / 鱼店（图标与浏览）

- **新增「横条」图标大小并设为默认**：一格一条，图标在左、`#编号` 与名称在右；横条平分整行宽度（最小 160px，
  窗口越宽列数越多）。想回到方块格子就选小 / 中 / 大。横条档下没有「隐藏编号和名称」开关，鱼店横条不画层板 / 遮阳伞。
- **横条悬停提示覆盖整条**，并与方块格的提示完全一致（物品 ID、鱼店不再各弹一份不同的内容）。
- **格子底板统一成主题 `secondary` 灰**：亮色 / 暗色跟着主题走，旧的写死颜色不再使用。
- **物品 ID 左上角改成和数据 ID 一样的页签**（「全部物品 / ⭐ 收藏」），11 个分类按钮改回带文字，分组入口并到这一行。
- **三页搜索框统一到页签行右侧**（固定 16rem、字号小一档），数据 ID 的分类 / 视图开关挪到左侧页签行。
- **全屏时右上角只留「退出全屏」**（常驻不自动收起），并修掉鱼店全屏工具条上沿的一条缝。
- **列表滚过一段距离后右下角出现「回到顶部」**（短列表不出现，全屏可用）。
- **鱼店加「分组」下拉**（钓鱼 / buff / npc / 指令 / 建造 / 召唤 / 团队 / 趣味 / 重铸 / 地牢 / 世界事件）：
  只在「全部」下出现，与搜索叠加；一个商品可属于多个分组，货架上没有的分组不列出。
- 鱼店右侧默认多一张「鱼罐」卡片（`/fish jar`，默认不自动执行）；「管理卡片」图标改为 `gallery-vertical-end`；
  商品详情顶部只留一条标题栏。

## 数据 ID

- **NPC 接入怪物图鉴的分组与排序**：可按图鉴分组（Boss、生物群系等）筛选，按图鉴的排序浏览；
  补齐 `-1` ~ `-65` 号 NPC（内部占位 / 变体），搜索可命中它们的正式名。
- **Buff 补上「游戏内描述」与「哪些东西会给你这个 buff」**（来源物品）；搜索框不再主动弹「最近搜索」。
- NPC 补上痛苦亡魂等缺失条目。

## 其它

- **去掉右下角的浮动指令窗**：「填入指令」改为打开搜索框并预填（`Ctrl/Cmd+K` 的形态），
  各页面（指令小抄、常用表格、物品详情、数据 ID）统一走这一条；浏览器里残留的旧浮窗设置会被自动清掉。
- **页面说明默认收起**，点顶栏 ⓘ 才展开。
