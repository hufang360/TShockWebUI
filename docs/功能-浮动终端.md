# 功能：浮动终端

文档版本：1.0
相关代码：`components/CommandTerminal.tsx`、`components/TerminalTopBarButton.tsx`、`lib/terminalContext.tsx`、
`lib/terminalWindow.ts`、`hooks/useCommandRunner.ts`、`hooks/useCommandResultsList.ts`、`hooks/useCommandHistory.ts`、`hooks/useCommandEditing.ts`
相关测试：`components/CommandTerminal.test.tsx`、`hooks/useCommandRunner.test.tsx`、`lib/terminalWindow.test.ts`、`App.test.tsx`

> 目标：**边看页面边执行指令**。看世界管理 / 玩家背包 / 物品 ID 时想顺手跑一条指令，
> 不必切到「指令」页、也不用把结果留在一个看不见的地方。

---

## 1. 定位与范围

- 只是**已有指令执行能力的新入口**：走同一条 `/api/command`（rawcmd / Tier B），不提权、不加后端接口。
- 结果与指令页**共用同一份数据**，所以终端不是「另一个世界」，而是同一份结果的浮窗视图。
- 其他页面可以**带指令打开**它：`open(text)` 覆盖草稿并把光标移到末尾（「小抄」页点一条记录就是走这个 API）。
- 入口按钮**登录后才出现**；若会话在终端开着时失效，面板内是 `LoginGate`（「请先登录！」+ 登录按钮）。
  会话中途失效时仍按统一流程弹登录框并在成功后重试一次（见 `useCommandRunner`）。

## 2. 入口：顶栏右侧图标按钮

**所有页面都有**，只有两页例外：

| 页面 | 入口 |
| --- | --- |
| 首页 / 物品 ID / 数据 ID / 查看存档 / 小抄 / 玩家管理 / 世界管理 / 自定义模块 | 显示 |
| **指令**（`editor`）/ **设置**（`settings`） | 不显示（这两页不需要边看边执行；指令页本身已有编辑器） |

- 形态：顶栏右侧的**「指令」图标按钮**（`IconAction`，只有 `Terminal` 图标），`aria-label` / `title` / Tooltip 都叫「指令」；手机在顶栏 `…` 菜单里。hover 的 Tooltip 里带快捷键。
- **登录后才显示**（未登录不渲染）；终端打开时按钮保持按下态（`aria-pressed`），再点一次关闭。
- **切到「指令」/「设置」页会自动收起终端**（正在执行的指令不受影响，结果照样写进共用结果列表）。
- 实现：`components/TerminalTopBarButton.tsx`（顶栏右侧；手机在 `…` 菜单里）+ `App.tsx` 的 `terminalAllowed`（`activeTab !== 'editor' && activeTab !== 'settings'`）。

**快捷键**：`Ctrl + `` `（macOS 也可 `Cmd + `` `）开关终端。`Ctrl+`` ` 不产生字符，
所以焦点在输入框里也直接生效，不会和输入法冲突（`lib/terminalContext.tsx` 的 `isTerminalShortcut`）。
快捷键本身不受上面的页面规则限制（在指令 / 设置页也能用），只是默认没有可见入口。

## 3. 形态

| 视口 | 形态 | 说明 |
| --- | --- | --- |
| ≥ 768px | **非模态浮动小窗** | 固定在右下角，可拖动标题栏移动、拖右下角缩放；不锁焦点、不压暗页面，可以一边点页面一边执行 |
| < 768px | **底部抽屉**（`Sheet side="bottom"`，80dvh） | 浮窗在手机上会吃掉整屏，改用抽屉；模态关闭即可 |

为什么不用 `Popover`：点外部即关、高度受限、没有焦点管理，选补全 / 看结果都会把浮层关掉。
为什么不复用右侧 `Sheet`（桌面）：它是模态 Dialog，会锁焦点 + 压暗整页，正好和「边看边执行」相反。

**非模态层的约定**（`docs/UI组件.md` 也记了一条）：`z-40`，低于所有模态层（`z-50`）；
打开模态（登录框、详情抽屉等）时不强行收起终端，只是被模态遮住；关闭不做「点外部关闭」，只认
`×` / `Esc` / `Ctrl + `` `，或再点一次顶栏入口。

## 4. 布局：输入框在底部

```
┌──────────────────────────────┐
│ 指令            〔清空〕〔↗〕〔×〕│ 标题栏（拖动区、窗口标题也叫「指令」）
├──────────────────────────────┤
│  结果列表（贴底滚动、可折叠）      │  ResultPanel
│  …                            │
├──────────────────────────────┤
│  /relive 参数提示               │
│  [ 输入指令…            ] [▶] │  CommandEditor
└──────────────────────────────┘
```

- `CommandEditor` 的补全下拉是 `absolute bottom-full`（**向上**展开）。输入框放底部才能保证
  下拉始终有空间；放顶部且在屏幕下缘时会被裁掉。
- 包裹编辑器的容器**不能** `overflow-hidden` / `overflow-y-auto`，否则下拉被裁。
  浮窗本身 `overflow-hidden`，所以最小高度定为 420px（足够容纳 288px 的下拉 + 参数提示 + 输入行）。
- 结果区直接复用 `ResultPanel`（富文本 / `[i:..]` 图标 / 贴底滚动 / 折叠）。
- 输入框用 `CommandEditor` 的 `compact` 尺寸（高度 `h-8`、字号比设置值小 3px、发送按钮 `size-7`），
  给结果区多留一点纵向空间；补全 / 参数提示 / 历史回翻行为与指令页一致。窗口标题（`aria-label`）也叫「指令」。
- 标题栏右侧的「清空 / 在指令页中打开 / 关闭」三个图标按钮 hover 都有 Tooltip（`title` 保留给触屏 / 读屏）。

## 5. 数据：哪些共用、哪些独立

| 数据 | 存储 | 是否与指令页共用 | 理由 |
| --- | --- | --- | --- |
| 执行结果 | `tswui:commandResults`（按服务器） | **共用** | 终端跑完，切到指令页能直接看到同一条；seq 接着最大值递增，不撞号 |
| 历史 | `tswui:history` | **共用** | 终端执行过的指令出现在指令页历史 / ↑↓ 回翻里 |
| 输入草稿 | `tswui:terminal:draft` | **独立** | 终端执行后清空输入；若共用 `tswui:draft` 会顺手抹掉指令页里没跑完的草稿 |
| 窗口几何 | `tswui:terminal`（`{ x, y, w, h }`） | 全局（不分服务器） | 窗口位置属于界面偏好，不需要按上游区分 |

共用的前提是 `useLocalState` 订阅 `STORAGE_EVENT`：指令页与终端同时挂载时，一边写入另一边立刻同步。
终端的输入草稿在执行成功（`dispatched`）后清空；被前端拒绝（`in_game_only` / 未登录）时**保留输入**，方便就地改。

## 6. 执行流程

终端没有自己的执行逻辑，全部走 `hooks/useCommandRunner.ts`（指令页同一份）：

1. `inspectCommand` 前置校验：空输入 / `allowServer=false`（Tier A）→ 追加 `rejected` 结果，不发请求；
2. 未登录 → 追加 `rejected`，不发请求；
3. 发 `/api/command`；`token_invalid` 时 `onTokenInvalid()`（弹登录框）→ 登录成功**重试一次**；
4. 追加结果 + 历史；返回 `dispatched`（是否真的发出去了）。

真正的权限判定始终在 TShock；终端不提权、不伪造身份（`docs/设计原则与约束.md` §4.2 / §5）。

## 7. 交互细则

| 场景 | 行为 |
| --- | --- |
| 打开 | 点入口按钮或 `Ctrl+`` `；输入框自动聚焦（编辑器随面板挂载）；其他页面可用 `open(text)` 预填并覆盖草稿 |
| Enter | 补全下拉打开时先接受候选；下拉关闭时执行（与指令页完全一致） |
| ↑ / ↓ | 历史回翻（下拉关闭时） |
| `Esc` | 先关补全下拉（编辑器内部 `preventDefault`），再一下才关终端 |
| 执行中 | 发送按钮转圈；重复 Enter 被 `runningRef` 挡住 |
| 清空 | 只清本机结果列表（与指令页共用），二次确认 |
| ↗ | 「在指令页中打开」：把当前输入写进 `tswui:draft`、关闭终端并跳到指令页 |
| 关闭 | 组件不卸载：正在执行的指令继续跑完，重新打开能看到结果 |
| 拖动 / 缩放 | 结束时写入 `tswui:terminal`；恢复时一律先 clamp 进视口（换小屏不会跑到屏幕外） |
| 换页 | 切到「指令」/「设置」自动收起；其余页面保持原状 |

## 8. 已知限制

- **没有真正的焦点陷阱**（非模态的设计）：Tab 可以从终端走到页面其余部分；这是刻意取舍。
- **不做跨标签页实时同步**：窗口几何只在挂载时读取；另一标签改了尺寸不会被本标签感知。
- **移动端软键盘**：底部抽屉靠 `Sheet` 的定位 + 浏览器行为处理；极端情况下（小屏 + 展开键盘）
  输入框可能被键盘盖住一部分，需要在真机验证。
- **弹层层级**：终端在 `z-40`，被 `z-50` 的模态层盖住；同时打开两个浮层的体验未单独优化。
- 结果上限 20 条（与指令页一致），超出丢最旧。

1. 世界管理页开终端执行 `/wi`，看到真实世界信息；

4. devtools → Application → Local Storage 确认没有 token，只有上述 `tswui:*` 键。
