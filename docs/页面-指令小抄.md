# 页面：小抄（侧边栏独立页，原「指令小抄」）

文档版本：4.0
相关代码：`pages/CommandTipsPage.tsx`（页面）、`lib/worldCommandTips.ts`、`lib/spawnTips.ts`、`lib/commandFormat.ts`
相关测试：`pages/CommandTipsPage.test.tsx`、`lib/spawnTips.test.ts`、`App.test.tsx`
数据：`data/npcs.json`（`sb` / `en`）、`lib/npcCollections.ts`、`tools/gen-data.mjs`

> 定位：世界 / 时间 / 召唤类指令的**生成器**。侧边栏「常用」分组，**排在「指令」下方**（图标 `ScrollText`，地址 `#/commands`）。
> 页面有两个 tab：**默认 / NPC管理**。（「指令库」已移回指令页工具面板，见 §4。）
> 点一条记录 = 把完整指令**填进右下角「指令」浮窗**（覆盖草稿，不自动执行）。
> 未登录也能看（小抄不取服务器数据）。旧地址 `#/spawn` 也回落到本页。

---

## 1. 为什么是「生成指令」而不是「直接执行」

- 页面只负责拼指令：避免误触发动世界（刷 Boss、切困难模式、改时间都是不可轻率执行的操作）。
- 权限与结果都由 TShock 判定，页面不承诺任何权限。
- 其中 `/sb`、`/sm`、`/tpnpc` 是 `allowServer=false`（C6），**网页端根本不能执行**，
  只能复制到游戏里；其余的（`/worldevent`、`/time`、`/godmode` …）都是 `allowServer=true`，
  在页面输入框 / 浮窗里回车即可执行。

## 2. 结构：两个 tab

`Tabs`（**line / 下划线变体**）：

| tab | 卡片 |
| --- | --- |
| **默认** | 事件（`/worldevent` + `/forcehalloween` `/forcexmas`）、世界模式（`/worldmode` `/hardmode` `/evil`）、时间 / 风 / 世界信息（`/time` `/wind` `/worldinfo`） |
| **NPC管理** | 召唤 Boss（30 条）、召唤 NPC（示例，ID）、传送 NPC（示例 + 去数据 ID 查更多）、刷怪率（`/maxspawns` `/spawnrate`）、无敌模式（`/godmode`） |

- **没有大标题**（顶栏面包屑已指明页面）；「需要权限 / 不会自动执行」的提示放在**每个 tab 内部**顶部。
- **所有卡片统一两列网格**（`grid gap-4 xl:grid-cols-2`，窄屏单列）：
  - 默认：事件 / 世界模式 / 时间·风；
  - NPC管理：召唤 Boss（表格）/ 召唤 NPC / 传送 NPC / 刷怪率 / 无敌模式。
- **卡片内是表格**（`CommandTable`）：列依次为 **指令（第一列，等宽字体）→ 名称 → 备注 → 填入按钮**；
  分组（事件 / 入侵 / 节日）用整行 `colgroup` 表头隔开。备注列在 `sm` 以下隐藏。
- 表格在卡片内滚动：用法卡 `max-h-[26rem]`、召唤 Boss `max-h-[30rem]`，行多也不会把页面撑长；表头 sticky。
- 点整行或行尾按钮都会把指令填进右下角「指令」浮窗（按钮同时是键盘 / 读屏入口），不自动执行。

## 3. 指令与来源（全部按 TShock 6.2.1 源码核实）

### 3.1 事件（`/worldevent`）

| 行 | 指令 | 说明 |
| --- | --- | --- |
| 陨石 / 满月 / 血月 / 日食 | `/worldevent meteor` / `fullmoon` / `bloodmoon` / `eclipse` | 一次性事件 |
| 沙尘暴 / 下雨 / 史莱姆雨 / 金币雨 | `/worldevent sandstorm` / `rain` / `rain slime` / `rain coin` | **切换**，再执行一次停止 |
| 灯笼夜 / 流星雨 | `/worldevent lanternsnight` / `meteorshower` | 一次性事件 |
| 入侵（二级） | `/worldevent invasion goblins\|snowmen\|pirates\|pumpkinmoon\|frostmoon\|martians` | `Invade()` 读 `args.Parameters[1]`；可选第 3 个参数是波数 |

- 事件全集 = `_validEvents`，入侵类型 = `_validInvasions`（`TShockAPI/Commands.cs`）。
- `rain` 的第二个参数取自 `Rain()`：`slime` / `coin`，不传 = 普通雨。

### 3.2 节日模式

| 指令 | 行为 |
| --- | --- |
| `/forcehalloween` | 切换万圣节模式（`ForceHalloween = !ForceHalloween`），**无参数** |
| `/forcexmas` | 切换圣诞节模式，**无参数** |

### 3.3 世界模式

| 指令 | 行为 |
| --- | --- |
| `/worldmode normal\|expert\|master\|journey` | 设置世界难度（`_worldModes`；`creative` 是 `journey` 的别名，也接受 0–3） |
| `/hardmode` | **切换**困难模式（无参数；服务器 `DisableHardmode` 时无法打开） |
| `/evil` | **切换**腐化 ⇄ 猩红（无参数） |

### 3.4 时间 / 风 / 世界信息

| 指令 | 参数 |
| --- | --- |
| `/time day\|night\|noon\|midnight\|hh:mm` | 设置时间 |
| `/wind <mph>` | -40 ~ 40（来自 `Wind()` 的范围校验） |
| `/worldinfo` | 无参数，返回世界信息 |

### 3.5 刷怪率

| 指令 | 参数 |
| --- | --- |
| `/maxspawns [n\|default]` | 无参数 = 查询；`default` = 5 |
| `/spawnrate [n\|default]` | 无参数 = 查询；`default` = 600；**数值越小刷得越快** |

### 3.6 无敌

| 指令 | 说明 |
| --- | --- |
| `/godmode` | 切换**自己**的无敌（需要 `tshock.godmode`） |
| `/godmode <玩家名>` | 对别人用需要 `tshock.godmodeother`（卡片注释里说明，不做按钮，避免填入占位符） |

### 3.7 召唤 / 传送

| 指令 | 拼法 |
| --- | --- |
| `/spawnboss <boss> [数量]` | 30 个 Boss，顺序与备注取自 `ShowSpawnTips()`；参数取 `data/npcs.json` 的 `sb`，含空格加引号 |
| `/spawnmob <名称/ID> [数量]` | 示例用数字 ID（向导 22、旅商 368） |
| `/tpnpc <名称>` | **只接受名称**（`TPNpc()` 不解析 ID），用英文名；按钮显示 `#ID` 仅作对照 |

## 4. 与浮动终端、数据 ID 的关系

- 点击任何一行 / 示例 → `useTerminal().open(cmd)`：打开浮窗并**覆盖**草稿，不累加。
- 指令库（全部指令列表）在**指令页的工具面板**里（最左边的 tab），点一条填进页面输入框。
- **数据 ID → NPC / Buff 详情**里显示同一批指令（`/spawnboss` 仅 Boss、`/gbuff` 用于 buff），同样可复制；
  两边都**不按玩家权限隐藏**（页首提示「各指令权限不同」，判定在 TShock）。
- 「在数据 ID → NPC 里查更多」：写 `dataIdState` 的 `kind: 'npc'` 后跳 `#/dataid`，落地即 NPC tab。

## 5. 边界

- 不做「一键全部 Boss」「一键切换困难模式」这类批量/危险操作按钮：点开只是填一条指令，执行前玩家自己确认。
- 不列全部怪物 / 城镇 NPC（示例 + 数据 ID 入口），避免两处维护同一份清单。
- 不校验权限后才显示行（除数据 ID 详情外）：权限判定在 TShock，页首只做统一提示。

真实服务器（人工）：

1. 默认 tab 点「血月」→ 输入框出现 `/worldevent bloodmoon`（自动回到「指令」tab），回车后游戏内入夜并出现血月；
2. 点 `/time 12:00` 执行 → 世界时间变为正午；
3. 点 `/maxspawns 5` 执行 → 返回「changed the maximum spawns to 5」；
4. NPC 管理 tab 点 Boss → 输入框只有指令（不自动执行）；未开 Tier B 时回车应得到「只能在游戏内执行」的明确拒绝。
