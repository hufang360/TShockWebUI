# v0.1.0-rc.13 更新日志（2026-11-21）

> 单版本、按功能模块的详细更新。对外发布说明见 [`release/v0.1.0-rc.13.md`](../release/v0.1.0-rc.13.md)；
> 全量历史见根目录 [`changelog.md`](../../changelog.md)。

本轮重点：鱼店货架改成「手动刷新 + 本机缓存」（命中缓存时 0 次上游请求）；
首页「世界信息」「我的背包」默认改手动执行；鱼店「分组」的取消方式收进下拉第一项。

## 鱼店

- **货架改「手动刷新 + 本机缓存」**
  - 货架只在服主改完配置（`/fish reload`）后才会变，所以不再定时重拉：进页面时**货架为空才请求一次**，
    成功就存本机（按服务器分开，含能力探测结果）。之后刷新浏览器、切走再回来都直接读缓存，**不再打服务器**。
  - 工具条新增「刷新货架」按钮，旁边显示「更新于 20:08」；**超过 24 小时**没更新变警告色，
    悬停提示点刷新重拉，过期时时间戳带日期（「更新于 11/20 20:08」）。
  - 右侧指令卡片那组「刷新全部」不再顺带刷货架（各自刷各自的）；执行「重载配置」成功仍会重拉，
    购买之后不重拉。
- **商品详情去掉「我的进度 / 还能买 N 次 / 冷却还剩 N 秒」**：拉货架不再带 `self=1`
  （那要求玩家在线，还会逐条算个人限购）。能不能买、还剩几次以**购买时的上游判定**为准；
  买不成时上游的提示原样显示。
- **「分组」下拉的取消方式改了**：「分组：钓鱼」旁边那颗 × 去掉，下拉第一项固定是**「全部」**
  （不筛分组，条数是当前页签 + 搜索命中的件数）；点它或再点一次已选中的分组都回到整张货架。
  清除入口和分组列表收在同一处，工具条少占一格。

## 首页

- **「世界信息」「我的背包」改为默认手动执行**：这两张卡的数据变得快，进页面顺手打两条指令不值得。
  现在它们不参与自动刷新 /「刷新全部」/「统一执行」，按钮是 ▶「执行」、左下角常显「执行于 …」。
  想让它们跟着自动跑：首页「管理卡片」→ 该卡行尾菜单里打开自动执行。

## 维护

- 新增手动工作流 **`Promote latest`**：把某个已发布的版本提升为 Docker 的 `latest`
  （在 registry 内复制 manifest，不重新构建）。发版流程仍是「预发布不自动覆盖 `latest`」，需要时手动跑一次。
