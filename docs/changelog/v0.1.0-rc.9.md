# v0.1.0-rc.9 更新日志（2026-11-07）

> 单版本、按功能模块的详细更新。对外发布说明见 [`release/v0.1.0-rc.9.md`](../release/v0.1.0-rc.9.md)；全量历史见根目录 [`changelog.md`](../../changelog.md)。

本次重点：**侧栏全局搜索**（一个框搜物品 / NPC / 指令 / 页面等）、**「指令小抄」改版**（行内展开详情、同前缀指令折叠）、
**详情抽屉不再挡住左侧导航**（鱼店 / 物品 ID / 数据 ID，且切回来还在）、**图鉴以外的物品详情改成弹框**、**货架顶上多了一圈遮阳伞**。

---

## 指令小抄：单击行内展开详情、同前缀指令折叠

- 主表只剩**指令 / 说明 / 权限**三列：不再显示「规范写法」那一行、不再有操作列，也没有单独的分组标题行
  （分组标题改成折叠行的「说明」，例如 `/worldevent` → 世界事件）；**原来的「说明」与「备注」合成一列**
  （`主说明 · 备注`，如「切换困难模式 · 仅游戏内」）。
  权限取自 `data/commands.json`，没有权限写 `-`；折叠行整组权限一致才显示。
- **整表按指令列 a~z 排序**（折叠行用它的前缀参与排序；分区只决定折叠行的「说明」）。
- **单击任意一行就地展开「详情行」**（不再有弹框 / 抽屉，单开、再点收起）：
  指令语法、使用提示、别名、相关指令（点一下**把表格过滤到那条**）、`数据 ID → NPC`（`/spawnboss` `/spawnmob`
  `/tpnpc` `/butcher` `/renameNPC` 才有）、权限（仅 `md` 以下）。表格里已有的指令 / 说明 / 权限 / 复制 / 执行不重复。
  没有任何补充信息的行展开时不插空行。
- **行内悬停按钮**（触屏常显）：指令列「复制指令 / 执行指令」、权限列「复制权限」；
  **带占位符的参考行与 `allowServer=false` 的指令没有「执行指令」**。执行只是把指令填进浮窗，不自动发出。
- 详情行里的语法 / 提示按条走：`/forcehalloween` `/forcexmas` `/hardmode` `/evil` `/worldinfo` 不显示指令语法；
  `/maxspawns` 与 `/spawnrate` 各显示自己的；`/kick` `/mute` 不套 `/ban` 的语法与提示；
  「玩家账号」整组只讲自己那一条；`/godmode` `/butcher` `/renameNPC` `/tempgroup` 等不显示使用提示。
- 多子项参考行（`/warp` `/region` `/itemban` `/projban` `/tileban` `/group`）的说明补齐成子命令标签（`/region define` → 定义区域）。
- **同一前缀的指令默认折叠**：`/worldevent …`（事件 + 入侵合成一行）、`/worldmode …`、`/time …`、`/spawnboss …`、
  `/warp …`、`/region …`、`/group …`、`/death …` 等收成一行，点一下展开；展开后子行显示完整指令并缩进一级；搜索时自动展开。
- 几组「同一件事的两个方向」也折起来：`/give` 收起 `/item`、`/buff` 收起 `/gbuff`、
  `/tp` 收起 `/tphere` `/tppos` `/pos` `/tpallow`。
- **只能在游戏内执行的指令**（`allowServer=false`）指令文字标红，说明里跟一句「仅游戏内」；多子项的只在折叠行标（子行不重复）。
- 分组合并：「账号（玩家自己）」+「用户账号」→ **玩家账号**；「封禁」+「禁言 / 踢出」→ **封禁**；
  「入侵」并进「世界事件」；`/itemban` `/projban` `/tileban` 从「建筑与保护」挪到「封禁」。
- 「权限配置」只剩两行折叠组：TShock 权限两条并进 `/group`，插件权限并进 `hf 常用`（新增 `/user group hf GM` 把 `hf` 提成服主）。
- 相关指令补上节日开关：`/forcehalloween` ↔ `/forcexmas`，两条都关联 `/worldevent`。
- **搜索也匹配权限名**（如 `tshock.world.save`）。
- 斑马纹按数据行序号计算（插入详情行时条纹不跳），各列单行、超出省略；指令列超过 22 字符时悬停显示完整指令。
- 使用提示与指令语法都按句换行显示（`whitespace-pre-line`）。

## 详情抽屉：只遮内容区、不再挡住左侧导航

- 适用范围：鱼店商品详情、物品 ID 详情（可堆叠抽屉）、数据 ID 详情、指令小抄的分组抽屉。
  （指令小抄的指令详情本次已改成居中弹框，不再走这套遮罩。）
- 以前的详情是**模态抽屉**：弹出就把整页压暗（包括左侧导航），想切到别的页面得先关掉；
  关掉再回来还得重新翻货架找那件商品。
- 现在（桌面端）遮罩**只盖内容区**（半透黑 50%，**不模糊**），**左侧边栏不被遮住**：抽屉开着也能直接点导航切到指令 / 首页。
  外观仍是原来的右侧整高抽屉；侧栏收起时，「展开侧栏」按钮浮在遮罩之上。
- **切到别的页面再回来，刚才打开的详情还在**：鱼店商品（数量 / 参数回默认）、数据 ID（`{ kind, id }` 记在页面模块内存里）、
  物品 ID 都接着开；关掉之后就不会再自动弹开。
- 关闭：点遮罩、右上角 × 或 `Esc`（点导航不算关闭）；「建筑预览」的放大图叠在它上面时，`Esc` 只关放大那一层。
- 手机 / 窄屏保持原样：模态抽屉，点抽屉外 / 下滑关闭。
- 详情里的内容本身都没变（鱼店的价格 / 解锁 / 别名 / 限购 / 购买时机 / 检查 / 备注、参数与数量、购买结果、建筑预览）。
- 货架还没拉回来时，恢复出来的详情**不允许购买**（此时商品编号可能已经指向别的商品，插件是按配置下标发货的）。

## 物品详情：图鉴以外的页面改成弹框

- 以前在指令 / 数据 ID / 鱼店等页面点物品提示右上角的 ⓘ「物品详情」，会**跳到「物品 ID」页**再打开抽屉，
  当前筛选与填了一半的指令都丢了。
- 现在**就地弹出物品详情弹框**，内容与图鉴里那份完全一样（tips、词缀与标签广播、`/give`、合成 / 分解 / 掉落、
  前往 Wiki / 复制名称 / 复制 ID）；弹框里再点配方材料 / 掉落物的 ⓘ 会**叠一层**（左上角「返回」）。
- 切到别的页面会自动关掉这个弹框；「物品 ID」页面内的行为不变（仍是可堆叠的右侧抽屉）。

## 鱼店：货架区顶上多了一圈遮阳伞

- **蓝白相间**的布条排成一整片，每条下端收成半圆；最左 / 最右那一条是灰色（篷布绕到背面的那一截）。
- 布条会**按透视散开**：中间几条竖直、越靠两端越往外斜，像站在摊子正前方看那圈裙边；
  每块布两侧略暗、下端再压一截，看着是一片厚布。两端留一点空白，不会切出半条碎布。
- 布条尺寸固定（蓝 33px / 白 24px），窗口拉多宽都不会变胖。
- 表格视图里不画（数据表上面顶块篷布没意义）；「页面设置」里可以关掉（`遮阳伞`），跟服务器分开记。

## 左侧栏顶部：语言 / 主题按钮换位

- 页头右上角原来是「主题（电脑 / 太阳 / 月亮）→ 语言（中 / EN）」，现在交换：**语言在左、主题在右**。
- 只是顺序变化，行为不变（点语言切中英、点主题循环 自动 / 浅色 / 深色）。

## 全局搜索（侧栏）

- **入口**：侧栏页头第二行（「WebUI」标题行下方、「首页」上面）是一个**长得像搜索框的按钮**（放大镜 +「搜索…」+
  快捷键芯片）；点它、按 `Ctrl/Cmd+K`、或点移动端顶栏的搜索图标，都打开**同一个居中弹框**。
  - 全站只有这一套搜索界面（原来那套「贴着侧栏输入框的浮层」已删除）。
  - 侧栏收起时快捷键照样能用；**商品详情 / 物品详情这类抽屉开着时也能用**（搜索弹框浮在它们上面，只让位给已有模态弹框）。
- **可搜的域**：页面（含已激活模块与自定义模块）、物品、指令、NPC、Buff、图格、墙、鱼店商品、物品集合。
  - 图格与墙**分成两组**，右侧统一显示 `#ID`；指令行有终端图标。
  - 组顺序固定（不按得分重排组）；组内「完全相同 > 前缀 > 包含」。只做字面匹配，不做拼音 / 模糊 / 语义。
  - **不搜玩家名**（由「玩家管理」页自己查）。
- **动作**：物品**就地打开物品详情弹框**（不跳页）；其余结果跳页并带上搜索词——
  指令 → 指令小抄；NPC / Buff / 图格 / 墙 → 数据 ID（连数据源一起切）；鱼店商品 → 鱼店（填好搜索框）；
  物品集合 → 物品图鉴应用集合。被截断的组末尾有「前往「XX」查看更多」，写明会去哪个页面。
- **指令结果可以就地执行**：`allowServer !== false`、没有必填参数、且已登录时，`Enter` 直接在弹框里执行并切到
  二级页显示结果（执行中转圈 → 输出 / 错误），左上「返回」回到列表；否则仍然只是跳「指令小抄」查用法。
- **行内操作**（悬停 / 高亮时浮在右侧信息之上，不占常驻位置）：复制 ID / 复制指令、把指令填进浮动终端
  （终端不可用时不显示）。键盘：`⌘/Ctrl+C` 复制高亮行，底栏右侧跟着高亮行显示「复制 ID / 复制指令」。
- **底栏提示**：左侧通用键 `↑` `↓` 选择 / `Enter` 打开 / `Esc` 取消；只和当前模式有关的提示靠右
  （有最近搜索时的 `Delete` 删除、结果模式下的复制快捷键）。弹框**没有关闭按钮**，靠 `Esc` / 点遮罩关。
- **空态与降级**：空词显示「最近搜索」（≤5 条，新键 `tswui:global:searchHistory`，可单条 `Delete` 删除）；
  「鱼店商品」未登录或插件没装时**整组不出现**。搜索本身不发请求，只有打开弹框时按需拉一次鱼店货架。
- **样式**：弹框圆角 16px（比通用弹框紧一档）、输入框与页面搜索框同高；条目高亮是圆角块。
- **代码**：`components/GlobalSearch.tsx`（入口按钮 + 弹框 + 二级结果页）、`lib/globalSearch.ts`（匹配与截断）、
  `lib/searchIntent.ts`（跨页预填）、`lib/fishGoodsCache.ts`（货架缓存）、`lib/keyboard.ts`（`⌘` / `Ctrl` 文案）；
  详见 [`功能-全局搜索.md`](../功能-全局搜索.md)。

## 修复：无 HTTPS 时复制按钮不工作

- 现象：用 `http://IP:8080` 打开（C12 的常规部署形态）时，所有复制按钮都**没反应**：
  点「复制 ID / 名称 / 指令 / 结果 / 配方 / 权限命令」都不出现「已复制」；
  「指令小抄」里点复制还会在控制台抛 `TypeError: Cannot read properties of undefined (reading 'writeText')`。
- 原因：`navigator.clipboard` **只在安全上下文**（`https:` / `localhost`）存在，项目这 9 处直接调用它，
  http 下它是 `undefined`，`navigator.clipboard.writeText(...)` 是**同步抛错**（`.catch` 接不住）。
- 处理：新增 `web/src/lib/clipboard.ts` 的 `copyText()`，统一收敛这 9 处调用：
  优先 Clipboard API，不可用 / 被拒时退回隐藏 `textarea` + `document.execCommand('copy')`（http 下仍可用）；
  两条都失败才返回 `false`（界面不显示「已复制」，不假装成功）。
- 影响：http 部署下复制恢复可用；https / localhost 行为不变。
