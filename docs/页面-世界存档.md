## 定位

**公开工具 + 纯本地**：本地 `.wld` 世界存档查看器。

- 侧边栏「工具 › **世界存档**」，与「玩家存档」并列；「世界管理」（WorldModify 插件模块）在「扩展」分组。
- **文件不上传服务器**：头部解析、图格解码、缩略图渲染全部在浏览器里完成（无接口、无登录、无插件依赖）。
- **默认只读**：导入、缩略图、地图分析、查找图格都不改动任何文件、不写入任何存储。
- **可编辑并另存**（用户确认的例外）：世界名 / 种子 / 难度 / 出生点 / 时间 / 月相 / 血月 / 日食 / 困难模式 /
  Boss 进度；**整类替换图格**（A → B）；箱子名 / 箱子内容 / 招牌文本。保存时在浏览器里改字节，
  **下载一份新文件**由你自己替换（原文件不动、不上传）。箱子和招牌的**数量 / 坐标**不可改。
  格式事实见 [`技术事实.md`](技术事实.md)「世界文件（.wld）」。

## 支持的文件

| 文件 | 说明 |
| --- | --- |
| `.wld` | Terraria PC 世界存档 |
| `.wld.bak` | 游戏 / TShock 保存时的上一份备份（**同格式**） |
| `.wld.bak2` | 更早一份备份（**同格式**） |

文件选择框 `accept=".wld,.wld.bak,.wld.bak2,application/octet-stream"`；也可以把文件**拖进整页**。
不做客户端扩展名拦截：改名后的文件照样能解析，真正判定看文件头。

范围：release **140 … 326**（1.2.4 ~ 1.4.5.8）。更旧的是 V1 格式（没有 `relogic` 文件头），
提示「世界文件版本过旧（…）：请在游戏里打开并重新保存一次」；更新的提示「高于本工具支持的版本」。
另外有个 64 MB 的保险丝：明显不是世界存档的大文件直接拒绝（不做解析、不卡界面）。

## 界面结构

1. **顶栏右侧**：`导出图片`（`IconAction` + `Camera`，与「玩家存档」同款；渲染完成后才出现）。
2. **工具卡**（一行）：`导入 .wld`（主按钮，解析中显示 Spinner）+ **`来个 Demo`**（outline，`Sparkles`）+ `导出 .wld`
   （导入过才有）+ **`编辑`**（导入过才有，进入编辑态）+ 右侧说明（格式；解析中变成「正在渲染缩略图… N%」）。
   编辑态下这一行换成 **`保存并下载 .wld`** + `放弃修改`（有改动时二次确认）+ 说明文案。
   文件选择框隐藏（`data-testid="world-wld-input"`）。
   - **来个 Demo**：拉取自带的一张**空白世界**（`web/public/demo/world.wld`，4200×1200，只有天空 / 地表 / 石头 / 地狱，
     81 KB、release 228），走**完全相同的本地解析**流程，导出 `.wld` 也能把这份 demo 存下来。
     资源缺失时给一句「Demo 世界加载失败」，不影响手动导入。
4. **空态**：`Empty` + 「还没有选择世界存档」；整页是拖放区（`data-testid="world-drop"`）。
5. **错误**：`Alert variant="destructive"`，文案直接用解析器给的具体原因（如「不是有效的 Terraria 世界存档: 文件头不匹配」）。
6. **世界概览**（`WorldPanel`）：
   - **缩略图**：`<canvas>`。位图按「像素预算」尽量做到 **1 图格 = 1 像素**（小 / 中世界原尺寸，
     大世界 2 图格/像素 = 4200×1200）；屏幕上按容器宽度平滑缩放，**点击可打开 1:1 大图**（可滚动看清方块）。
   - **标题行**：世界名 + 徽章（难度 / 大小 / 邪恶 / 困难模式 / 已收藏 / 本地导入）。
     - 难度：旅途 / 普通 / 专家 / 大师；大小按图格宽（≤4200 小 / ≤6400 中 / 其余大）；邪恶：腐化 / 猩红。
   - **特殊种子**（有才显示）：醉汉世界 / 值得一玩的世界 / 十周年纪念 / 饥荒联动 / 蜜蜂世界 /
     颠倒世界 / 无陷阱世界 / 天顶世界 / 空岛世界。
   - **字段网格**（2 / 3 / 4 列自适应，值空则不显示该行）：尺寸 `宽 × 高`、种子、创建时间、最后游玩、
     出生点、地牢、存档版本（`1.4.5.8（326）` 这种「游戏版本（release）」）、保存次数（revision）。
   - **Boss 进度**：已击败的 Boss / 入侵徽章；一个都没有时显示「还没有击败任何 Boss」。

7. **地图分析**（`WorldAnalysis`）：概览 chips（空气占比 / 水·岩浆·蜂蜜·微光 / 箱子·招牌·城镇 NPC·图格实体）+
   **分层**（地表 / 地下 / 洞穴 / 地狱，每层 y 范围、空气占比、Top3 方块）+ **图格占比** Top12（可展开全部）+
   墙体（折叠）+ 箱子物品 Top12；明细可点开（箱子逐格内容 / 招牌全文 / NPC 明细，带搜索）+
   「导出分析」下载 `<世界名>-analysis.txt`。详见 [`功能-地图分析.md`](功能-地图分析.md)。
8. **查找图格**（`WorldFind`）：按名字 / 常量名 / ID / 代表物品名搜**图格、墙、液体**→ 扫描世界 →
   「命中 N 处」+ 坐标（可点→跳 1:1 大图）+ 「在缩略图上标记」+ 「导出坐标 CSV」。
   详见 [`功能-查找图格.md`](功能-查找图格.md)。
9. **编辑态**（`WorldEditPanel`）：世界名 / 种子 / 难度 / 出生点 X·Y / 当日时间（附 `HH:MM`）/ 月相 /
   白天·血月·日食·困难模式 / Boss 与事件复选框；另有 **替换图格**（`WorldTileReplace`：填两个 id、
   实时显示「将替换 N 格」、二次确认；只改 id 字节，长度 / 段指针 / footer 不变）与
   **箱子与招牌**（`WorldContentEditor`：箱子改名 + 40 格内容、招牌多行文本；**只改内容，不改数量与坐标**）。
   底下一行只读摘要（尺寸 / 邪恶 / 版本）+「保存并下载 .wld」「放弃修改」。
   详见 [`计划-wld编辑.md`](计划-wld编辑.md) §7.9 / §7.10。
   编辑态顶部有一条提示：**服务器正在用这个世界时先关服再替换文件**。

## 导出

- **导出 .wld**：把导入时的原始文件原样下载（浏览器 object URL；编辑保存后导出的是**编辑后的**文件）。
- **导出分析**：`<世界名>-analysis.txt`（分节格式对齐 TEdit 分析报告）。
- **导出坐标 CSV**（查找图格）：`<世界名>-<目标>.csv`，抬头 + 每行 `x,y`。
- **导出图片**：把渲染好的缩略图用 `canvas.toBlob('image/png')` 编码，下载 `<世界名>.png`
  （小 / 中世界是原尺寸 1 图格 = 1 像素；大世界 4200×1200）。
  与「玩家存档」的导出图片同一套思路：位图已经算好，只做编码 + 下载，**不经过任何服务端**。

## 时间显示（重要）

存档里两种时间语义**不同**，混用会整体差一个时区（踩过，见 `lib/save/bytes.ts` 的 `dotnetBinaryToIso`）：

- **创建时间**：游戏写 `DateTime.Now` → 本地墙上时间，**原样显示、不换算**；
- **最后游玩**：游戏写 `DateTime.UtcNow` → 换算成浏览器本地时区再显示（与文件 mtime 对得上）。

（ticks 是 100ns 单位、约 6.2e17，超过 double 精度，解析时用 BigInt。）

## 缩略图怎么画（浏览器里）

- 采样：先按**像素预算**（默认 8M 像素 ≈ 4200×1200）算缩放比
  `res = max(1, ceil(sqrt(宽×高/预算)), ceil(宽/8192), ceil(高/8192))`，
  即「能不缩小就不缩小」；每块取**优先级最高**的颜色：图格 > 液体（≥64/255）> 墙 > 深度背景。
- 深度背景（与 TEdit 小地图一致）：`y < 80` 太空 / 最下 192 行地狱 / 岩石层以下 / 地表以下 / 天空。
- 只读图格段一次（`for x { for y }`，RLE 同列向下重复），**按列分块**（默认每 128 列
  `await` 让出主线程一次 + 回调进度），大世界也不卡界面；内存只有缩略图位图（1280px 宽 ≈ 1.8 MB）。
- 颜色表：`web/src/lib/save/worldColors.generated.ts`（`node tools/gen-world-colors.mjs` 生成，别手改）。
- 性能实测：15.4 MiB / 8400×2400 的真实世界，解析 <1ms、渲染 **4200×1200** 位图 ≈**130ms**（V8）；
  输出大小与之前 1200px 版本几乎相同（耗时在图格扫描，不在输出像素数）。
- **悬停看这一格**：缩略图上移动鼠标会显示「图格名 · 墙：墙名 · 液体名 · (x, y)」，空气显示「空气」。
  实现：渲染缩略图时顺手记录**每列的图格流字节偏移**（`recordColumnOffsets`，8400 列 ≈ 34 KB），
  悬停时从该列列首按 RLE 解码到目标行（`web/src/lib/save/worldTileAt.ts`，最多 2400 个条目），
  不重扫世界、也不额外占位图内存。名字与「查找图格」同一套口径（`dataset.tileNameById` / `wallDisplayName`）。
- **导出高清图**（顶栏第二个相机图标）：按 **1 图格 = 1 像素**重新渲染一次再导出 PNG，
  文件名带 `-hires`。屏幕上那张缩略图受 8M 像素预算限制（大世界是 2 图格/像素），要看清方块就用这个。
  实测：4200×1200 → 72 ms / 位图 20 MB；8400×2400 → 450 ms / 位图 81 MB（含画布约 160 MB），
  所以 > 8M px 会先弹确认，> 24M px 直接拒绝。
- **颜色图例**：缩略图下方一行「色块 + 方块名 + 占比」，取占比最高的 6 种。
  色块直接取渲染用的同一张 `TILE_COLORS`（表里没有的用中性灰，与渲染兜底一致），所以颜色不会对不上。
- 为什么不再用 `image-rendering: pixelated`：屏幕上永远是「原图缩小」，平滑降采样比最近邻更接近游戏地图的观感；
  需要逐格看清时点开 1:1 大图。
