# docs 文档索引

本目录是 TShockWebUI 的文档。给编码 Agent 的**必读顺序与铁律**见仓库根 [`AGENTS.md`](../AGENTS.md)；
本页只做**导航 + 命名约定 + 单一事实源**。

## 命名约定

| 类型 | 命名 | 说明 |
| --- | --- | --- |
| 功能 / 机制 | `功能-<名>.md` | 怎么做、事实来源、验收 |
| 页面 | `页面-<名>.md` | UI 结构、交互、数据来源 |
| 插件接入 | `插件-<名>.md` | 端点 / 字段 / 权限 / 限制（模板见 `插件接入规范.md`） |
| 计划 / 草案 | `计划-<名>.md` | 未完成的设计 |
| 审查 / 复盘 | `审查-<名>.md` | 阶段性体验/一致性审查（含发现、建议，待办链接到 `TODO.md`） |
| 历史存档 | `记录-<名>.md` | 任务与验收记录（**不是待办**） |
| 工程 / 规范 | 无前缀或英文大写名 | `设计原则与约束.md`、`ARCHITECTURE.md`、`API_SPEC.md`、`TECHNICAL_RESEARCH.md`、`REST_API限制.md`、`UI组件.md`、`TODO.md` |

## 单一事实源（避免多处维护）

| 铁律 / 提问边界 / 交付要求 | [`AGENTS.md`](../AGENTS.md) | **只放长期约定**；功能细节写 `docs/`，别往 AGENTS 里加 |
